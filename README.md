# STAM FREIGHT CONTROL

Star Citizen 비공식 비영리 운송 플래너입니다. 게임의 `Game.log`에서 읽은 계약과 공개 데이터를 대조해 항로와 적재 계획을 준비합니다. **실게임 검증 전 공개 시험판**이며, 모든 미션의 실제 상자 구성이나 연속 함선 위치가 자동으로 확인되는 완성본은 아닙니다.

[운송 관제](https://limmin3-sudo.github.io/stam-freight-control/) · [Windows 앱 다운로드](https://limmin3-sudo.github.io/stam-freight-control/download.html) · [13단계 출항 안내](https://limmin3-sudo.github.io/stam-freight-control/guide.html) · [남은 작업](docs/RELEASE-READINESS.md)

## 처음 실행하기

1. 다운로드 페이지에서 Windows ZIP을 받고 **새 폴더에 전부 풀어 주세요**. Windows 10/11 x64용이며 Node 런타임을 포함합니다. 별도 Node 설치나 관리자 권한은 필요하지 않습니다.
2. `STAM.exe`를 실행하고 `StarCitizen/LIVE/Game.log`를 선택하세요. 기본 브라우저에 관제가 열립니다. 실행기 창은 최소화해 두셔도 됩니다.
3. 파트너를 고르고 함선·출발지를 확인하세요. 로그에서 찾은 함선·위치는 후보로 제시하며 현재 탑승·위치로 단정하지 않습니다.
4. 게임에서 운송 계약을 받으세요. 정보가 충분한 계약은 자동으로 선택됩니다. 늦게 들어오는 목표는 같은 실행 계약 ID에 연결합니다.
5. **항로 계산·안내 시작**을 누르세요. 지도와 아래 적재 3D에서 방문 순서와 화물 공간을 확인할 수 있습니다.

웹사이트만 열었을 때의 파일 선택은 저장 로그를 한 번 읽습니다. 실시간 연동은 Windows 앱의 로컬 관제를 사용하세요. 실행기를 종료하면 로그 감시도 종료됩니다. 연결 주소에는 임시 키가 포함될 수 있으므로 주소 전체를 공유하지 마세요.

## 운송 계획

- 수석 항해사는 함께 실을 화물과 같은 방향의 계약을 묶습니다. 브리지 오퍼레이터는 가까운 간단한 계약 완료를 우선합니다.
- 동일 배송지의 화물을 가깝게 배치하고, 미션별 화물 소유 정보는 유지합니다. 꺼둔 그리드는 적재에서 제외하며 이미 실린 위치는 재계산할 때 보존합니다.
- 상자 크기별 개수가 없으면 **공간 예약**으로 구분합니다. 예약 블록을 실제 상자로 표시하지 않습니다. 사용자가 확인한 크기별 개수는 직접 지정할 수 있습니다.
- 운송 중 새 계약은 **현재 항로에 추가 / 다음 계획으로 보관** 중 선택합니다. 계약을 제외할 때 남은 화물을 확인하고 공간을 유지합니다. 게임의 계약을 대신 포기하거나 화물을 버리지는 않습니다.
- 지도 이동은 계획 시간에 따른 **예상 이동**입니다. 실제 연속 위치나 배송 완료를 뜻하지 않습니다.
- OCR은 사용자가 켠 화면 보조 감시입니다. 선택 영역만 로컬에서 읽고 로그와 비교하며, 화면 알림만으로 계약을 확정하지 않습니다.

품목·수량·픽업별 배분·배송지가 충분하지 않은 계약은 이유를 표시하고 보류합니다. 유형 ID만으로 모든 실행 계약의 명세를 확정하지 않습니다. 공개 목록의 범위와 게임 빌드도 별도로 확인합니다.

## 설정과 기록 보존

기존 Firebase 로그인·설정·운항 기록 동기화를 유지합니다. 신규 적재 상태·계약 선택·안내 구간·지급 기록·입력 초안은 계정별로 **현재 브라우저에 보관**합니다. 새 운송 상태 전체의 자동 기기 간 동기화는 아직 아닙니다.

상단 **백업·복원**에서 현재 계정의 설정과 구조화된 운송 기록을 파일로 보관할 수 있습니다. 복원은 대상 기록을 교체하므로 먼저 현재 백업을 저장하세요. 원문 로그·로그인 정보·연결 키는 포함하지 않습니다. 다른 브라우저에서는 같은 계약을 다시 읽어야 하며 백업만으로 실제 게임 상태를 생성하지 않습니다.

앱 업데이트는 이전 실행기를 종료하고 새 ZIP을 별도 폴더에 풀어 실행하세요. 같은 PC·브라우저·기본 로컬 주소에서 기록을 이어 사용합니다. 웹사이트와 로컬 앱은 서로 다른 브라우저 저장 공간입니다. 기존 수동 플래너의 진행 중 운항을 새 로그 계약으로 자동 변환하지 않습니다.

## 출항 브리핑

이용 안내는 13장 슬라이드이며 목차·방향키·모바일 화면·관제로 돌아가기를 지원합니다. 24초 1080p 영상은 영어 화면 문구와 한글 자막, 독자적인 화물선 이미지, 합성 음악과 엔진·트랙터 빔·컨테이너 고정음을 사용합니다. 자동 재생하지 않습니다. 앱 장면은 합성 계약을 사용한 시연이며 실제 게임 검증 영상이 아닙니다.

한국어와 English 미리보기를 제공합니다. English는 주요 조작을 전환하며 일부 세부 안내·진단은 한국어가 남아 있습니다. 한국어에서도 지명·품목 등 게임 고유명은 영어를 유지합니다. 게임 로그 원문은 번역하거나 변경하지 않습니다.

## 개발자 실행

Node.js 22 이상: [공식 다운로드](https://nodejs.org/en/download). Node 22·24·26.13.0을 Windows/Linux CI에서 검사합니다. 모든 과거/미래 Node 버전의 호환을 보장하지 않습니다.

```sh
node scripts/prepare.mjs
npm test
node scripts/log-link.mjs --help
```

Windows 소스 실행은 `start-log-link.cmd`에서 Game.log를 선택하면 됩니다. 앱 ZIP 사용자는 이 과정이 필요 없습니다. `npm start`는 개발용 정적 서버입니다. Three.js·OCR 자산은 고정 출처와 무결성 검사를 통해 준비하며 원본 로그를 업로드하지 않습니다.

## 정책과 출처

선택한 로그 파일을 읽습니다. 메모리 읽기·프로세스 주입·패킷 감청·입력 자동화·게임 파일 수정·EAC 우회를 구현하지 않습니다. CIG/EAC의 공식 승인을 받았다고 주장하지 않습니다. 게임 로그 원문을 원격 서버로 자동 전송하지 않습니다.

공개 데이터는 [Star Citizen Wiki API](https://api.star-citizen.wiki/)와 각 파일의 출처·빌드를 따릅니다.

자체 코드는 [MIT](LICENSE), 외부 구성 요소와 게임 데이터는 각 권리자의 조건을 따릅니다. Star Citizen 및 관련 상표·게임 자산의 권리는 CIG 및 각 권리자에게 있습니다. 비공식 비영리 팬 도구이며 CIG와 제휴하지 않습니다.
