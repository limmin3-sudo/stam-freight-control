# 미연결 운송 기능 초안 — 2026-11-11

사용자 지시로 관제센터 전경 → 입체지도 → 적재 3D → 콘솔 구성 → 업무 연결 순서로 전환하면서 분리 보존한 초안이다. **미완성·미검증이며 현재 앱에 연결하지 않는다.**

- `tracked-changes.patch`: 작업 시작 당시 HEAD에 대한 추적 파일 변경.
- `new-files/`: 같은 시점의 새 모듈 원문(저장소 루트 기준 경로).
- 포함 범위: 수신 프로젝션/개발용 loopback 프록시, 기존 엔진 경계, 별도 운항 상태, 미션 화면 초안, 렌더러 정리 API.
- 아직 기존 ControlRoom 호출부와 새 Props가 연결되지 않았고 통합 테스트도 없다. 그대로 적용하면 완성된 기능이 아니다.
- 재사용할 때 최신 화면 설계에 맞춰 검토·통합하고 실제 계약 소유권/재개 좌표/수신 오류/저장 오류/연결 보안 테스트를 먼저 추가한다.
- 공개 앱과 기존 사용자 데이터는 변경하지 않는다.
