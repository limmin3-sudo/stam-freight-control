ZIP 전체를 새 폴더에 풀고 STAM.exe를 실행하세요. Windows ARM은 이번 배포 대상이 아닙니다. 실행기에 코드 서명이 없으므로 Windows가 경고할 수 있습니다. 보안 기능을 끄지 말고 배포 출처를 확인해 주세요.

현재 사용할 수 있는 흐름

  • Game.log 읽기 전용 연결, 계약 수신·목표 갱신·종료 기록 확인
  • 확인된 정보로 항로·적재 계획, 배송지별 공간 예약, 실제 상자 구성 직접 보정
  • 파트너별 항로, 운송 중 새 계약 합류·보관, 남은 화물 유지
  • 지도 예상 이동·관제 모드, 같은 계획의 마지막 안내 구간 선택 재개

모든 미션 유형의 자동 명세, 실제 함선 위치의 연속 추적, 운송 상태 전체의 기기 간 동기화는 아직 완성되지 않았습니다. 게임 입력·메모리·네트워크 패킷에 접근하지 않습니다. EAC 또는 CIG의 공식 승인을 받은 앱이라고 표시하지 않습니다.

업데이트와 저장된 설정

이전 실행기를 종료하고 새 ZIP을 별도 폴더에 풀어 실행하세요. 같은 PC·브라우저·기본 주소에서는 기존 로컬 설정을 사용합니다. 이전 폴더에 덮어쓰거나 게임 폴더에 넣을 필요는 없습니다.

브라우저 데이터를 지우거나 프로필·포트를 바꾸면 저장 공간이 달라집니다. 기존 지급 기록은 운항 기록 창에서 내보낼 수 있습니다. 모든 운송 데이터의 통합 백업·이전은 아직 지원하지 않습니다.
