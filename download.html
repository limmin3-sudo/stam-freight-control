배포 파일 확인

배포 페이지에서 ZIP·SHA-256·검증 결과를 확인해 주세요.

ZIP 전체를 새 폴더에 풀고 STAM.exe를 실행하세요. Windows ARM은 이번 배포 대상이 아닙니다. 실행기에 코드 서명이 없으므로 Windows가 경고할 수 있습니다. 보안 기능을 끄지 말고 배포 출처를 확인해 주세요.

현재 사용할 수 있는 흐름

  • Game.log 읽기 전용 연결, 계약 수신·목표 갱신·종료 기록 확인
  • 확인된 정보로 항로·적재 계획, 배송지별 적재 공간 가이드, 실제 상자 구성 직접 보정
  • 파트너별 항로, 운송 중 새 계약 합류·보관, 남은 화물 유지
  • 지도 항로 표시·예상 이동·관제 모드
  • 계정별 운송 상태 복원, 완료 계약·지급 기록과 같은 계획의 안내 재개

상자 개수가 없으면 배송지별 공간 가이드를 사용하고, 빠진 계약 정보는 해당 계약에서만 보완합니다.

업데이트와 저장된 설정

화면·항로·적재 기능은 사이트 업데이트로 받아 다음 앱 실행부터 적용합니다. 앱을 매번 새로 받을 필요는 없습니다. 앱 자체 업데이트가 안내될 때만 기존 실행기를 종료하고 새 ZIP을 별도 폴더에 풀어 주세요. 같은 PC·브라우저·기본 주소에서는 저장된 설정을 이어 씁니다.

브라우저 데이터를 지우거나 프로필·포트를 바꾸면 저장 공간이 달라집니다. 상단 백업·복원에서 현재 계정의 설정과 운송 기록을 파일로 보관할 수 있습니다. 다른 브라우저로 복원한 뒤에는 게임 계약을 로그에서 다시 읽어야 합니다.
