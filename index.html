좌표는 게임 데이터 스냅샷이야. 3D 지도에서 천체 크기와 표시점은 확대했으며, 퀀텀 경로선은 방문 구간을 뜻해. 천체 차폐·OM 우회·연료·전투·서버 대기열은 실시간 반영하지 않아. 게임 안에서 실제 이동 경로를 확인해 줘.

예상 시간은 설정된 평균 퀀텀 속도·우회 여유·정박·대기권 이동·상자당 작업 시간으로 계산해. 상자 크기가 스크린샷에 없으면 가정값을 사용하고, 결과에 표시해. 출발 시 기존 화물은 없는 상태야.

선택한 함선의 구역별 치수에서 상자 겹침과 최대 상자 크기를 검사해. 기본적으로 다른 수주 미션·배송지의 상자를 같은 구역에 배치하지 않아. 휴리스틱 배치이므로 배치 실패가 실제 적재 불가능을 증명하지는 않아. 실제 부착 위치·상자 접근성·무게 중심은 현장에서 확인해야 해.
