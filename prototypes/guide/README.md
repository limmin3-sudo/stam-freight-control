# 이용안내 준비 틀

사용자 지시(2026-11-05): 같은 탭의 전용 페이지, 슬라이드 형식, 모든 단계의 프레임 크기 고정. Claude 참고 구성안을 받았다. 그대로 확정한 것은 아니며 기능 오류 해결 후 검토·제안한다. [참고 구성안](../../docs/GUIDE-REBUILD-PROPOSAL.md).

- `index.html`/`guide.mjs`/`guide.css`는 비공개 준비 틀이다. `scripts/web-files.mjs` 공개 파일 목록에 포함하지 않는다.
- `guide.mjs`의 `slides` 배열에 확정된 한영 내용·단계별 동작을 넣을 수 있다.
- 확정 전에는 현재 이용안내 버튼과 안내 내용을 교체하지 않는다.
- 확정 후 루트 전용 페이지로 연결하며 브라우저 뒤로 가기와 기존 미션/운항 상태를 유지한다.
