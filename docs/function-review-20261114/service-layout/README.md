# 서비스센터 구성 및 FLIGHT CONSOLE 정리

2026-11-14 작업본. beta 2.8.0 배포 후 사용자 피드백을 반영했으며 이번 변경은 미커밋·미배포다.

- 서비스센터 첫 화면을 아카이브와 같은 카드 선택 구조로 구성했다. 계정·운송기록·피드백/오류 신고·업데이트를 선택해서 내부 화면으로 들어간다.
- 계정 내부의 중첩 프레임을 제거하고 통계를 정리했다. 수정 기록은 접어 두되 모든 조회 기록과 기존 기능을 유지한다. 내부 메뉴 이동 중 피드백 초안도 유지한다.
- 상단의 작은 계정/로그 버튼을 FLIGHT CONSOLE의 두 행으로 통합했다. 계정 열기, 로그 상태 표시와 미션 화면 이동 동작을 보존했다.
- 아카이브 아래 세부 펼침만 제거했다. 큰 공간 메뉴 펼침과 아카이브 본문 자료 접근은 유지한다.

## 확인 범위

TypeScript 및 배포 빌드 통과. 프로덕션 빌드를 Chromium에서 열어 합성 계정/운송기록으로 8항목을 확인했다(`checks.json`). 390px 화면의 가로 넘침과 터치 영역, 계정 창 열기/닫기, 로그 이동, 운송기록 보존, 30개 수정 기록 접기/펼치기와 내부 프레임 제거를 확인했다. 브라우저 오류 없음.

실제 Firebase 계정·실시간 게임 로그 연결을 이번 검증에서 사용하지 않았다. 이전 릴리스 전체 테스트를 이번 변경의 재실행 결과로 포함하지 않는다. 캡처는 테스트 계정이다.
