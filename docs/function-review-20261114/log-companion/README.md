# 로그 연결 앱 개편 — 2026-11-14

**후속 마감:** [설치 EXE 생성·설정 보존·재실행 개선](INSTALLER-FINISH.md)을 완료했다. 아래의 설치 EXE 미생성 기록은 이 후속 결과로 갱신된다. 실제 Windows 최종 검증/배포는 아직이다.

기능 클라우드 / `integration/freight-division-20261113`, HEAD `916b067` 위 기존 미커밋 작업 보존. 사용자가 로그 앱 재개와 테마·폰트·구성 변경을 승인했고, 실행 아이콘은 STAM 로고 하나로 통합하도록 확정했다. 버전은 개발용 `app.1.4.0`. **커밋·푸시·배포 없음.** 공개 다운로드 메타데이터는 기존 릴리스 그대로다.

## 실제 구현

- `desktop/Launcher.cs`: STAM 중심/FREIGHT DIVISION 보조 브랜딩, 청록 투사 유리 패널·금색 주 동작, Barlow Medium 500·SUIT Medium 500. 연결 상태/읽은 MB/최근 확인 시각 → 감시 로그 → 미션콘솔 열기 순서. 한국어/영어, 키보드 포커스, 파일 경로 툴팁. 실제 Windows Forms UI이며 웹 이미지를 씌운 시안이 아니다.
- 실행 파일·작업표시줄·트레이·설치 파일에 원본 STAM 로고 `desktop/stam.ico` 적용. PNG 비율을 유지한 16~256px 투명 아이콘. 사용자는 `STAM.exe` 하나만 실행하며 Node/bridge를 따로 실행하지 않는다. 설치 시 STAM 바로가기를 제공한다.
- 지난 선택 경로 자동 연결. 일반 설치 경로의 제한된 탐색으로 유일한 LIVE 로그 자동 선택. LIVE 설치가 여러 곳이거나 PTU/EPTU만 있으면 직접 선택 안내. 로그가 일시적으로 없어져도 기존 경로를 기다리며 다른 채널로 임의 전환하지 않는다.
- 창 X는 트레이로 숨김, 트레이 열기/미션콘솔/앱 종료. 프로세스 종료 후 지수 지연 재연결, 명시 중지 시 재시도 중단. UTF-8 표준 출력을 지정해 한글 경로 보존. 게임 파일은 읽기 전용.
- `desktop/bridge.mjs`의 stdio 상태 전달. HTTP 주소·Origin·preflight·프로세스별 토큰 보안 규칙 유지, 외부 파일 선택/제어 API 추가 없음. 상태에는 로그 본문·플레이어 ID를 넣지 않는다.
- 새 `use-log-receipts.ts`에서 기존 `connectLive` 사용. 공개 HTTPS 미션콘솔이 먼저 열려 있어도 자동 연결. 앱 재시작/토큰 교체·탭 새로고침 복구. 기존 Worker에서 동일 SCMDB/Wiki 보완·실제 수량·변경 알림 규칙 사용. 미처리 스냅샷은 최신 하나로 합쳐 Worker 대기열 누적 방지.
- 수신함은 기존 탭 보관/수동 보완 규칙 유지. 초기 revision 0·읽는 중인 부분 스냅샷으로 저장 수신함을 비우지 않는다. 앱 중단 시 마지막 수신 기록 보존. 파일 직접 가져오기/브라우저 감시는 그대로 남고 사용자가 전환하면 이전 입력을 종료해 결과 경합 방지.
- `desktop/installer.iss`: 관리자 권한 없는 사용자 설치, STAM 바로가기, 기존 경로/언어/브라우저 운항 보존. 기존 ZIP 배포 구조도 유지. `build-windows.ps1`에서 실제 Windows 컴파일/언어 검사/수신 self-test/KO·EN 캡처 후 ZIP 및 설치 EXE를 만들도록 연결.

## 검증

- 루트 테스트 **269**, 앱 테스트 **88**, 타입 검사·생산 빌드 통과. 추가된 동작은 자동 발견 모호성, 실제 stdio/API의 파일 생성 대기·추가 수주·읽기 전용·부모 종료, 글꼴 포함 패키징이다.
- 실제 Chromium HTTPS origin + 실제 loopback API + 실제 React Worker, 합성 수주 로그로 확인: 페이지 선행 실행, 로그 생성 대기, 8/4/4 SCU 자료 보완, 추가 수주, 운항 불변, 오프라인 기록 보존, 앱 토큰 교체, 새로고침, 명시 중지, 파일 가져오기 전환, 재연결, 영어 390px. 빈 로그로 앱을 재시작한 revision 0이 기존 수신함을 지우지 않는 회귀도 확인했다. 웹 요청으로 토큰 누출/페이지 오류 없음. [보고서](browser-report.json), [연결된 미션콘솔](mission-app-connected.png).
- 실제 C#를 Mono로 Windows x64 GUI 실행 파일로 컴파일했다. Mono/Linux의 실제 Windows Forms 화면에서 한글/영어 렌더링과 언어 전환 self-test, 실제 Node 자식 프로세스 self-test(계약 추가·읽기 전용·인증 API)를 확인했다. [실제 앱 코드 캡처 — Mono/Linux](companion-ko-mono.png). Windows 화면 캡처나 Windows 실행 검증으로 오해하지 않는다.
- 임시 Windows 시험 ZIP은 `dist/STAM-app.1.4.0-review-win-x64.zip`. 공식 Node 22.23.4 Windows x64 ZIP의 기존 고정 SHA256을 확인했고 파일별 해시/ZIP 무결성을 검사했다. `PACKAGE.json`에 교차 컴파일·Windows 미검증·미커밋 작업임을 명시했다. 배포 산출물/서명된 설치본이 아니다.

## 남은 범위

Windows 실제 실행, 트레이의 Windows 동작, 설치/업그레이드/제거, 125~200% DPI, 실제 설치 경로의 자동 탐색, 실제 게임 실시간 수신은 미검증이다. Inno Setup 설치 EXE는 Windows 빌드 경로까지 구현했으며 이 Linux 환경에서 생성·실행하지 않았다. 사용자는 실게임 검증을 당분간 못 한다고 했으므로 완료로 대체하지 않는다.

승인 후 커밋된 소스로 Windows 패키지 워크플로를 실행하여 위 범위를 확인하고 릴리스를 게시한다. 현재 공개 다운로드와 사이트에는 이 변경을 자동 게시하지 않는다. 시험 ZIP의 미션콘솔 열기는 공개 사이트로 이동하므로, 새 미션콘솔 자동 수신 기능을 일반 사용자가 쓰려면 이 웹 변경도 함께 배포해야 한다. 브라우저의 로컬 네트워크 접근 허용은 첫 연결에서 필요할 수 있다. 웹/앱 자동 업데이트는 별도이며 기존 공개 웹 갱신 구조를 유지한다.
