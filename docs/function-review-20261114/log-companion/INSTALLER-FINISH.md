# 설치형 앱 마감 — 2026-11-14, 미배포

이 문서는 이전 README의 “설치 EXE 미생성” 상태를 갱신한다. 실제 Windows 최종 검증을 완료했다는 뜻은 아니다.

## 변경

- 같은 STAM 아이콘을 다시 실행하면 프로세스별 창을 더 만들지 않고 현재 창을 복원한다. 세션 내 명명된 이벤트로 원래 UI 스레드에 알리며, Windows에서는 같은 실행 파일의 기존 프로세스에 전경 활성화 권한을 전달한다. 이전 버전이 이벤트를 지원하지 않거나 시작에 실패한 경우에만 기존 안내 메시지를 유지한다.
- 실제 폼의 닫기 → 트레이 유지 → 창 복원 → 명시 종료 → 재실행을 검사하는 `--self-test-window`를 추가했다. 임시 설정 폴더와 한글 파일명의 합성 로그만 사용하며 실제 사용자 설정을 건드리지 않는다. 수신 프로세스 중복/종료 후 잔존, 로그 읽기 전용, 언어/경로 보존을 검사한다.
- 사용자 설치 EXE를 실제 생성했다. STAM 로고를 사용하며 바탕화면 STAM 바로가기 하나와 같은 실행 파일을 가리키는 시작 메뉴 항목을 만든다. 관리자 권한/별도 Node 설치가 필요 없다. 기존 AppId와 설정 경로를 유지한다.
- 빌드 시 Inno Setup 7.1.1 x64를 공식 릴리스의 고정 SHA256으로 검증해 준비한다. 러너에 우연히 설치된 컴파일러 버전에 의존하지 않는다.
- `check-installer.ps1`은 깨끗한 Windows 빌드 프로필에서 설치·실제 앱 실행·두 번째 아이콘 실행·업데이트·제거·설정 보존을 검사한다. 기존 STAM 설치나 설정이 있으면 변경 전에 중단한다.
- 향후 게시 스크립트는 ZIP과 설치 EXE 양쪽의 URL/용량/SHA256을 확인하고 함께 게시한다. 기존 ZIP 전용 릴리스도 호환된다. 릴리스 안내의 “닫으면 연결 종료”를 트레이 동작에 맞췄다. **게시 스크립트를 실행하지 않았으며 공개 다운로드 메타데이터는 바꾸지 않았다.**

## 이번에 확인한 범위

1. Mono/Linux: C# x64 컴파일, 실제 폼의 한글 경로 자동 연결·닫기·복원·같은 watcher PID 유지·종료·설정 복원 통과.
2. Wine 10: 공식 Inno 컴파일러로 실제 Windows x64 설치 EXE 생성. 실제 설치된 34개 파일의 SHA256이 패키지와 일치.
3. Wine 10: 같은 설치 EXE로 재설치 후 로그 경로/언어 보존, 바탕화면 STAM 아이콘 1개 유지. 실제 제거 후 앱/바로가기 삭제, 두 설정 파일 보존.
4. 변경 관련 Node 테스트 5개, JS 구문 및 Python 구문 검사 통과. 전체 웹 테스트를 불필요하게 다시 반복하지 않았다.

[기계 판독 검증 기록·산출물 해시](installer-check.json)

실제 Windows에서의 두 프로세스 간 창 활성화·트레이·DPI, Windows PowerShell 검증 스크립트 전체 실행, 실게임 수신은 남았다. Wine 설치 확인을 실제 Windows 확인으로 대체하지 않는다.

## 시험 산출물

- `dist/STAM-app.1.4.0-review-setup-win-x64.exe`: 설치형 시험본.
- `dist/STAM-app.1.4.0-review-win-x64.zip`: 갱신된 휴대형 시험본.
- `dist/STAM-app.1.4.0-review-SHA256.txt`: 두 파일의 체크섬.

미서명·미게시 개발본이며, `PACKAGE.json`에 교차 컴파일/미커밋 작업/Windows 미검증 상태를 표시한다. 설치기는 이 검토용 패키지의 동일 파일을 포함한다. 앱의 미션콘솔 버튼은 공개 사이트로 이동한다. 새 React 미션콘솔의 자동 수신은 해당 웹 변경과 함께 배포해야 일반 사용자가 사용할 수 있다. 현재 작업으로 사용자 계정/운항·공개 사이트·Git 원격을 변경하지 않았다.
