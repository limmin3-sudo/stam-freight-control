# 지도 표현 보강 — 2026-11-14

기능 클라우드 / `integration/freight-division-20261113`, 배포 기준 `916b067` 이후 작업본. 서비스센터/FLIGHT CONSOLE 기존 미커밋 변경을 보존했다. 이번 작업은 지도 표현이며 적재 3D는 변경하지 않았다. 커밋·푸시·배포 없음.

## 변경

- 화면 해상도에서 계산하는 배경의 큰 얼룩을 길게 겹치는 성간 먼지층으로 정리했다. 스탠턴 청색·파이로 구리/주황·닉스 청록, 원거리 별, 카메라 회전 시 방향 고정은 유지한다. 저해상도 파노라마 확대는 사용하지 않는다.
- 공통 암석/가스 표면을 쓰는 천체에 기존 `BODY_LOOK`의 개별 팔레트를 적용한다. 기존에는 같은 분류의 공통 색만 사용했다. 밝은 얼음 색에서도 원래 표면의 명암을 남긴다. 전용 텍스처가 있는 주요 행성의 원본은 유지한다.
- 높은 화질의 가까운 지표에서만 작은 표면 변화를 추가하고, 픽셀보다 작아지면 줄인다. 가스 행성에는 암석 표면 입자를 넣지 않는다. 눈 밝기를 높이 지도로 잘못 사용하지 않는다.
- 대기 가장자리의 색과 표면이 섞이는 방식을 조정했다. 홀로그램의 투과도와 명암을 조정하되 위경도 격자·와이어프레임을 넣지 않았다.
- 홀로그램 항성에 쓰던 구름 마스크 구체를 사용자 승인 플라스마 이미지로 통일했다. 기본 실사 항성 이미지는 교체하지 않았다. 반려된 `celestial/plasma.png`는 사용하지 않는다.
- 기존 지도 좌표·카메라·검색·경로 계산·방문 순서·선적은 수정하지 않았다. 금색 선택 강조와 경로선 유지.

## 품질/성능 경계

새 대형 이미지나 후처리 bloom, 추가 렌더 패스를 넣지 않았다. 근접 표면 변화는 화질과 화면상 크기에 따라 생략된다. CPU/GPU 실물 성능 개선 수치를 주장하지 않는다.

표면은 기존 생성 이미지/설정 팔레트에 기반한 시각적 근사이며 게임에서 추출한 지형이 아니다. 원본은 1774×887이고 이번 작업을 4K 원본 제작/업스케일링이라고 부르지 않는다. 원본 추가 제작과 실제 GPU 장시간 측정은 별도 잔여다. 실사/홀로그램 모드는 기존 비교 URL을 유지하며 모드 선택 메뉴는 임의 추가하지 않았다.
