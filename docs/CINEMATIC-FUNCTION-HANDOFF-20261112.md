## 반드시 유지할 사용자 기준

1. **큰 패널 하나.** 오른쪽 가이드와 기존 승인 영상을 유지하고 왼쪽의 큰 프레임 안에 왼쪽 메뉴·오른쪽 대화. 모바일도 외곽 프레임은 하나.
2. 실제 배경이 비치는 청록 유리, 얇은 입체 발광 경계. 호박빛 모서리/구분선 포인트를 없애지 않는다. 선택 버튼은 테두리뿐 아니라 면 전체에 호박빛을 준다.
3. 글씨와 조작은 실제 HTML/버튼으로 유지하고 기존 ID·이벤트·데이터·내비게이션 연결을 보존한다. 플라이트 가이드·브리지 오퍼레이터·수석 항해사는 공통 재질/타이포 기준을 쓴다.
4. 기준 사진은 `docs/cinematics/lounge-guide/lounge-guide-hologram-ui-v1.png`. 사진의 재질을 기준으로 하되 사진의 두 패널 배치를 복제하라는 뜻이 아니다. 원본 그림의 글씨는 생성된 픽셀이며 정확한 원본 폰트 파일을 찾지 못했다.

## 검증과 남은 일

최종 인계 상태에서 TypeScript/Vite 빌드와 앱 테스트 12개 파일이 통과했다. 기존 500kB 번들 크기 경고는 유지된다. 실행 코드가 기준과 동일하므로 전체 운항 테스트를 새로 통과했다고 보고하지 않는다. 새 자산 RGBA/치수/alpha/해시는 확인했다. 반려 시안 당시 메뉴/대화/복귀/모바일 검사가 통과했더라도 그 결과로 새 자산 적용 완료나 시각 승인이라고 주장하지 않는다. 새 자산은 미연결이므로 실제 영상 위 가독성·크기 변경·실물 모바일/GPU 검수가 남아 있다.

내일 순서:

1. 기능 담당의 배포 완료 SHA를 받고 공유 파일 변경을 대조한다.
2. 새 생성 자산을 별도 연출 브랜치에서 큰 통합 패널 하나에 연결한다. 투명도와 호박빛을 독립 제어하고, 원본 사진과 실제 영상 위에서 비교한다.
3. 사용자 외형 확인 후 기존 버튼/영상/복귀/모바일 회귀를 검증해 기능 담당에게 새 PR로 넘긴다.
4. 파트너 선택 최종 연출은 **2.5D 관제센터에 서 있는 인물 클릭** 방식이다. 현재 큰 초상화 카드는 임시이며 이번 인계에서 구현하지 않는다.
5. 서비스센터·정보실·영상관 마지막 프레임은 해당 실제 화면으로 제작. 게이트 가이드 에스코트 재제작, 이륙·우주/스테이션 이동·최종 음향은 후속 연출이다.
