# 입체지도 천체·항성계 배경 재질

2026-11-12 · Codex · feature/mission-console-screen · 로컬 검토본, 배포 없음

## 항성 버전 정정 — 현재 상태

개편 전 표현 복구는 사용자가 요청한 버전이 아니었다. 현재는 개편 후 `hologram-scene.ts`에서 사용하던 `assets/stellar-plasma.png` 금빛 필라멘트 자산을 다시 연결한다. `starObject`로 정면 VFX 스프라이트를 만들며 실제 3D 위치·표시 반지름·기존 지도 조작을 사용한다. 구체 표면 시뮬레이션이라고 주장하지 않는다. 개편 전 셰이더와 이번 반려된 튜브 홍염은 이 지도에서 사용하지 않는다.

## 직전의 잘못된 복구 기록

사용자가 생성 질감 기반 항성을 반려했다. 해당 항성 셰이더·튜브 홍염을 제거하고 기존 `mapfx.mjs`의 `starMaterial`과 `starCoronaMaterial`을 그대로 복구했다. `plasma.png`는 보존한 반려 원본이며 실행 시 읽지 않는다. 현재 사용 질감은 9개다. 아래 최초 적용·검증 기록의 생성 항성 부분은 과거 상태다.

## 실제 연결

`NavigationChart` → `chartAppearance` → `createCelestialMaterials`로 생성한 PNG 질감을 기존 `starmap.mjs`의 회전 가능한 구체에 연결한다. 이전 완성 구체 이미지를 평면으로 붙이는 방식이 아니다. 관제 화면도 같은 지도 어댑터를 사용한다. 기존 방 연출·이동 영상과 경로·적재 계산은 이번 범위에서 변경하지 않는다.

- Hurston / microTech / ArcCorp / Crusader: 독립적인 펼친 표면 이미지 4개.
- 다른 암석/얼음/사막 천체: 공용 암석 질감에 기존 천체 종류의 색상과 이름별 UV 오프셋을 적용한다. 다른 가스 행성은 가스 질감을 공유한다. 모든 천체가 독립 원본을 갖췄다고 주장하지 않는다.
- 구름: 흑백 커버리지 이미지와 별도 구체. 표면과 같은 시간 오프셋으로 이동하며 표면에 근사 구름 그림자를 적용한다. 사용자 동작 줄이기 설정이면 애니메이션이 멈춘다.
- 대기: 얇은 별도 셸, 실제 표시 좌표의 항성 방향을 이용한 산란 근사. 게임의 물리 대기를 정밀 시뮬레이션한 것은 아니다.
- 항성(현재): `assets/stellar-plasma.png`를 실제 3D 위치의 정면 VFX 스프라이트로 표시한다. 위의 최신 버전 정정을 따른다. 펼친 플라스마 표면과 튜브 홍염은 반려된 이전 구현이며 사용하지 않는다. 전역 bloom은 계속 꺼 둔다.
- 스탠턴/파이로/닉스: 각각 파랑/호박빛/청록의 별도 성운 이미지. 색만 바꾸는 공용 이미지가 아니다. 파노라마에는 별을 제거하고 별 6,500개를 별도 점으로 그린다. 배경은 무한 거리의 방향 광선으로 계산해 회전 시 변하고 이동 시 시차가 생기지 않는다.

## 자산·범위

`apps/control-room/src/assets/celestial/manifest.json`에 원본 생성 출처, 실제 픽셀 크기, 파일 크기와 SHA-256을 기록했다. 현재 소스는 각 1774×887 픽셀이다. 4K/8K 원본이나 게임 추출 지형이라고 표시하지 않는다. 생성된 표면은 예술적 표현이며 거점의 게임 좌표와 일치하는 지리 지도가 아니다. 기존 위치·경로·거리 데이터는 그대로 사용한다.

경도 이음새는 좁은 구간에서 셰이더로 혼합한다. 극점 늘어짐과 극단적인 확대에서의 원본 해상도 한계는 남는다. 눈이나 해안선의 색을 높이로 해석하는 범프는 제거했다. 실제 높이/법선 데이터가 없으므로 가짜 높이 정확성을 주장하지 않는다. 텍스처는 어댑터 내부에서 공유·재사용하고 파노라마는 해당 항성계 진입 때 읽는다. 종료 시 GPU 텍스처를 해제한다.

## 검증

- `npm test`: 232개 통과. 로컬 HTTP 서버를 여는 테스트에는 네트워크 허용 실행이 필요했다.
- `npm run test:control-room`: 42개 통과.
- `npm run build:control-room`: TypeScript/Vite 통과. 기존 큰 JS chunk 경고는 남아 있다.
- `node scripts/check-navigation-browser.mjs`: 지도 회전/우클릭/Shift 이동/휠, 위성 탐색, 항성계 이동, 구간 선택, 상자 선택·소유권, 미리보기의 운항 상태 보존, 언어, 모바일, 관제 지도 및 화물 카메라 유지 통과.
- `node scripts/check-celestial-occlusion.mjs`: 배경 별이 실제 렌더링된 473픽셀을 확인한 뒤 불투명 전경으로 가렸을 때 밝은 픽셀 0개를 확인했다. 별의 깊이 검사를 끄면 실패하는 검증이다.
- `node scripts/capture-celestial-review.mjs`: 실화면의 항성계 3개·천체 확대 4개, 자산 10개 응답과 WebGL/셰이더 오류를 확인하는 재현 스크립트. `STAM_MISSION_URL`, `STAM_QA_OUTPUT`, `STAM_PLAYWRIGHT_MODULE`, `STAM_CHROMIUM`으로 환경을 지정한다.

브라우저 기능 검증은 소프트웨어 GPU·0.5 DPR이며, 시각 캡처는 1600×1000·1 DPR이다. 실제 사용자 GPU 성능 검증을 대체하지 않는다.

최종 캡처 검증: 자산 10개 모두 응답, 셰이더/페이지 오류 0개, 세 항성계와 천체 확대 4장 캡처 완료. Vite의 이미지 모듈 요청과 원본 PNG 요청은 쿼리를 제거해 같은 자산으로 집계한다. 마지막 별 가림·항성 밝기/홍염 수정 이후 다시 캡처했다.
