## 매 기능 도입 전 필수 질문

**각 단계 시작 전에 사용자에게 설명하고 답을 받은 뒤 구현한다.** 이전의 포괄적 개발 승인을 다음 기능 도입 승인으로 해석하지 않는다.

1. 이번에 가져올 기능과 사용 흐름을 구체적으로 보여준다.
2. 기존3.8의 어느 화면·버튼·조작·저장 형식을 유지하는지 설명한다.
3. 바꾸거나 없애려는 것이 있으면 항목별로 묻는다. 암묵적으로 대체·삭제하지 않는다.
4. 사용자가 유지/변경/제외를 결정하면 이 표의 승인 기록에 남긴다.
5. 기능 하나를 연결하고 기존 동작과 새 흐름을 검사한 뒤 결과를 보여준다. 다음 기능 전에 다시 묻는다.

화면상의 작은 동작도 기준에 포함한다: 관제 모드 비율과 복귀·포커스, Space/Enter, 지도 단독 보기/상단 시점/거점 카드/목록 접기, 화물 필터·작업 전후·막는 상자 강조, 개인 메모, 파트너 말투/소개, 그리드 선택과 카메라. 원본 코드·작업 이력에서 직접 찾으며 사용자에게 모두 다시 떠올리게 하지 않는다.

## 후속 승인 — 계약 수신함·언어·오퍼레이터

- 앱/사이트 업데이트를 분리하고 로그 계약을 수신함 카드에 모은다. 카드 클릭 → 원래 미션 편집창 → 사용자 확인·저장 순서다. 자동 계획 삽입은 하지 않는다.
- 스크린샷·AI 글·직접 입력은 보조로 유지한다. 출발지 선택 후 「정말 여기서 출발할까요」 단계만 제거한다.
- 지명·품목도 새 AI 한국어로 표시한다는 사용자 답변 확정. English는 영문 이름, 내부 식별자는 그대로 유지한다.
