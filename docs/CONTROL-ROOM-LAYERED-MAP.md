## 2026-11-11 최신 수정 — 궤도와 시설 복구

이 절이 아래 이전 구현 기록보다 우선한다. 궤도는 기본 ON이다. `systemPoints`는 Star/Planet과 모든 Manmade 계열 시설을 제공하며 스탠턴 47시설(라그랑주 정거장 18), 파이로 13, 닉스 20이 연결됐다. 라그랑주 정거장과 항성 직속 시설을 항성 표면 근처로 당기지 않고 원래 항성계 좌표로 배치한다. 위성 소속 시설은 원본 위성→행성 계보를 따라 표시용 행성 밖에 배치한다. 위성 구체 자체를 추가한 것은 아니다.

`displayPositions`는 원본 좌표를 변경하지 않는 순수 표시 계산이며 회귀 테스트에서 시설 누락·항성 직속 정거장의 잘못된 축소·행성 내부 시설 배치를 검사한다. 목록 검색은 한국어/영어 이름과 HUR-L1 같은 코드를 지원한다. 전체 지도에서는 라그랑주 코드 표기, 선택/확대에서는 전체 이름을 표시한다. 아이콘과 이름이 멀리 떨어지지 않도록 겹치는 보조 이름을 숨기고 커서/선택에 우선권을 준다. 통신시설은 확대 시 표시하며 목록으로 항상 접근할 수 있다.

행성 표면에 카메라 방향의 약한 보조광을 적용해 밤쪽의 색/지형을 보존했다. shared `mapfx.mjs`의 기존 앱은 수정하지 않았다. 관제센터의 원경 지도 크기/투사광/이름 숨김, 승인 항성·배경·왼쪽 메뉴는 유지한다.

정거장 표식은 사용자 재지시에 따라 전체가 청백색 빛으로 이루어진 반투명 입체 홀로그램이다. 링과 중앙 타워, 네 연결 통로가 있으며 선택/커서 접근 시 1.3배 강조한다. 기본 크기 26 CSS px, 통신시설 16 px. 생성 자산 `station-hologram.png`와 additive sprite를 사용하며 자유 회전 가능한 정거장 3D 모델은 아니다. 기존 금속판 정거장 아이콘 시안은 폐기한다.

확대/축소는 휠·핀치·왼쪽 버튼에서 최소 0.7, 최대 9로 제한한다. `시점 초기화`는 초기 중심·시선 방향·배율 1로 복원하고 잔여 회전 관성도 해제한다. 선택 대상은 유지한다. 실제 계약 계산/운항 상태 등 기존 업무 기능은 유지 대상이지만 새 화면에 아직 전부 연결하지 않았다. 기능 삭제가 최종 디자인 요구사항으로 해석돼서는 안 된다.

- 최종 검증: 빌드·미리보기 테스트 8파일·전체 회귀 231개 통과. Chromium에서 스탠턴 47/파이로 13/닉스 20시설, 라그랑주 검색·선택, 궤도 ON/OFF, 동일 canvas와 저장 데이터 유지, 모바일 검색·넘침 없음 확인. 확대 9/축소 0.7 한계, 회전 후 초기 중심·방향·배율 복원과 휠 제한도 확인했다. 페이지/셰이더 오류 없음. 기존 큰 번들 경고 유지.

## 현재 구현과 범위

별도 React 미리보기에서 관제센터 전경과 항로 화면이 **같은 WebGL 캔버스/장면/천체 선택 상태**를 사용한다. 중앙 지도를 선택하면 캔버스 표시 영역이 늘어나고 주변에 지도 UI가 나타난다. 돌아오면 같은 장면이 테이블 위 영역으로 줄어든다. 확대 중 회전·선택 대상 확대가 가능하며 복귀할 때 전체 항성계 시점으로 부드럽게 복원한다. 기존 자유 이동 3D 방 모델과 별개다.

- 전경: 원본 `control-room-empty-seats-reference.png`는 수정하지 않았다. 지도 제거·안쪽 빈자리 직원 추가·좌우 바깥자리 직원 제거를 수행한 새 `control-room-clean-plate.png`를 SVG 마스크 영역에만 덮는다. 마스크 밖은 원본이다. 편집 영역 내부까지 원본과 픽셀 단위 동일하다고 주장하지 않는다.
- 인물: 기존 승인 자산을 재사용. 오퍼레이터는 가로 32%, 항해사는 68%, 둘 다 세로 43% 시작·높이 43%로 배치했다. 지도와 테이블의 중앙 통로를 확보한다.
- 선택 원: 미션 콘솔은 `(6.5%,73%)`, 관제 콘솔은 `(95.4%,74%)`, 중앙 지도는 `(50%,57%)`. 좌우 원은 빈 의자 아래 바닥에 놓인다. 화면 비율에 맞춰 같은 위치를 유지한다.
- 실제 지도: 별도 `StantonHologram`/`hologram-scene` 레이어. 카메라 전환, 인물 이동, 천체 크기 조절은 배경 재생성 없이 코드로 수행한다.
- 천체 크기: 항성 반지름 `.40`, 크루세이더 `.28`, 나머지 `.22–.25` 표시 단위. 항성이 모든 행성보다 크지만 과도하게 중심을 채우지 않도록 했다. 실제 크기와 궤도 거리를 같은 축척으로 그린 도표는 아니다.
- 좌표·ID: 기존 `log-location-index.json`의 스탠턴 항성·4행성·4주요 정거장 값을 사용한다. 정거장 아이콘은 과장된 행성 표면 밖으로 표시만 옮기며 원본 좌표를 바꾸지 않는다. 근접 간격·크기는 화면에서 설명한다.
- 표면: 생성한 `stanton-surface-atlas.png`를 4개의 UV 영역으로 나눠 실제 구체에 매핑한다. 게임 공식 표면 텍스처나 실제 지형 고증 완료본이 아니다. 전용 표면 shader에서 명암 경계·표면 미세 대비·해양 반사·아크코프 야간 발광을 처리한다. 행성의 대기·구름 shader를 사용하며 bloom은 사용하지 않는다. 항성 표현은 아래 VFX 자산으로 교체했다.

## 최신 시각 구성 — 사용자 반려 후 재구성

- 라운지/관제센터 공통 메뉴와 지도 탐색은 `space-main`의 왼쪽 독립 열이다. 오른쪽 사이드바와 UI 프로젝터 하드웨어·하단 아이콘 메뉴는 폐기했다. 모바일도 왼쪽 좁은 열 안에서 스크롤한다. 하단 footer는 비었다. 기존 미션/운항 콘솔 내부는 별도 컴포넌트이며 이 개편 완료 범위가 아니다.
- `hologram-button.png`는 투명한 청색 유리 버튼 이미지이고 아이콘이나 글자가 없다. 실제 클릭/키보드 포커스/번역 텍스트는 DOM이다. 설정도 왼쪽 메뉴에 있다.
- 항성은 사용자 승인 금빛 필라멘트 참고를 토대로 제작한 투명 `stellar-plasma.png`를 사용한다. 3D 중심에 카메라 정면 스프라이트를 놓고 보이지 않는 구체로 선택을 처리한다. 회전 가능한 구체의 실시간 플라스마 표면이나 물리 시뮬레이션이 아니다. 고품질 정지 VFX 자산이며 재질/자산을 별도로 교체할 수 있다.
- `hologram-projection.ts`는 관제센터 원경에서 중앙 받침대로부터 위로 퍼지는 푸른 빔을 그린다. UI 프로젝터 제거와 별개로 유지하는 지도 테이블의 투사광이다. 확대 지도에는 표시하지 않는다.
- `hologram-catalogue.ts`에서 스탠턴 파란색, 파이로 호박색, 닉스 청록색을 정의한다. `log-location-index.json`의 Star/Planet ID·좌표를 보존하고 표시 좌표/크기만 조정한다. Pyro IV는 Pyro V와 화면상 구별되도록 표시 위치를 이격한다. 정거장 표시는 현재 스탠턴 주요 4곳만 지원한다. 파이로/닉스 표면도 공식 지형 고증 완료본이 아니다.
- 원경은 천체 이름이 보이지 않는다. 펼친 지도 이름은 넓은 자간의 Oxanium/SUIT 텍스트와 약한 발광으로 표시하고 직사각형 상자를 제거했다. 제목은 STAM 라운지 / STAM 관제센터를 유지한다.
- 이전 장식 선택 링·정거장 모델은 제거했다. 정거장은 작은 입체 점 표식이다. 기본 궤도 OFF, 사용자가 켜면 얇은 선으로 표시한다. 라그랑주 거점은 아직 추가하지 않았다.
- `hologram-route.ts`는 표시 공간에서 천체 회피만 담당한다. 원본 위치·운송 계산에는 영향을 주지 않는다. 새 경로는 일정한 두께의 중심선+부드러운 광선이고 반복 펄스·튀어나온 화살표는 없다. 현재 토글은 스탠턴 포트 트레슬러→바이니 포인트의 표현 예시이며 실제 계약 연동이 아니다.
- 같은 canvas를 계속 유지하며 항성계 변경 시 내부 천체만 교체하고 자원을 정리한다. 관제센터로 돌아오면 스탠턴을 보여준다. 30fps 제한, 화면 밖/숨겨진 탭 정지, DPR 상한 1.75. 동작 줄이기 대응.
