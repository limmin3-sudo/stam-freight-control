# STAM FREIGHT DIVISION 상위 시설 메뉴

2026-11-16 · 승인 v6 제품 연결 · 로컬 미리보기 / 미배포

## 최신 구현

장소 표식은 최신 사용자 승인으로 기본 샴페인 골드, 커서/키보드 강조는 백금빛으로 변경했다. 점·선·명칭이 함께 강조되며 요약은 아이보리다. 라운지/관제센터에도 동일 적용. [실제 화면 검증](gold-label-review/report.json).

시설 명칭은 사용자 확정에 따라 **아카데미 / Academy**로 통일했다. 아래 요약은 **운송 팁 · 노하우**. 라운지 안내데스크와 구분하며 기존 `guide-center` 경로/시설 ID는 호환성을 위해 유지한다.

사용자가 v6를 승인해 시작 화면으로 연결했다. 아래 과거 시안의 승인 대기 표시는 당시 기록이다.

- 시설 4곳은 점·안내선·이름으로 표시한다. 커서를 올리면 주변이 어두워지고 건물은 밝게 유지되며 이름은 금빛으로 강조된다. 공사 부지 2곳은 배경에만 남고 명칭·버튼·설명은 없다.
- 라운지/관제센터는 기존 기능으로 연결한다. 무역센터/아카데미는 준비 중 패널이며 실제 센터 기능 완성으로 표시하지 않는다.
- 큰 사이드바 메뉴는 기본 접힘이며, 직접 눌렀을 때 이동/펼침을 수행한다. 무역센터·아카데미도 동일한 기존 재질의 큰 메뉴로 추가했다.
- FLIGHT CONSOLE은 함선·파트너·미션 수만 요약한다. 기존 커서/키보드 상세정보와 클릭 고정은 보존했다. 로그인·게임 로그 상태는 승인 유리 에셋을 사용하는 상단바 버튼으로 이동했다. 기존 계정 창과 로그 입력 기능을 재사용한다.
- 옛 라운지 준비 영상은 시작/라운지 진입 모두 폐기했다. `main.tsx`에서 OpeningFilm 연결을 제거했고 소스는 과거 제작 이력으로만 남겼다. 다른 투어·이동 영상은 유지한다.
- 패널과 상단바는 승인 PNG 재질 시트를 CSS로 표시한다. 배경은 승인 원본 1672×941이며 4K 또는 독립 3D 건물이라고 주장하지 않는다.
- 시설 ID·좌표·클릭 윤곽·선택 이미지 레코드를 분리했다. 현재 각 시설 레이어는 같은 전경을 잘라 표시한다. 향후 건물 교체에는 기존 건물을 덮는 정렬된 전경 패치가 필요하며 실제 3D 모델 분리가 아니다.

검증: 타입 검사/생산 빌드와 앱 테스트 24개 파일 통과. 실제 Chromium 8개 점검 그룹 통과, 페이지 오류/누락 0건. 계정 창/로그 진입·상세정보 hover·계약 보존·3언어·390px 확인. [결과](runtime-review/report.json)와 캡처는 `runtime-review/`에 저장했다. 실계정 인증·실게임 수신은 이번 UI 변경으로 새로 검증하지 않는다. 커밋·푸시·배포 없음.

## 사용자 확정

- 사이트 시작을 STAM 운송사업부로 옮기고 라운지·관제센터를 하위에 연결한다.
- 브랜드는 STAM을 크게, FREIGHT DIVISION을 하위 명칭으로 둔다.
- 라운지, 관제센터(우주 스테이션), 무역센터(명칭 잠정), 가이드센터, 확장 자리 2곳.
- 확장 자리는 공사 중처럼 표시하며 나중에 다른 시설로 교체할 수 있어야 한다.
- 최상급 실사 품질·디테일 목표. 버튼·패널은 별도 에셋을 만들어 사용자 승인 후 사용한다.
- 기존 상단바·사이드바/라운지/관제 내부·미션/관제/저장 기능을 보존한다.

## 최신 검토 — 참조 이미지 없이 완전 신규 v6

사용자가 조합 방식 대신 아예 처음부터 새로 만들라고 다시 지시했다. `facility-fresh-v6.png`는 **이미지 참조 경로와 이전 이미지 포함 옵션을 모두 생략한 텍스트 기반 신규 생성**이다. 시설 4곳·단일 링 관제 스테이션·공사 부지 2곳만 유지하고 건물 세부·배치·카메라·빛은 새로 생성했다. 사용자 승인 완료, 로컬 제품 연결·미배포. [제작 기록](fresh-v6.json). 승인 패널은 별도 자산으로 유지한다.

## 이전 검토 — v3 실사 질감·구도 + v4 건물 형태

사용자가 v3는 실사 느낌과 구도가 더 좋고, 건물 형태는 v4가 좋다고 명확히 구분했다. **v3 전체를 폐기하는 것이 아니라 구도·재질/조명의 기준으로 유지**한다. v4는 곡선형 라운지·단차형 무역센터·다각 유리 가이드센터의 형태 기준이다. 두 이미지를 역할별 참고로 제공해 전체 새 렌더링을 요청한 `facility-combined-v5.png`가 최신 후보이며 사용자 승인 대기다. 스테이션 단일 링과 공사 부지 2곳 유지. 이미지 합성 도구로 잘라 붙인 작업이 아니며 참조 이미지 기반 생성이다. 제품 미적용·미배포. [제작 기록](combined-v5.json).

## 이전 검토 — 이전 건물 구조 복귀 / 스테이션 재제안

사용자는 v3의 전체 느낌과 3개 링 스테이션을 반려하고 이전 건물 구조가 더 예쁘다고 정정했다. `facility-original-architecture-v4.png`는 건물 형태 참고 후보다. 처음 생성한 v1을 **건물 형태·구도 참고 이미지**로 제공하고 전체를 선명하게 재렌더링하도록 요청했다. 반려된 v3에 덧편집하지 않았으며, 이미지 입력 없는 text-only 생성이라고 주장하지 않는다. 실제 생성 해상도는 1672×941이다.

곡선형 라운지·단차가 있는 어두운 무역센터·다각 유리 지붕 가이드센터의 이전 형태를 기준으로 삼았다. 스테이션은 단일 항만 링·중앙 구조·도킹 암으로 재제안했다. 사용자는 3개 링을 싫다고 했으며, 단일 링은 이번 제안으로 아직 확정하지 않았다. 공사 부지 2곳 유지, 패널 승인 상태 유지. 제품 미적용·미배포. [제작 기록](original-architecture-v4.json).

## 이전 정정 — 새 원본 제작

사용자가 세라핌 또는 에버러스 하버 느낌을 요청했다. 두 공개 Wiki의 실제 참고 이미지를 확인해 긴 중심축·분리된 여러 링·도킹 암·공업 모듈을 기준으로 삼았다. 이어 사용자가 반복 편집으로 이미지가 뭉개지므로 처음부터 새로 만들라고 명시했다. 진행 중 덧편집 호출은 중단했고 해당 수정본을 채택하지 않았다.

`facility-fresh-harbor-v3.png`는 기존 이미지 입력 없이 텍스트로 **새로 생성한 원본**이다. 시설 구성과 공사 부지 2곳은 유지하되 건물 세부·구도는 새로 생성됐다. 1672×941, 사용자 승인 대기, 제품 미적용·미배포. v3는 이후 사용자 반려로 이력 보존하며 최신 후보는 v4다. 승인 패널 재질은 유지한다. [제작 기록·출처](fresh-harbor-v3.json).

## 시안 상태

- `facility-overview-v1.png`: 고정 사선 시점의 실사 전략게임식 시설 전경 제안. 빈 부지를 공사 상태로 바꾸기 전 시안.
- `facility-construction-v2.png`: 확장 부지 2곳에 낮은 골조·소형 크레인·작업등 추가. 사용자는 전체에 긍정적인 반응을 보였으나 **원형 스테이션이 구형처럼 보여 마음에 들지 않는다고 명시**했다. 스테이션은 미승인이며 사용자가 줄 예시를 기다린다. 다른 시설을 통째로 다시 만들지 않는다.
- `glass-ui-material-approved.png`: 청백색 기본/금빛 선택 버튼과 우측 패널의 재질 시트. 사용자는 **패널 디자인을 좋다고 승인**했다. 해당 패널 외형/재질을 기준으로 사용한다. 개별 버튼 상태와 최종 화면 배치는 아직 적용/검증 전이다.
- 이 파일들은 생성 이미지 기반 **디자인 시안**이며 실제 앱 스크린샷·완성된 조작 화면이 아니다. 시트는 1536×1024 RGBA, 실제 분리/슬라이스 자산은 후속이다. 실사 배경은 1672×941의 현재 생성 원본이며 4K 완성본이라고 주장하지 않는다.
- 현재 이미지에 표시된 공사 부지는 시안에 합쳐져 있다. 실제 제품에서는 배경과 교체 가능한 시설 레이어를 분리해야 하며, 아직 분리 완료가 아니다.

## 기능 구성안

| 시설 ID | 표시/상태 | 연결 |
| --- | --- | --- |
| lounge | 라운지 / 운영 | 기존 #/lounge, 언어 유지 |
| bridge | 관제센터 · 우주 스테이션 / 운영 | 기존 #/bridge, 역할·운항 상태 유지 |
| trade | 무역센터 / 준비 중 | 이름 잠정. 무역 기능을 구현한 것처럼 표시하지 않음 |
| guide-center | 아카데미 / 운송 팁 · 노하우 | 향후 운송 팁·가이드 전용 센터. 방금 완성한 서비스센터 이용안내와 구분 |
| expansion-a | 공사 중 | 시설 명칭·이동 목적지 미지정 |
| expansion-b | 공사 중 | 시설 명칭·이동 목적지 미지정 |

각 시설을 고정 ID, 상태, 표시명, 이미지 레이어, 위치/클릭 영역, 목적지로 분리해 관리한다. 공사 부지를 새 센터로 바꿀 때 해당 레코드와 자산만 교체하고 기존 운항/미션 저장 형식은 건드리지 않는다. 준비/공사 중 시설에는 설명만 표시하고 존재하지 않는 기능 화면으로 이동시키지 않는다. 운영 시설은 키보드와 터치로도 진입할 수 있게 한다.

## 연결 전 확인할 코드

- `apps/control-room/src/space-navigation.ts`: 새 division route와 기본 진입을 추가하되 기존 명시적 deep link는 유지.
- `SpaceExperience.tsx`: 기존 parentSpace/scene/sidebar/여행 전환이 lounge/bridge를 전제로 하므로 기본 경로 문자열만 바꾸지 않음. 승인 시설 레이어를 독립 컴포넌트로 연결.
- `OpeningFilm.tsx`와 opening 정책: 기존 영상은 라운지 맥락이므로 사업부 새 진입에 임의 재사용하지 않음. 영상/전환 인계와 새 첫 진입 정책을 함께 결정.
- 실제 메뉴 글자는 승인 Barlow Medium 500 + SUIT 500 및 기존 STAM 로고 사용. 생성 이미지에 글자를 굽지 않음.
- 전체 본문을 16:9 기준으로 맞추되 기존 고정 상단/사이드바와 겹치지 않게 함. 모바일에서는 시설을 읽고 선택할 수 있는 별도 배치 필요.

## 바로 다음 작업

완전 신규 생성 v6의 전경과 시설 형태를 확인받는다. 이후에도 반복 덧편집으로 디테일을 낮추지 않는다. 승인 패널의 개별 PNG/필요한 상태를 분리 제작하고, 시설 전경+실제 글자+패널의 화면 배치를 보여준다. 승인되지 않은 배경/버튼을 제품 기본 진입에 적용하지 않는다. 이번 2.10.0 배포에는 포함하지 않았다.
