# 무역 관제 가격 중심 구성 · 2026-11-17

사용자는 무역 관제를 지도·적재·큰 파트너 중심에서 **가격과 실제 거래 중심**으로 바꾸고, 공간을 적게 쓰는 그래프를 추가하도록 승인했다. 기존 기능 작업은 보존했다. 커밋·푸시·배포 없음.

## 화면과 흐름

- 상단: 현재 위치·기록상 자본·실현 손익·화물 수량. 담당자 초상/이름을 눌러 안내를 펼친다. 가격표를 인물로 가리지 않는다.
- 본문: 왼쪽 약 25%는 보유 품목·수량·가중 평균 원가, 오른쪽 약 75%는 품목별 터미널 가격·수요·비교 수량·차익·자료 날짜·이동 추정. 행성계/지역/검색/정렬을 제공한다. 전체 화물 조회는 품목별 행을 함께 보여주며, 여러 행의 수요가 단일 품목에 중복 배정되지 않는다.
- 선내 화물이 없으면 현재 위치에서 매입할 수 있는 품목을 보여주고 계획실로 이어진다. 장부가 아예 없어도 조회 위치를 선택할 수 있다. 실제 매입/판매/도착은 자동 처리하지 않는다.
- 거래처 선택 → 상세 제목으로 포커스/스크롤 이동 → 보고가에 따른 예상 금액·경로 미리보기 → 현재 도착지에서만 화물 묶음별 거래 입력 → 실제 수량/단가/총액 확인 → 기존 확인 창에서 명시적으로 저장. 다른 거점의 가격을 선택해도 위치·장부가 바뀌지 않는다.
- 아래: 실제 거래 입력은 계속 제공. 기존 재고 검색/위치·품목·소유권 묶음/태그/보관·회수, 이력/되돌리기/CSV, 백업·클라우드는 펼쳐서 접근한다.
- 지도와 적재는 독립된 버튼으로 요청할 때만 마운트하고 닫으면 해제한다. 계획실 상세에서는 기존 두 화면을 함께 유지한다. 이동 연출은 별도 담당 범위다.
- 모바일은 가격표의 한 행을 두 열 카드로 표시하여 단가·차익을 옆으로 밀지 않고 함께 읽을 수 있다. 공용 승인 프레임·유리 에셋·Barlow/SUIT 500 유지.

## 작은 그래프의 의미

1. 차익: 0 기준선을 중심으로 양수는 오른쪽 금색, 손실은 왼쪽 붉은 막대. 현재 필터 결과 전체에 같은 절댓값 척도를 사용한다. 정확한 수치와 `비용 전` 표기를 함께 표시한다.
2. 수량: 보고 수요·상자 크기·소유권 조건으로 비교한 수량 / 보유량 비율. 숫자·퍼센트를 함께 표시하며 실제 구매자 수요 보장이 아니다.
3. 가격: 공급자가 제공한 주간 최저–최고 범위와 현재 보고가 점. 시계열/추세 그래프가 아니다. 범위가 없으면 생략하고, 최저=최고도 정상 처리한다.

SVG는 각 100×16px 정도이며 그래프용 외부 라이브러리를 추가하지 않았다. 텍스트·접근성 이름으로 의미를 제공하고 색만으로 구분하지 않는다. 읽는 법·상세 조건은 바로 옆에서 펼친다. 지도·적재용 Worker/WebGL은 기본 관제 화면에서 실행하지 않는다. 가격표는 20행씩 표시하고 시세 재확인은 현재 표시된 품목으로 제한한다.

## 데이터와 보존 경계

- 기존 UEX 스냅숏/품목별 갱신을 재사용. 가격과 자료 수정 시각·게임 버전을 함께 표시한다. API 조회를 게임 서버 직결 실시간 정보로 표현하지 않는다.
- 기존 위험·위법·행성계·설비 조건 적용. 최대 가격 경과/패치 조건을 벗어난 행은 관측 자료로 표시하되 거래 입력 자동 채움을 막는다. 사용자가 원래 입력하던 수동 실제 거래 기능은 유지한다.
- 동일 품목의 여러 묶음은 한 거래처의 보고 수요를 공유한다. 상자 단위 반올림, 보관 화물 제외, 도난/미확인 소유권의 NQA 조건, 터미널 최대 상자 규격을 적용한다.
- 미확인 수요·원가는 `미확인`이다. 금액은 배정된 수량의 원가와 예상 매출을 비교한 **비용 전 차익**이다. 퀀텀 시간에 접근·점프·상하차 시간이 포함됐다고 주장하지 않는다. 경로 연결이 없으면 이동 미확인.
- 경로 후보 재계산은 계획실로 조건만 전달한다. 실제 보유 화물·남은 경로·거래 기록·운송 계정 데이터를 바꾸지 않는다. 가격표는 독자적인 예측/실행 최적화 엔진이 아니다.
