# 확정 셔틀 탑승 영상 — 기능·연출 로컬 인계

2026-11-12 · 사용자 요청: 확정 탑승 영상만 연결·검증·배포. 기능 로컬과 연출 로컬에서 후속 작업.

## 출처와 재현

- 연출 클라우드의 승인 파일과 `LOCAL-CINEMATIC-HANDOFF-20261112.md`는 이 실행 환경에서 접근할 수 없었다. 다른 클라우드의 파일 공유를 가정하지 않았다.
- 사용자 제공 공개 원본을 직접 다운로드하여 지정 사양으로 재현했다. 추가 생성·색 변경·속도 변경 없음. 원본 및 결과 SHA-256, 접근 불가 승인본의 참조 SHA-256은 `record.json`에 각각 구분했다. **재현본은 승인 클라우드 파일과 바이트 해시가 다르다.**
- 원본 0–5.75초(138프레임), 5.416667초부터 8프레임 페이드아웃, 검은 화면 4프레임, 원본 6.75초(162프레임)부터 마지막까지 79프레임, 뒤 구간 6프레임 페이드인. 1280×720 · 24fps · 221프레임 · 9.208333초.
- 앞 대사를 유지하고 연결부 원본 현장음만 0.25초 크로스페이드했다. 오디오 뒤 구간의 원본 6.75초는 출력 5.916667초에 대응하므로 영상과 어긋나지 않는다. 최종 엔진음·이륙음·착륙음을 추가한 버전이 아니다.
- 재현: `python3 scripts/rebuild-shuttle-boarding.py`. curl/FFmpeg 필요. 원본을 직접 가져오며 원본 체크섬이 달라지면 출력하지 않는다. 인코더 버전 차이로 재현 파일의 바이트 해시는 달라질 수 있다.
- PR #23은 안내데스크 접근·대기·복귀/라운지 원본 복원 작업이다. PR 파일 목록에 이번 셔틀 영상은 없었다. 이 요청으로 PR #23을 병합하지 않았다.

## 실제 연결

- `SpaceExperience.tsx`: 라운지의 `gate` 영역/원형 표식을 눌렀을 때만 탑승 영상을 연다. 라운지 메뉴의 관제센터 바로가기는 기존 빠른 진입을 유지한다. 연출 끄기·동작 줄이기는 영상을 생략한다.
- `ShuttleBoarding.tsx`: 실제 `ended` 이벤트 또는 ‘관제센터로 바로 이동’에서 기존 bridge 라우트로 이동한다. 기존 1.4초 타이머가 영상을 중단하지 않는다. 미확정 이륙·비행·착륙 장면을 뒤에 붙이지 않는다.
- 영상은 브라우저 화면 안에서 비율 유지(`contain`)·`playsInline`로 재생한다. 음소거는 기존 소리 설정을 따르며 영상 중 소리 버튼으로 변경할 수 있다. 취소/Esc는 라운지, URL 변경은 해당 목적지로 이동하며 미디어를 정지·해제한다.
- 재생 차단에는 사용자 클릭 재생, 로드 실패/지연에는 바로 이동·취소를 제공한다. 네이티브 모달로 뒤의 메뉴 클릭·키보드 포커스를 차단한다.
- 계약·경로·선적 위치·운항 진행·계정 저장 로직은 변경하지 않았다. 다른 기능 체크아웃의 미커밋 지도/적재 시안을 이 배포에 섞지 않았다.

- `node scripts/check-shuttle-boarding-browser.mjs`: 데스크톱 실제 자연 종료, 소리/음소거·음량, 취소/Esc·건너뛰기·바로가기·URL 변경, 로딩 실패, 자동재생 차단 후 재시도, 390px 영문/한글 UI와 동작 줄이기, 계산된 실제 형식의 운항 데이터 보존을 검사한다. 기본 Vite 5184, 주소는 `STAM_SHUTTLE_URL`, 캡처 폴더는 `STAM_QA_OUTPUT`으로 지정한다.

- 실제 게임·실계정·실물 모바일 기기 검증은 이번 범위가 아니다. 모바일은 Chromium 390px 에뮬레이션이다.

## 다음 담당

**기능 로컬:** 최신 `handoff/local-studio-20261110` 또는 명시적으로 지정한 최신 main을 보존 절차에 따라 받는다. `AGENTS.md`, `STAM_HANDOFF.json`, `PROJECT_STATUS.md` 최상단을 확인한다. 셔틀 재생·목적지 연결은 이 문서의 두 TSX 파일이 담당한다. 공유 파일을 동시에 수정하지 않는다. 검증 명령을 실행한 뒤 미리보기를 켠다.

**연출 로컬:** `record.json`과 실제 런타임 MP4가 이번 배포 기준이다. 원본 객실 형태 차이는 사용자가 수용했다. 다시 생성하거나 승인 전 영상으로 바꾸지 않는다. 이륙 영상의 이동 방향·진동은 미확정/반려 상태다. 최종 엔진·이륙·착륙음도 미완료다. 승인된 후속 영상과 연결 구간·종료 프레임·오디오 사양을 기능 담당에게 전달하기 전에는 런타임에 추가하지 않는다.

미완성 항목: 이륙 영상, 최종 엔진음/이륙음/착륙음, 다른 공간·콘솔의 미완성 이동/복귀 영상. 현재 정상적인 직접 이동 흐름은 유지한다. 새로운 후속 작업·추가 배포를 자동 승인한 것으로 해석하지 않는다.
