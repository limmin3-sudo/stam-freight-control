## 현재 연출 순서

라운지 장소/가이드 클릭 → 새 접근 → 새 대기 루프와 통합 홀로그램 → 패널 수납 → 새 복귀 → 원본 라운지 사진/전신. 기존 바로가기, 소리 전환, 이동 건너뛰기, 첫 운송/정보실 연결과 키보드 정리를 유지한다.

새 대기 루프는 사용자의 최종 정정대로 홀로그램 패널 뒤에서 재생한다. 고해상도 데스크 사진은 로딩/실패 시 기본 화면이다. 원래 A/B 영상은 제작 자료에 보존됐지만 앱에서 재생하지 않는다.

## 남은 문제와 기능 담당 확인

1. 생성 영상은 720p이며 고해상도 사진과 인물·배경 위치가 조금 다르다. 전환과 루프 경계의 시각적 차이가 완전히 제거된 것은 아니다. 원본 오디오는 보존했으나 모든 발화의 독립 전사/청취 검수는 하지 않았다.
2. 이번 왕복 연결에 추가 기능 구현은 필요 없다. 공유 `SpaceExperience.tsx`에서 이미지 상태 복원과 기존 미션/서비스 기능 변경이 충돌하는지만 통합 시 확인한다. 배포 빌드에서 `prepare-guide-desk.mjs`를 돌리더라도 새 제작 폴더가 포함되어 있어야 한다.
3. 라운지→게이트는 프롬프트 제작/시안 검토 중이다. 사용자 지적: 게이트 이동/변형, 느린 카메라·발화. 반려 시안을 앱에 연결하지 않는다. 최종 영상/도착 사진 승인 뒤, 기존 게이트 클릭의 bridge 이동 앞에 재생을 붙일 필요가 있으면 기능 담당에게 별도 연결 요구를 전달한다.
4. 디렉터/브로커 소개 전용 상태, 네 파트너 카드 정렬/크롭/반응형은 이후 별도 연출 작업에서 최신 main을 확인한다. 이번 PR이 그 화면 개편까지 완료했다는 뜻은 아니다.
