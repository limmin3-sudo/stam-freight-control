# 라운지 가이드 근접 대화

접근·경청·복귀 영상의 재생 경로와 구도 참고용 1664×936 무자막 PNG 세 장을 담았다. 현재 라운지의 배경과 접수 직원, 모니터, 게이트 위치를 기준으로 잡았다. 전경은 2026-11-19 사용자가 확정한 전신 에셋과 위치(중심 x 32%, 상단 y 46.2%, 높이 45.8%, 발끝 y 약 92%)를 쓴다. 근접 두 장은 같은 안내 데스크 도착 배경과 카메라 높이에서 미소와 경청 표정만 달리한다.

## 수령한 접근 영상

[접근 원본](../../../apps/control-room/public/partner-dialogue/director/approach.mp4)은 1280×720, 24fps, 145프레임(6.04초)이며 AAC 오디오가 있다. 가이드가 데스크를 가리키고 돌아서 걸어간 뒤 접수 직원 앞에서 손님을 바라본다. [Grok 게시물](https://grok.com/imagine/post/e22aaf30-38d5-449b-be6a-07857ff11ffc)

[접근 영상의 마지막 프레임](approach/loop-anchor.png)을 연결 확인용으로 함께 제공한다.

## 수령한 경청 루프

[경청 루프 원본](../../../apps/control-room/public/partner-dialogue/director/idle.mp4)은 1280×720, 24fps, 361프레임(15.04초)이다. 가이드가 정면에서 손을 모으고 기다리다가 약 4~6초에 오른손으로 셔츠를 한 번 정돈하고, 약 9~13초에 왼손으로 귀 옆 머리카락을 한 번 넘긴다. 마지막에는 다시 손을 모으고 손님을 바라본다. 접근 마지막과 루프 첫 프레임, 루프 첫 프레임과 마지막 프레임에서 얼굴과 손, 데스크의 위치가 육안상 일치한다. [Grok 게시물](https://grok.com/imagine/post/00b591dc-12ec-4091-9bc3-69e6a1370d98)

## 기능팀 연결 지점

가이드를 선택하면 접근 영상을 한 번 재생한다. 종료 시 데스크 대화 패널을 표시하고 경청 영상을 첫 프레임부터 음소거로 반복한다. 두 영상은 같은 표시 영역과 배율을 사용한다. 동작 줄이기에서는 02를 바로 표시한다. 패널은 얼굴과 게이트 입구가 보이도록 화면 하단에 배치한다.

대화를 마치면 [복귀 영상](../../../apps/control-room/public/partner-dialogue/director/return.mp4)을 한 번 재생한 뒤 라운지 전경을 표시한다.
