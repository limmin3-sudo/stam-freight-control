# 웹 3.1 기준 무역 튜토리얼 인계

## 기준과 통합 범위

- 기준: `handoff/local-studio-20261110` / `434b50e` (웹 3.1.0 배포 완료 증거 커밋).
- 작업 브랜치: `cinematic/trade-guide-310-20261117`.
- 원격 fetch 후 깨끗한 로컬 공통 인계를 fast-forward하고 별도 브랜치를 생성했다. 기존 연출 브랜치와 제작 자료를 보존했다.
- #35·#37·#38·#39는 기준 배포에 포함되지 않았다. 이번 브랜치는 그 전체를 병합하지 않는다. #39의 안내데스크 메뉴 관련 6개 소스 변경만 패치 적용 전 대조한 뒤 선별 이식했다.
- 이번 PR은 최신 기능본에 직접 적용할 수 있다. #35→#37→#38 전체를 선행 적용할 필요가 없다. #39의 메뉴 변경은 이번 작업이 대체하므로 이후 #39 전체를 중복 병합하지 않는다. #35~38의 별도 디자인/근접 대화 작업은 기존 브랜치에서 별도 검토한다.
- main/공통 인계 원격에 푸시·병합·배포하지 않는다. 기능 담당이 최신 작업을 보존하면서 통합한다.

## 연결된 동작

안내데스크 → 무역 튜토리얼 선택 → 무역 연습 시작 → 담당 범위 → 예시 시세 확인 → 계획 검토 → 매입/출발/도착/판매/비용/마감 → 실제 무역 계획 화면.

- 범위 선택은 기존 `spaceHash`의 `facility=trade&room=planning&advisor=intrasystem|interstellar`로 전달한다. ko/mix/en을 유지한다.
- 실제 `TradeSuite` 화면을 재사용한다. 예시 수치·연습 기록을 실제 장부로 전달하지 않는다.
- 예시: 자본 100,000, 32 SCU × 1,000 매입, 32 SCU × 1,200 판매, 비용 1,000. 완료 자본 105,400 / 순손익 5,400 / 선내 0 SCU.
- 출발·도착은 판매를 자동 기록하지 않는다. 잘못된 순서·중복 액션은 적용되지 않는다. 이전 단계 복귀 시 연습 유지, 기록 초기화/종료 후 재시작 시 초기화.
- 예시 상태는 React 메모리에만 있다. 계정·실시간 시장·실제 장부 저장 모듈에 의존하지 않는다. 실제 운송 연습과 기존 시설 투어 연결도 유지한다.
- 원본 안내데스크 영상·반환 컨트롤러·공용 유리 에셋과 Barlow/SUIT를 재사용한다. 무역 로비 배경과 승인된 담당자 이미지를 재사용하며 새 인물/프레임 자산은 생성하지 않았다.

- `guide-journey-content.ts`: 무역 5단계 KO/EN 대사. 좌표/특정 버튼 위치에 의존하지 않는 기능 설명.
- `TradeGuideStage.tsx` / `trade-guide.css`: 예시 카드·확인·연습 기록·실제 화면 진입.
- `trade-guide-practice.ts` / `tests/trade-guide-practice.test.ts`: 독립 예시 상태/검증.
- `PROJECT_STATUS.md` 및 이 폴더: 인계·브라우저 재현 스크립트·최종 화면.

`SpaceExperience.tsx`, `TradeSuite`, 실제 무역 계산/저장/클라우드/계정/함대/데이터/배포 설정은 수정하지 않았다. 공유 파일을 과거 버전 전체로 복원하지 말 것. `tools/prepare-guide-desk.mjs`는 예전 추출기이므로 실행해 현재 컨트롤러를 덮지 말 것.

## 범위와 남은 일

이번 완료는 개인 무역의 기본 흐름을 설명하는 고정 예시 연습이다. 실제 시장 계산기·실제 거래 수행이 아니며, 가격/재고는 실측값으로 표시하지 않는다. 기존 공동 무역의 초대/승인/정산은 마지막에 소개만 하고 별도 실습은 만들지 않았다. 새 전체 시설 투어, 음성 안내, 셔틀 영상 제작도 이번 범위가 아니다. 최종 디자인/배포 승인은 기능 담당 통합 이후 진행한다.

실제 무역 화면에는 이번에 수정하지 않은 기존 '교역' 문구와 기존 셸 테마가 남아 있다. 이전 연출 PR의 명칭·셸·근접 대화 변경을 이번 튜토리얼 완료로 간주하지 말 것.
