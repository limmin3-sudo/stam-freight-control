# 복귀 시 축소 연출 — beta 2.7.0 후속

브랜치 `cinematic/return-pullback-20261113`, 기준 최신 main/개발 인계 `fa647d0`. 이미 기능 담당이 통합·배포한 PR #26/#27 위에서 진행한다. 기존 기능·지도·관제·적재 변경을 되돌리지 않는다.

정보실에서 라운지로 돌아갈 때도 안으로 확대하던 문제를 수정한다. 방/콘솔에 들어갈 때는 기존 확대와 STAM 점등을 유지하고, 나갈 때는 뒤로 빠지며 실제 상위 공간이 넓어지는 축소를 사용한다.

- 정보실·서비스센터·영상관 → 라운지
- 미션·항로 지도·관제 콘솔 → 관제센터
- 관제센터 → 라운지
- 다른 방/콘솔 사이 이동과 라운지 게이트 → 관제센터는 기존 진입 방향을 유지한다.

복귀는 현재 화면에서 333ms 동안 살짝 물러나 암전한 뒤, 돌아갈 장소의 가까운 시점(5.2배)에서 라운지/관제센터 전체(1배)로 697ms 동안 축소한다. 이전 화면에 대응하는 목적지 좌표를 사용한다. 정보실에서 나오면 정보실 앞, 미션 콘솔에서 나오면 미션 콘솔 앞에서 시야가 넓어진다. 총 기본 시간은 기존 약 1.03초다. 고정 상단바/사이드바는 움직이지 않는다. 돌아온 공간의 표식·글씨·인물 클릭 영역은 카메라가 멈추면 나타난다.

복귀 시에는 실제 공간을 드러내며 STAM 로고·전류/점등음은 표시하지 않는다. 기존 150ms 파지직/로고는 실제 메뉴로 들어가는 방향에 유지한다. 가이드의 기존 접근·대기·복귀 영상은 그대로 사용한다.

## 변경 파일 / 기능 담당 병합

- `SpaceExperience.tsx`: 진입과 복귀의 시각 방향·목적지 시점 전달, 같은 복귀 경로를 사이드바·상단 로고·기존 방 화면 Esc에 연결. 기존 가이드/지도 Esc 소유권은 보존한다. **현재 공유 기능 구조와 대조하여 작은 diff만 합친다.**
- `ConsoleArrival.tsx`, `console-arrival.css`: 복귀 때 점등 대신 빠르게 암전을 걷고 목적지 카메라를 축소한다. 총 시간 유지.
- `travel-direction.ts`, `tests/travel-direction.test.ts`: 화면 관계에 따른 진입/복귀 시각 분류와 검증.

`ControlRoom`, `MapConsole`, 운항 저장/계약/계산/적재 위치, 역할 선택, 고정 메뉴 파일/디자인은 수정하지 않는다. 새로운 이미지·영상·모델 자산도 필요 없다. 새 이동으로 복귀 중인 애니메이션을 중단하면 이전 타이머와 시점 상태를 정리한다. 모션 감소에서는 기존처럼 즉시 이동한다.

## 검증

- `npm run build --prefix apps/control-room`: TypeScript/Vite 통과. 기존 큰 번들 경고 유지.
- `npm test --prefix apps/control-room`: 15개 테스트 파일 통과(방향 분류 검증 포함).
- 실제 production preview Chromium: 12개 복귀/회귀 시나리오 통과. 각 복귀에서 실제 목적지 카메라 행렬이 큰 값에서 1배로 단조 감소하는 프레임을 기록했다. 운항 저장값 유지, 원래 확대·점등, 취소 후 지연 이동 없음, 복귀 중 새 이동, 모바일 가로 넘침 없음, 모션 감소를 확인했다.
- 실제 기기와 새 전체 튜토리얼 동선은 이번 검증 범위가 아니다.
