## 파일과 연결 지점

- 질문용 반응 WebP 45장은 `apps/control-room/src/assets/dialogue-scenes/`에 있습니다. `CrewEncounter.tsx`가 인물별 파일을 읽고 `PartnerQuestion.tsx`가 실제 질문 제출 시 전환합니다.
- 여섯 명의 접근·대기·복귀 원본 18개와 `playback.json`은 `apps/control-room/public/partner-dialogue/`에 있습니다. Pages 빌드가 이 디렉터리를 그대로 복사합니다.
- 교수 4장, 중개인 3장, 오퍼레이터 3장의 투명 튜토리얼 패널용 WebP는 `apps/control-room/src/assets/tutorial-partners/`에 있습니다. 후속 실습 패널에서 가져다 쓸 소스입니다.
- 과목별 인계 대사는 `apps/control-room/src/partner-tutorials.ts`에 있습니다. 새 실습 본편 제작은 후속 범위입니다.

## 검증과 배포 설정

최신 기능 코드와 함께 루트 테스트 299개, 관제실 앱 테스트 182개 및 프로덕션 빌드를 통과했습니다. Pages 조립 후 파트너 재생 목록·미디어 19개와 반응 WebP 45개의 해시를 소스와 대조했습니다. `scripts/check-partner-playback-browser.mjs`로 실제 미디어 재생·복귀와 둘러보기를 다시 확인할 수 있습니다.

파트너 질문은 기존 Pages 워크플로의 `STAM_PARTNER_API_ORIGIN` 저장소 변수를 사용합니다. 질문별 표정과 자세는 로컬 테스트 응답으로 검증했습니다. 공개 반영 뒤 운영 로그인 계정으로 질문·응답을 확인해 주세요.
