# 기능팀 인계 · 시설 파트너 대화 연출

파트너를 선택하면 해당 파트너의 접근 영상을 한 번 재생한다. 도착하면 대화 패널과 대기 화면을 표시하고, 대화 종료 시 복귀 영상을 한 번 재생한 뒤 원래 시설 전경과 선택 포커스를 복원한다. 패널·대화 API와 시설 라우팅 연결은 기능팀 작업이다.

## 재생 시점

1. `approach`는 파트너 선택 시, `return`은 대화 종료 시 사용한다. 두 영상의 음성은 기존 소리 설정을 따른다.
2. 접근 재생 중 선택한 파트너의 `idle.src`를 미리 로드한다. 정지 이미지는 디코딩을 마쳐 두고 접근 종료 시 같은 16:9 영역에 같은 배율과 정렬로 표시한다. 관제센터·무역센터·아카데미에 지정된 파일은 영상 제작에 사용한 1664×936 PNG 원본이다. 대화 패널이 열린 동안 이 이미지를 유지한다.
3. 라운지의 `idle.type`은 `video`다. 대화 중 `loop`와 `muted`를 적용한다. 복귀 종료 시 각 시설의 기존 공간 화면으로 돌아간다.

Vite 앱의 공개 경로는 `partner-dialogue/playback.json`이다. 앱 기준 URL로 연결표를 읽고, 각 미디어 경로는 연결표의 URL을 기준으로 해석한다. MP4 13개와 PNG 5개가 브랜치에 개별 파일로 포함된다.
