# 기능팀 추가 인계 · 탐색 UI, 시설 둘러보기, 라운지 배치

이 변경은 기존 [파트너 대화 인계](../partner-dialogue-20261119/README.md) 커밋 `493197f`의 직계 후속 커밋이다. 기능팀이 해당 인계를 적용 중이면 이 후속 커밋 한 개만 현재 작업 브랜치에 추가로 반영할 수 있다.

- 상단의 로그인·게임 로그·앱 다운로드·언어 컨트롤은 동일한 크기의 청색 유리 버튼을 사용한다. 사이드바는 검정 유리 금장 버튼과 확대한 클릭 영역을 사용한다.
- 안내 데스크에서 시작하는 둘러보기는 라운지·관제센터·무역센터·아카데미 순서로 진행한다. 시설마다 다섯 대사이며 총 14장면이다. 자동 진행, 대사별 다음, 시설별 건너뛰기를 지원한다. 라운지 게이트 장면은 실제 라운지 배경과 표식 좌표를 사용한다.
- 라운지 가이드는 게이트 왼쪽에 두 손을 포갠 자세로 서고 이름표는 발밑에 표시된다. 클릭 영역은 같은 인물 위치를 따른다. [라운지 구도와 기준 프레임](../lounge-guide-dialogue-20261119/HANDOFF.md)
