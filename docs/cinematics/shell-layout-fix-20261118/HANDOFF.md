## 최신 디자인 확정 — 상단 유리 / 볼록한 금색 연결부 / 건메탈

사용자 표시의 1번은 기존 청남색 유리 상단바, 2번은 플라이트 콘솔 주변의 황금빛 연결부, 3번은 메뉴 뒤 건메탈로 반영했다. 2번은 얕게 볼록한 금속 면·곡선 베벨·미세한 결·반사광을 가진 별도 생성 자산이며 실제 A 콘솔은 그 앞에 기존 크기로 유지한다. 곡선은 바 내부 장식이고 본문과 맞닿는 경계는 여전히 직각이다.

`clean-shell-material.png`와 상단 3개 source rectangle은 그대로 사용한다. 새 `shell-gold-gunmetal.png`의 금색 연결부만 고정 높이 164px, 아래 건메탈과 끝 테두리는 남는 사이드바 높이에 배치한다. 모바일은 기존 상단만 사용하며 데스크톱 장식을 별도 공간으로 추가하지 않는다. 본문·폰트·버튼·콘솔 크기 및 전환 좌표 변경 없음.

이번 재질 수정 뒤 타입/생산 빌드와 `verify-layout.mjs` 12개 결과를 다시 통과했고 최종 캡처를 갱신했다. 아래 앱175개·루트282/283 결과는 직전 기하 수정 시의 검사이며 이번 재질 교체만으로 전체 검사를 반복하지 않았다.

## 문제와 수정

기존 셸은 934×499 시안 영역을 화면 전체에 늘렸다. 헤더는 화면 높이의 12%, 사이드바는 화면 폭의 18.3%, 라운지 위 여백은 화면 높이의 6.8%로 잡혀 있었다. 가이드를 클릭하면 사이드바까지 사라지고 비디오가 전체 창 너비로 다시 계산됐다. 900px 이하에서는 안내 패널의 큰 상단 여백이 이동 영상에도 적용됐다.

사용자 후속 결정에 따라 **장면을 바에 맞추지 않고 원래 장면 배치를 복구**했다. 데스크톱 상단 67px, 사이드바 `clamp(248px,16.4vw,320px)`, 본문 추가 패딩/상단 여백 없음. 기존 1672:941 비율을 유지한다. 가이드에서도 같은 사이드바와 장면 셀을 사용하며 도착 전/복귀 중에는 모바일 대화용 세로 크롭을 적용하지 않는다. 도착 후 모바일 대화의 세로 스크롤 구성은 유지한다.

시안 확대를 없애기 위해 글자/사진/버튼이 없는 **새 바 전용 자산**을 image_gen으로 제작했다. 생성 결과는 네이티브 1536×1024 RGBA PNG이며 3K/4K라고 주장하지 않는다. 최초 둥근 안쪽 모서리는 사용자 지적에 따라 직각으로 다시 생성했다. 최종 자산은 안팎 모두 직각이고 상단·왼쪽 영역에만 렌더링한다. 콘텐츠 위에 그림자나 곡선 마스크를 겹치지 않는다. 다섯 소스 영역으로 나눠 연결하고 길이가 필요한 부분만 늘린다. 높은 DPR에서 모든 픽셀이 원본과 동일하다는 보장은 아니다.

기존 D 사이드 버튼, 청록 상단 버튼, A 플라이트 콘솔, 함선 이미지, Barlow/SUIT 폰트, 계정/로그/언어 및 기능 콜백은 유지한다. 데이터·계산·네이티브 앱·버전·공개 다운로드는 변경하지 않았다.
