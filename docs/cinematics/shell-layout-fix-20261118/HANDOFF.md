## 최종 디자인 — 직선 사선·한 줄 브랜드·따뜻한 금색

금색 이름판을 오른쪽으로 연장하고 곡선 대신 직선 사선으로 바꿨다. `STAM FREIGHT DIVISION`은 한 줄이며 STAM38px, 부제16px의 Barlow500 실제 텍스트다. 원형 로고60px·검은 입체 글씨를 유지했다. 761–1000px에서는44/30/12px로 줄여 버튼과 가로 넘침을 피하고, 모바일은40/27/10px 한 줄 브랜드에 기존 컨트롤을 줄바꿈한다. 데스크톱 상단67px와 장면 셀은 유지한다.

사용자가 회색/백금처럼 보인다고 지적한 시안은 사용하지 않는다. 최신 생성본은 따뜻한 샴페인 골드, 미세한 표면결, 사선 절삭면의 이중 가공 홈과 단차, 모서리의 짧은 가공 표시를 포함한다. 최종 원본 `/workspace/generated_images/exec-b70798fc-6552-40a3-8128-0aad3b63c08e.png`. 중간 시안과 기존 원본은 제작 폴더에 보존했다. `assets/provenance.json`에 최종 출처/해시/일곱 구간을 기록했다.

상단의 직선 사선 구간 폭은400px(좁은 데스크톱200px), 나머지 유리만 가변 길이를 채운다. Sidebar 하우징은 콘솔 요약 하단과 메뉴 캡션 사이에서 직선 단차로 끝난다. 상세 콘솔은 기존처럼 메뉴 앞에 겹쳐 열린다. ResizeObserver와 스크롤 이벤트는 해제 시 정리한다. 기존 A콘솔/D버튼과 기능 상태는 변경하지 않는다.

타입/빌드, 기존 브라우저12개, 하우징 단차4개 검증 통과. 320/390/768/1024/1595px 로고 잘림·문서 넘침·Barlow 확인은 `review/brand-checks.json`. 실제 화면은 `brand-desktop.png`, `brand-mobile.png`, `housing-final.png`, `housing-expanded.png`. 아래 전체 테스트 결과는 앞선 기하 수정 당시 기록이다.

## 문제와 수정

기존 셸은 934×499 시안 영역을 화면 전체에 늘렸다. 헤더는 화면 높이의 12%, 사이드바는 화면 폭의 18.3%, 라운지 위 여백은 화면 높이의 6.8%로 잡혀 있었다. 가이드를 클릭하면 사이드바까지 사라지고 비디오가 전체 창 너비로 다시 계산됐다. 900px 이하에서는 안내 패널의 큰 상단 여백이 이동 영상에도 적용됐다.

사용자 후속 결정에 따라 **장면을 바에 맞추지 않고 원래 장면 배치를 복구**했다. 데스크톱 상단 67px, 사이드바 `clamp(248px,16.4vw,320px)`, 본문 추가 패딩/상단 여백 없음. 기존 1672:941 비율을 유지한다. 가이드에서도 같은 사이드바와 장면 셀을 사용하며 도착 전/복귀 중에는 모바일 대화용 세로 크롭을 적용하지 않는다. 도착 후 모바일 대화의 세로 스크롤 구성은 유지한다.

시안 확대를 없애기 위해 글자/사진/버튼이 없는 **새 바 전용 자산**을 image_gen으로 제작했다. 생성 결과는 네이티브 1536×1024 RGBA PNG이며 3K/4K라고 주장하지 않는다. 최초 둥근 안쪽 모서리는 사용자 지적에 따라 직각으로 다시 생성했다. 최종 자산은 안팎 모두 직각이고 상단·왼쪽 영역에만 렌더링한다. 콘텐츠 위에 그림자나 곡선 마스크를 겹치지 않는다. 일곱 소스 영역으로 나눠 연결하고 길이가 필요한 부분만 늘린다. 높은 DPR에서 모든 픽셀이 원본과 동일하다는 보장은 아니다.

기존 D 사이드 버튼, 청록 상단 버튼, A 플라이트 콘솔, 함선 이미지, Barlow/SUIT 폰트, 계정/로그/언어 및 기능 콜백은 유지한다. 데이터·계산·네이티브 앱·버전·공개 다운로드는 변경하지 않았다.
