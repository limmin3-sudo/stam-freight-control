## 최신 디자인 확정 — 상단 곡선 / 콘솔 아래 직선 단차

상단 왼쪽에서 플라이트 콘솔 둘레까지 하나로 이어지는 두꺼운 샴페인 골드 하우징을 적용했다. 상단의 금속/청남색 유리 경계는 곡선이고, 사이드바에서는 플라이트 콘솔 바로 아래·운송사업부 버튼 위에서 수평 직선 단차로 끝난다. 그 아래는 건메탈이다. 별도 둥근 콘솔 받침 시안은 이번 자산으로 교체했다.

최종 `shell-gold-gunmetal.png` 하나를 일곱 영역으로 나누어 사용한다. 상단의 곡선 구간 폭은 고정하고 오른쪽 유리만 남은 길이를 채운다. `ShellMaterial.tsx`의 ResizeObserver는 콘솔 요약 높이와 스크롤을 따라 단차를 요약 하단과 메뉴 캡션 사이에 맞춘다. 상세창은 기존처럼 메뉴 앞에 겹쳐 펼쳐지므로 하우징을 늘리거나 메뉴를 밀지 않는다. 관찰자/이벤트는 해제 시 정리하며 기능 상태나 본문 크기는 바꾸지 않는다. 760px 이하에서는 사이드 장식을 숨기고 상단 재질만 기존 반응형 바에 사용한다.

기존 A 콘솔·D 버튼·Barlow/SUIT 글꼴과 본문/가이드 영상 좌표는 유지했다. 새 원본은 `/workspace/generated_images/exec-6dacd686-aad4-46b2-a917-2edb62bae12d.png`이며 출처/해시는 `assets/provenance.json`에 저장했다. 이전 clean 자산은 보존하지만 현재 셸에서 import하지 않는다.

이번 수정 뒤 타입/생산 빌드, 기존 화면 검증 12개, 콘솔 접힘/펼침/스크롤/다시 접힘의 단차 검사 4개를 통과했다. `review/housing-final.png`, `housing-expanded.png`, `housing-checks.json` 및 기존 최종 캡처를 갱신했다. 아래 앱175개·루트282/283은 앞선 기하 수정 당시 검사 결과다.

## 문제와 수정

기존 셸은 934×499 시안 영역을 화면 전체에 늘렸다. 헤더는 화면 높이의 12%, 사이드바는 화면 폭의 18.3%, 라운지 위 여백은 화면 높이의 6.8%로 잡혀 있었다. 가이드를 클릭하면 사이드바까지 사라지고 비디오가 전체 창 너비로 다시 계산됐다. 900px 이하에서는 안내 패널의 큰 상단 여백이 이동 영상에도 적용됐다.

사용자 후속 결정에 따라 **장면을 바에 맞추지 않고 원래 장면 배치를 복구**했다. 데스크톱 상단 67px, 사이드바 `clamp(248px,16.4vw,320px)`, 본문 추가 패딩/상단 여백 없음. 기존 1672:941 비율을 유지한다. 가이드에서도 같은 사이드바와 장면 셀을 사용하며 도착 전/복귀 중에는 모바일 대화용 세로 크롭을 적용하지 않는다. 도착 후 모바일 대화의 세로 스크롤 구성은 유지한다.

시안 확대를 없애기 위해 글자/사진/버튼이 없는 **새 바 전용 자산**을 image_gen으로 제작했다. 생성 결과는 네이티브 1536×1024 RGBA PNG이며 3K/4K라고 주장하지 않는다. 최초 둥근 안쪽 모서리는 사용자 지적에 따라 직각으로 다시 생성했다. 최종 자산은 안팎 모두 직각이고 상단·왼쪽 영역에만 렌더링한다. 콘텐츠 위에 그림자나 곡선 마스크를 겹치지 않는다. 일곱 소스 영역으로 나눠 연결하고 길이가 필요한 부분만 늘린다. 높은 DPR에서 모든 픽셀이 원본과 동일하다는 보장은 아니다.

기존 D 사이드 버튼, 청록 상단 버튼, A 플라이트 콘솔, 함선 이미지, Barlow/SUIT 폰트, 계정/로그/언어 및 기능 콜백은 유지한다. 데이터·계산·네이티브 앱·버전·공개 다운로드는 변경하지 않았다.
