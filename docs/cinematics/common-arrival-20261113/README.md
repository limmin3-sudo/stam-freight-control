# 공통 로고 점등 / 깊은 확대 / 장소명 클릭

브랜치 `cinematic/common-arrival-zoom-20261113`, 기준 `main` 40c3301. 연출 클라우드 작업이며 기능 담당이 최종 통합·배포한다. PR #27의 후속 변경을 포함한다.

## 최종 동작

일반 이동은 사이드바·실제 장소·원형 표식·장소명 글씨가 같은 기존 목적지 핸들러를 사용한다. 라운지와 관제센터 양쪽 모두 목적지 안으로 빠르게 들어가는 5.2배 확대 → 암전 → STAM 로고 → 짧은 전류 점등 → 최신 실제 메뉴로 이어진다. 고정 상단바·사이드바는 화면 밖으로 밀지 않고 콘텐츠 영역만 연출한다. 기존 서비스센터/정보실/영상관/콘솔의 테마와 서체, 기능 데이터를 그대로 표시한다.

기존 850ms 접근 + 180ms 밝아짐의 약 1.03초 예산을 유지했다. 출발 697ms, 도착 333ms이며 **파지직 전류 효과는 150ms 한 번**이다. 최초 콘솔 마운트가 무거워도 실제 화면이 DOM에 연결된 뒤 도착 표시 시간을 시작한다. 기존 효과음 켜짐과 음량을 따르는 110ms 대역 제한 노이즈를 짧게 재생하며, 기본 음소거에서는 소리가 나지 않는다. 모션 감소/연출 끄기에서는 즉시 목적지로 이동한다.

안내데스크로 가이드를 따라가는 기존 튜토리얼 접근·대기·복귀 영상은 이 일반 점등 효과에서 제외한다. 일반 게이트 클릭은 더 이상 셔틀 영상을 자동 재생하지 않고 확대를 사용한다. 기존 `ShuttleBoarding` 제작 자산/컴포넌트는 보존했으며, 전체 튜토리얼 동선에 셔틀 영상을 연결하는 상태/기능 작업은 기능 담당과 별도로 진행해야 한다. 전체 튜토리얼이 완성되었다고 보고하지 않는다.

장소명 글씨는 기본 푸른 흰색으로 통일하고 hover/키보드 선택 때 황금빛으로 강조한다. 배경 버튼 박스는 없다. 원형 표식과 같은 링크/이벤트를 사용하며 기존 식별자와 목적지, 수정키 링크 열기, Enter를 유지한다.

## 파일과 병합 범위

- `SpaceExperience.tsx`: 장소명 링크, 공통 전환 선택, 점등 타이머/효과음 연결. **공유 기능 파일이므로 작은 diff를 대조하여 병합**한다. 기존 버전 전체 덮어쓰기 금지.
- `space-config.ts`: 접근 확대 1.55 → 5.2. 좌표·데이터 계산은 변경하지 않는다.
- `ConsoleArrival.tsx`, `console-arrival.css`: 미리 읽어둔 로고/전류 PNG, 빠른 빛 스캔, 콘텐츠 영역의 점등 오버레이. 실제 UI와 이벤트는 뒤에서 동작한다.
- `lounge-labels.css`: 라운지/관제센터의 글씨 링크와 색상 통일.
- `assets/arrival/`: 실제 연결한 로고·투명 전류 생성 자산과 출처/해시 기록.

상단바/사이드바 파일, 계약·SCU·적재·경로·운항 저장, 파트너 선택 정책, `ControlRoom.tsx`, `MapConsole.tsx`는 수정하지 않는다. 사이드바의 펼침/접힘 디자인은 그대로이며 전환 중 외곽 메뉴를 고정하도록 연출 CSS만 덧붙였다. 기존 운항/계정 데이터를 지우지 않는다.

## 자산과 검증

`stam-standby-v1.png`는 공식 STAM 로고를 참조한 생성 이미지이며 공식 로고 픽셀과 동일한 파일이라고 부르지 않는다. 실제 전류 자산은 image_gen `exec-0e606460-f4b8-4f10-a586-0079ab93802a`, 1672×941 RGBA다. 모델 생성 원본은 제작 폴더에 보존하고 복사했다. 실제 파일과 해시는 `apps/control-room/src/assets/arrival/record.json`.
