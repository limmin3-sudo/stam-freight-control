# 공통 도착 로고 / 직접 방문 확대 / 장소명 클릭

브랜치 `cinematic/common-arrival-zoom-20261113`, 기준 `main` 40c3301. 연출 클라우드의 별도 작업이며 최종 통합·배포는 기능 담당이 진행한다.

## 사용자 최종 방향

- 서비스센터의 테마와 폰트는 이미 맞춰져 있다. 실제 화면을 새로 디자인하거나 고정 이미지로 대체하지 않는다.
- 일반 라운지의 서비스센터·정보실·영상관 방문은 간단한 확대 연출을 사용한다.
- 길게 안내하는 영상은 튜토리얼에서 가이드를 따라가는 동선에 사용한다.
- 튜토리얼 영상 마지막 프레임은 공통 STAM 로고 대기 화면으로 사용할 수 있다. 끝나면 목적지의 최신 실제 UI가 켜진다. 화면 구조를 수정해도 고정 UI 이미지를 담은 영상을 다시 제작하지 않도록 한다.
- 라운지와 관제센터의 장소명도 눌러 이동한다. 기본 글씨색은 라운지의 푸른 흰색으로 통일하고 hover/키보드 선택 시 황금색으로 강조한다. 글씨 배경에 버튼 박스를 추가하지 않는다.

## 이번 변경

`SpaceExperience.tsx`의 기존 장소명 `div`를 같은 위치·같은 내용의 실제 링크로 바꾸고 기존 `enter`/highlight/focus 이벤트에 연결했다. 원형 표식·장소·글씨가 같은 목적지와 동작을 사용한다. 기본 브라우저 수정키 링크 동작과 Enter를 유지한다. 전환 중 기존 `inert`를 그대로 사용한다.

서비스센터·정보실·영상관의 표식/장소/글씨 클릭은 기존 850ms 확대 전환을 사용한다. 기존 바로가기와 같은 방식이다. 모션 감소/실패 경로, 취소, 목적지 해시와 기능 화면은 그대로다. 콘솔 코드·계정·운송기록·계산·저장·파트너 선택은 수정하지 않는다.

`lounge-labels.css`에서 라운지/관제센터의 장소명·설명·안내선 기본색을 통일했다. 장소명 hover/focus/연결된 표식 강조는 황금빛으로 표시하고, 기존 서체·크기·배치·테두리 글자 처리는 유지한다. 상단바와 승인 사이드바는 변경하지 않는다.

[stam-standby-v1.png](stam-standby-v1.png)는 기존 공식 STAM 로고를 참조한 생성 시안이다. PNG 1672×941(기존 장면 크기), 남색/청록색 정면 대기 화면이며 실제 메뉴·사용자 데이터를 넣지 않았다. 생성 모델이 재현한 로고이므로 공식 로고 픽셀과 동일한 파일이라고 부르지 않는다. 해시는 `record.json`. 생성 원본은 제작 폴더에 보존했다. 아직 앱의 배경으로 연결하거나 동영상으로 만들지 않았다.

## 기능 담당 연결 사항 / 남은 범위

이번 공유 코드 파일은 `SpaceExperience.tsx`와 `lounge-labels.css`다. 파일 전체로 덮어쓰지 말고 장소명 링크와 세 장소의 전환 선택 부분만 대조해 합친다. PR #26과 독립적인 main 기준 변경이다. 이전 `cinematic/service-arrival-frame-20261113`의 고정 UI 생성 시안은 최신 결정에 맞지 않으므로 통합하지 않는다.

튜토리얼 실행 여부를 구분하는 전체 동선 상태와 새 영상 플레이어 연결은 이번에 임의로 만들지 않았다. 기존 안내데스크/게이트 셔틀 영상 경로는 보존했다. **기능 담당이 튜토리얼 상태에 따라 영상 경로를 선택하고, 일반 이동은 확대 경로로 보내는 연결이 필요하다.** 이 연결이 완료되었다고 보고하지 않는다. 신규 튜토리얼 영상이 준비되면 도착 UI를 뒤에 준비하고 로고 마지막 장면에서 실제 UI로 약 0.3~0.4초 전환한다. 로딩/오류/건너뛰기에서도 실제 목적지에 접근할 수 있어야 한다.

## 검증

TypeScript/Vite 빌드 및 앱 테스트 14개 파일 통과. 실제 production preview Chromium에서 데스크톱/모바일의 세 장소 글씨 클릭→확대→기존 UI, hover 금색, 박스 없음, 운항 저장값 유지, 표식과 Escape 취소, 키보드 Enter, 관제센터의 같은 색상 및 미션 글씨 이동, 기존 안내데스크 영상 경로, 모션 감소를 확인했다. 검수 결과와 실제 캡처는 `review/`에 저장한다. 실제 휴대폰 기기와 전체 튜토리얼 새 영상 연결은 검증 범위에 포함하지 않는다.
