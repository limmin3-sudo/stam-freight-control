## 실제 연결 / 디자인 / 남은 기능

실제로 동작하는 검토본: 전체5장소 순서, 구간 재생/정지/재개/건너뛰기/다시 시작, 기본 장소별 대기, 검토용 자동 진행, 기존 실제 메뉴 마운트와 안내 지속, 일반 사이드바 사용 시 오버레이 종료, 반응형, 동작 줄이기. 시네마/정보실/서비스센터의 현재 화면을 사진으로 고정하지 않았다.

연출만 완료: 새 가이드 자세5종과 2.5D 카메라/디졸브, 장소 소개 대사, 공용250ms 점등, 게이트에서의 마무리 안내. 새 자세는 최종 사용자 승인 전이다.

기능 담당 연결 필요:

1. 전용 튜토리얼 진입/종료와 현재 라우터를 연결한다. 일반 이동과 튜토리얼을 구분하고 기존 버튼/이벤트/데이터/DOM 식별자를 보존한다.
2. 현재 고정 상단바/사이드바를 유지한 콘텐츠 영역 크기를 제공한다. 이 시안은 iframe 내부의 `.space-topbar`/`.space-sidebar`를 읽는다. 제품에서는 iframe 대신 현재 레이아웃의 콘텐츠 경계 신호를 사용한다.
3. 도착 화면의 준비 신호를 제공한다. 시안의 `requestMenu`/`appHas`는 `cinema`, `information`, `service`와 현재 DOM 클래스를 사용한다. 공용 테마가 바뀌어도 대응하는 안정적인 화면 ID/ready 신호만 유지하면 대사·생성 PNG를 다시 제작할 필요가 없다.
4. 튜토리얼 상태 저장·재개·완료 여부·뒤로가기 정책은 아직 구현하지 않았다. 저장 모델을 이 연출에서 임의 추가하지 않았다.
5. 게이트 이후 기존 승인 셔틀 영상으로 이어지는 연결은 별도 결정한다. 새 투어가 기존 빠른 게이트 이동이나 운항 준비를 자동 변경하지 않는다.
6. 확정 안내 음성·립싱크·자연 보행은 없다. 이 검토본을 실제 보행 애니메이션이나 음성 완료본으로 설명하지 않는다.
