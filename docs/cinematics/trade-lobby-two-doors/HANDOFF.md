# 무역센터 로비 전경 검토

기준은 공통 인계 커밋 `1fdce17`이다. 새 전경 원본, 배치, 강조, 출입 연출은 `apps/control-room/review/trade-lobby/`에 있다. control-room 개발 서버에서 `/review/trade-lobby/`를 열면 직접 조작할 수 있다.

[로비 전경](review/lobby.png) · [무역관제실 강조](review/control-focus.png) · [거래기록실 강조](review/records-focus.png) · [진입과 복귀 MP4](review/control-roundtrip.mp4)

새 원본에는 상담 직원과 방문객, 금속 난간 뒤에서 대화하는 정장·칵테일드레스 차림의 방문객, 관제실 근무자가 포함돼 있다. 수석 무역관과 링 가문 중개인은 상담대 앞의 독립된 선택 영역에 로비 전용 전신 자산을 배치한다. 수석 무역관은 태블릿을 든 채 고개를 돌리고, 링 가문 중개인은 한 손으로 상담 방향을 안내한다. 중개인 전신은 이전 전신 참조 없이 새로 생성한 의상 시안이다. 기존 근접 대화 초상과 얼굴 일치 여부는 승인 단계에서 확인한다. 두 전신 자산은 각각 officer-lobby.webp와 broker-lobby.webp에 있다.

## 승인 후 기능 연결

| 진입 방식 | 연결할 기존 기능 |
| --- | --- |
| 무역관제실 문 | 시세 검색을 첫 화면으로 열고 선택한 거래를 내 함선·보유금액 기반 최적 경로 계산으로 전달 |
| 거래기록실 문 | 실제 매입·판매·잔량·정산 장부 |
| 수석 무역관 대화 후 경로 계획 | 행성계 내부 경로 계획 |
| 링 가문 중개인 대화 후 경로 계획 | 행성계 간 경로 계획 |
| 사이드바 | 선택한 방으로 즉시 이동 |

시안에서 방 선택은 `enter`, 복귀는 `leave`, 파트너 선택은 기존 `CrewEncounter`의 `actions`에서 처리한다. 내부 모니터에는 참고용 화면 캡처를 표시한다. 실제 기능 담당자가 시안 승인 후 현재 라우터의 방·범위 선택과 브라우저 뒤로 가기를 연결한다. 저장 데이터와 계산은 기존 기능에서 관리한다.

## 화면 검증

Chromium 1440×810에서 키보드 포커스·Enter로 두 문을 열고 복귀했다. 터치 에뮬레이션 [1180×820](review/tablet-landscape.png)과 [820×1180](review/tablet-portrait.png)에서 두 문과 두 인물을 각각 선택해 목적지를 확인했다. 세로 화면은 전경 비율을 고정해 위아래에 여백이 생긴다. 두 담당자의 대화에서 범위별 계획으로 넘어가는 동작, 동작 줄이기에서 확대 생략, 빠른 이동 목적지를 확인했다. 태블릿 실기기 검증과 실제 시세·장부 라우팅은 통합 단계에 남아 있다.
