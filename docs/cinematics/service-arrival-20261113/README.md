# 서비스센터 도착 프레임 v1

사용자가 서비스센터 → 정보실 → 영상관의 마지막 프레임부터 준비하자는 제안에 제작을 요청했다. 첫 대상으로 서비스센터 화면을 제작했다.

[영상 마지막 프레임](service-end-frame-v1.png) — PNG 1672×941, 기존 승인 모니터 이미지와 같은 크기. Grok 영상은 16:9로 설정한다. 현재 파일은 사용자 검토용 생성 시안이다.

- 정면 화면과 얇은 금속 모니터 틀만 표시한다. 방/책상/인물 배경과 카메라·패널 기울기가 없다.
- 기본 청록색 유리, 흰색 글자/아이콘, 호박색 로그인 버튼 면을 사용한다.
- 현재 기능 구성에 맞춰 위쪽 계정·최근 완료한 배송, 아래쪽 피드백·오류 신고/업데이트 기록/이용안내를 배치했다. 개인 계정이나 가짜 운송 실적을 넣지 않았다.
- 승인 모니터 프레임, PR #26의 생성 유리 자산, 기존 서비스 화면의 정보 배치를 참조했다. 생성 원본을 이동/삭제하지 않고 복사했다. 해시와 출처는 `record.json`.

## 다음 연결 작업

앱 코드·계정·배송기록·링크·상단바·사이드바는 변경하지 않았다. 이 생성 이미지의 서체·문구·배치가 현재 실제 UI와 픽셀 단위로 맞는 것은 아니다. 사용자가 구도를 확인한 뒤 실제 버튼과 동적 기록을 이 화면 안에 같은 좌표로 배치하는 연출 변경을 따로 준비해야 한다. 앱의 고정 상단바/사이드바는 유지하고 내부 콘텐츠와 영상 표시 영역을 맞춘다. 영상에 고정된 계정/배송 상태를 실제 개인 데이터 대신 표시하는 구조로 통합하지 않는다.

현재 수행한 검수는 이미지 열기, 파일 크기/해시, 한글 내용과 프레임 정렬의 시각 확인이다. 실행 코드 변경이 없어 빌드/기능 테스트는 반복하지 않았다. 이동 영상은 아직 생성/연결하지 않았다. 통합·배포는 기능 담당 범위다.
