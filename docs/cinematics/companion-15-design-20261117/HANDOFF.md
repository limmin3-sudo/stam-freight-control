## 실제 변경

- 창 외곽과 파일 카드: D 검은 유리·금색 프레임 이미지. 연결 창 본문 배경은 승인 사업부 전경 원본(`overview-approved.png`)을 그대로 복사해 적용하고 가독성용 어두운 층만 덧댔다. 오버레이·설정창 배경은 그대로 유지한다.
- 연결 상태: A 금속 매립형 계기판 이미지.
- 공통 버튼: 기존 청록 유리 이미지, 주요/선택 동작은 금색 이미지, 호버 밝기·눌림·키보드 포커스·비활성 글자 구분.
- STAM 원본 로고, **Barlow Medium 500 / SUIT Medium 500** 원본 글꼴 유지. GDI+ DrawString 대신 Windows GDI TextRenderer/ClearType으로 표시한다. 프로세스 내부에만 GDI 폰트를 등록하며 시스템에 설치하지 않는다. Windows GetTextFace/GetTextMetrics로 실제 선택된 두 글꼴과 굵기 500을 검사하고, 대체 폰트면 캡처 검증을 실패시킨다. `review/font-selection.json` 참고. 버튼 글자는 가로·세로 중앙 정렬한다.
- 프레임은 원본 PNG를 런타임 9분할로 표시한다. 선/도형으로 재제작하지 않는다.
- 오버레이 표시/숨김·단축키 설정·마이크 전환을 앱 창에서 기존 핸들러로 실행한다. 트레이 메뉴도 유지한다. 마이크는 기본 꺼짐, 사용자가 켜는 동작을 유지한다.
- 오버레이와 단축키 저장 버튼도 같은 재질을 사용한다. 작은 오버레이에서 두 버튼이 아래로 밀리지 않게 동일 폭으로 배치했다.
- 기본 920×730 클라이언트, 최소 창에서 본문을 스크롤한다. 고정 행 배치를 화면 밖으로 잘라 버리지 않는다.

## 기능 보존 / 수정 파일

- `desktop/Launcher.cs`: 창 배치·버튼 그리기·기존 기능 진입·캡처 전용 모드. 자동 탐색/읽기 전용 수신/재시도/트레이 종료/언어·경로 저장/공개 사이트 주소는 보존한다.
- `desktop/CompanionOverlay.cs`: 표면·버튼 배치·설정창 색상만 변경. hotkey·클릭 통과·12초 개인 표시 만료·음성 명령 허용 목록 유지.
- `desktop/DeckTheme.cs`: 이미지 캐시·원본 샘플링·9분할 렌더링. 파일 핸들을 즉시 해제하고 메모리 이미지는 프로세스 종료 시 정리.
- `desktop/theme/*.png`, `README.md`: 원본 에셋과 출처.
- `scripts/build-desktop.mjs`: 설치 ZIP에 필요한 프레임/버튼 PNG 세 장과 사업부 전경 PNG를 추가. 웹 HTML/웹 앱은 넣지 않는다.
- `desktop/build-windows.ps1`: 새 C# 파일 컴파일과 실제 창 크기별 캡처 연결. 릴리스 게시 단계 추가 없음.
- `tests/companion.test.mjs`: 배포 페이로드에 테마 자산이 포함되는지 기존 검사 확장.

SpaceExperience·웹 디자인·실제 거래/운송 계산·계정·로그 파서·API 프로토콜·운영 규칙·공개 배포 메타데이터는 수정하지 않는다.

## 검증과 남은 범위

로컬 루프백 접근이 허용된 환경에서 로그/상태/산출물 8개 검사를 통과했다. 제한된 샌드박스의 최초 실행에서는 루프백 서버 검사 두 파일이 실패했으며, 허용 환경 재실행은 전부 통과했다. `scripts/build-desktop.mjs`로 검수용 페이로드 생성과 사업부 전경 포함 확인.

최종 Windows 실행 [44099416549](https://github.com/limmin3-sudo/stam-freight-control/actions/runs/44099416549) 성공. C# 컴파일, Node 검사 8개, 번들 Node 실행·계약 수신·읽기 전용, 언어 전환, 닫기→트레이→복원·재시작·설정 보존, 전역 단축키/클릭 통과/개인 표시 만료, 설치/재설치/제거 검사를 통과했다. `review/windows-run.json`, `installer-check.json`, `overlay-native-check.json`이 실제 실행 증거다. 한글·영문 기본/작은 창/스크롤 하단 6장과 오버레이 2장을 `review/`에 보관했다. 기본 창의 불필요한 스크롤과 버튼 뒤 검은 사각 배경을 제거한 최종 캡처다. 이번 폰트·사업부 배경 수정본의 Windows 실행으로 8장 모두 갱신했으며 실제 폰트 선택 검사도 통과했다. 원본 에셋 4개의 동일 SHA는 `assets.json`에 기록했다. 브라우저 시안을 실제 Windows 캡처로 대신하지 않는다. 실제 게임/마이크 입력과 실사용자 계정은 검증 범위가 아니다. 다중 모니터의 실제 125/150/200% DPI와 게임 중 사용성은 현장 확인 대상으로 남긴다.

검수용 Windows ZIP·설치본은 위 Actions 실행의 `STAM-Windows-verification` 아티팩트에 있다. 릴리스 게시가 아니며 Actions 아티팩트 보관 기한 내에 내려받을 수 있다. 공개 앱 1.5 다운로드 링크는 그대로 유지된다.
