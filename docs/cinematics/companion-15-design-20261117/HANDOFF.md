# 로그 앱 1.5 실제 네이티브 디자인

## 기준 / 범위

- 기준: `handoff/local-studio-20261110` / 웹 3.1 인계 `434b50e`, 배포된 `app.1.5.0` 소스.
- 작업: `cinematic/companion-15-design-20261117`.
- 무역 튜토리얼 #40과 독립이다. #40을 선행 병합할 필요가 없다.
- 보류했던 #36 브라우저 시안에서 승인 PNG 세 장만 그대로 가져왔다. 이전 Launcher 전체나 앱 1.4 구조를 복원하지 않았다.
- 새 릴리스 번호/공개 다운로드 메타데이터는 변경하지 않는다. 이번 산출물은 검수용이며 기존 공개 app.1.5.0을 덮어써서 게시하지 말 것. 기능 담당이 별도 버전 결정 후 통합·검증·배포한다.

## 실제 변경

- 창 몸체와 파일 카드: D 검은 유리·금색 프레임 이미지.
- 연결 상태: A 금속 매립형 계기판 이미지.
- 공통 버튼: 기존 청록 유리 이미지, 주요/선택 동작은 금색 이미지, 호버 밝기·눌림·키보드 포커스·비활성 글자 구분.
- STAM 원본 로고, Barlow/SUIT 글꼴 유지. 글자는 네이티브 컨트롤로 표시한다.
- 프레임은 원본 PNG를 런타임 9분할로 표시한다. 선/도형으로 재제작하지 않는다.
- 오버레이 표시/숨김·단축키 설정·마이크 전환을 앱 창에서 기존 핸들러로 실행한다. 트레이 메뉴도 유지한다. 마이크는 기본 꺼짐, 사용자가 켜는 동작을 유지한다.
- 오버레이와 단축키 저장 버튼도 같은 재질을 사용한다. 작은 오버레이에서 두 버튼이 아래로 밀리지 않게 동일 폭으로 배치했다.
- 기본 920×730 클라이언트, 최소 창에서 본문을 스크롤한다. 고정 행 배치를 화면 밖으로 잘라 버리지 않는다.

## 기능 보존 / 수정 파일

- `desktop/Launcher.cs`: 창 배치·버튼 그리기·기존 기능 진입·캡처 전용 모드. 자동 탐색/읽기 전용 수신/재시도/트레이 종료/언어·경로 저장/공개 사이트 주소는 보존한다.
- `desktop/CompanionOverlay.cs`: 표면·버튼 배치·설정창 색상만 변경. hotkey·클릭 통과·12초 개인 표시 만료·음성 명령 허용 목록 유지.
- `desktop/DeckTheme.cs`: 이미지 캐시·원본 샘플링·9분할 렌더링. 파일 핸들을 즉시 해제하고 메모리 이미지는 프로세스 종료 시 정리.
- `desktop/theme/*.png`, `README.md`: 원본 에셋과 출처.
- `scripts/build-desktop.mjs`: 설치 ZIP에 필요한 PNG 세 장만 추가. 웹 HTML/웹 앱은 넣지 않는다.
- `desktop/build-windows.ps1`: 새 C# 파일 컴파일과 실제 창 크기별 캡처 연결. 릴리스 게시 단계 추가 없음.
- `tests/companion.test.mjs`: 배포 페이로드에 테마 자산이 포함되는지 기존 검사 확장.

SpaceExperience·웹 디자인·실제 거래/운송 계산·계정·로그 파서·API 프로토콜·운영 규칙·공개 배포 메타데이터는 수정하지 않는다.

## 검증과 남은 범위

로컬 루프백 접근이 허용된 환경에서 로그/상태/산출물 8개 검사를 통과했다. 제한된 샌드박스의 최초 실행에서는 루프백 서버 검사 두 파일이 실패했으며, 허용 환경 재실행은 전부 통과했다. `scripts/build-desktop.mjs`로 33개 파일 검수용 페이로드 생성 확인.

Windows 네이티브 컴파일·기존 동작·설치/제거·한영 화면 검증 결과는 최종 Windows 실행 증거를 이 폴더에 보관한다. 브라우저 시안을 실제 Windows 캡처로 대신하지 않는다. 실제 게임/마이크 입력과 실사용자 계정은 검증 범위가 아니다. 다중 모니터의 실제 125/150/200% DPI와 게임 중 사용성은 현장 확인 대상으로 남긴다.
