# 반려된 실행 시안 — 적용 금지

사용자가 재질을 원본 복구라고 인정하지 않은 시안이다. 작업 보존을 위해 코드·자산·기준 대비 patch를 보관했다. 기능 담당은 이 폴더를 앱에 복사하거나 patch를 적용하지 않는다. 실제 앱의 GuideDesk/PartnerConversation은 기준 737b957 상태로 되돌렸으며 승인 영상/기능 연결을 보존했다.

이 코드는 새로 생성한 `apps/control-room/src/assets/hologram/unified-glass-*.png`를 사용하지 않는다. 새 자산은 별도로 검토·연결해야 한다. CSS의 상대 자산 경로는 당시 앱 기준이며 보관본은 독립 실행 파일이 아니다.
