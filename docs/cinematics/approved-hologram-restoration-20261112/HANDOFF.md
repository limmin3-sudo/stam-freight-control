# 큰 통합 홀로그램 복원 검수 — 2026-11-12

브랜치 `cinematic/approved-hologram-restoration-20261112`, 기준 `737b9577ec84fb5a443e13a880cf4e27f09fb08e`. 공개 배포는 변경하지 않았다.

## 최신 사용자 정정

큰 패널 **하나** 안에 왼쪽 메뉴·오른쪽 대화를 넣는 기존 합의를 유지한다. 직전 두 패널 검수본은 사용자가 거절했다. 원본 사진은 재질·글자·호박빛 표현의 기준이며 원본 사진처럼 두 패널로 나누라는 뜻이 아니다.

- `guide-hologram-panels.ts`: 기존 `.unified` 하나를 그대로 장식한다. 메뉴/헤더/대화 노드 재배치·교체는 하지 않는다. 기존 ID·이벤트·접근/A-B대기/복귀 영상을 유지한다.
- `approved-hologram.css`: 가이드 왼쪽의 큰 반투명 청록 유리 하나. 독립된 면/테두리/반사 레이어와 호박빛 모서리·구분선. 선택 버튼은 면 전체를 호박빛으로 강조한다. 면 레이어 opacity `.25`와 약한 tint는 유지하되 포인트의 밝기는 독립시켰다.
- 모바일은 하나의 외곽 프레임 내부에서 메뉴 다음 대화를 세로로 배치한다. 가로 넘침 없이 버튼 크기를 유지한다.
- `PartnerConversation.tsx`: 이전 검수의 공통 유리 재질을 유지하고 호박빛 변수도 공유한다.

## 실제 검수 화면

- `review/guide-unified-desktop.png`: 최신 실제 앱 프로덕션 빌드, 1920×1080.
- `review/guide-unified-mobile.png`, `guide-unified-mobile-menu.png`, `guide-unified-mobile-dialogue.png`: 390×844 실제 앱.

## 자산 출처와 한계

[원본 조사](PROVENANCE.md)에 승인 PNG·전체 image_gen 프롬프트와 별도 관제 유리 생성기를 기록했다. 현재 `approved-hologram-skin.png`는 이전 복원 과정에서 image_gen으로 만든 문자 없는 RGBA 재구성 자산이다. 원본의 무손실 분리나 발견한 3D 원본이 아니다. 실제 텍스트는 SUIT이며, 원본 그림의 생성 글자와 정확히 같은 폰트라는 뜻이 아니다. `index.html`·`material-preview.html`은 과거 기준/분리 검토 화면이며 최신 앱 검수 화면이 아니다.

## 기능 경계

공유 파일은 `GuideDesk.tsx`, `PartnerConversation.tsx`의 시각 import/래퍼다. 기존 `guide-desk-controller.mjs`·템플릿·미션·경로·적재·운항·저장 코드는 변경하지 않았다. 기존 CSS/템플릿 재생성 후에도 별도 복원 모듈과 CSS는 유지된다.

최종 시각 사용자 확인, 실물 모바일/GPU 확인은 남아 있다. 서비스센터·정보실·영상관 마지막 프레임과 추가 이동 영상은 이번 수정 범위에 포함하지 않았다. main 병합·배포 없음.

## 최종 검증

TypeScript/Vite 빌드 통과(기존 번들 크기 경고 유지). 프로덕션 미리보기 Chromium에서 외곽 패널이 정확히 1개인지, 선택 버튼의 호박빛 면 fill과 포인트, 투명 면 및 짙은 gradient 제거를 확인했다. 메뉴→정보실, 응답→미션, 안내 텍스트 변경, 접기/펼치기·inert, 일반 동작 설정의 복귀 영상→건너뛰기→라운지, 오퍼레이터/항해사 열기·Esc 닫기 통과. 긴 한글·영문 응답이 패널 안에 들어간다. 390px 모바일 가로 넘침 없음, 버튼 높이 50.7/54.6px. 브라우저 pageerror 없음. 광학 테두리 마스크는 밝기 기반으로 바꿔 내부 사각형 절단 흔적을 없앴다.
