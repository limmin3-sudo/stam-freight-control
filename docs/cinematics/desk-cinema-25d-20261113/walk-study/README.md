# 가이드 세 걸음: 사진 관절 시험

사용자가 기존 2.5D 구성과 수정한 가이드 체형을 확인한 뒤, 실제로 두세 걸음 걷는 동작을 시험하도록 요청했다. 기존 시안을 보존한 후속 브랜치 `cinematic/guide-walk-study-20261113`에서 작업했다. 부모는 PR #32 브랜치의 `b0d8bdb4c676942de820e237c746bf5f3b5e6ea1`이다. main/공통 인계 병합·배포 없음. 기능 담당의 테마·하위 화면 작업은 수정하지 않는다.

## 확인 화면

기존 전용 서버를 사용한다.

```sh
node docs/cinematics/desk-cinema-25d-20261113/server.mjs
```

- 동작 확대: `http://127.0.0.1:5196/docs/cinematics/desk-cinema-25d-20261113/walk-study/`
- 투어에 연결: `http://127.0.0.1:5196/docs/cinematics/desk-cinema-25d-20261113/index.html?walk=1`
- 승인된 기존 정지 포즈 시안: 같은 `index.html`에서 `?walk=1`을 빼면 된다. 걷기 모듈을 불러오지 않는다.

동작 확대 화면에서 세 걸음 재생, 일시정지/계속 보기, 원래 자세, 반복, 라운지 배경 전환으로 비교한다. 모바일에서는 인물에 글씨가 겹치지 않게 안내 제목을 숨긴다. 동작 줄이기 설정에서는 정지 자세를 유지한다. 투어 화면은 4.05초부터 2.04초 동안 세 걸음을 진행한 뒤 두 발을 딛고 멈추며, 기존 입구 안내/실제 시네마로 이어진다.

## 구현한 동작

승인된 `../assets/guide-entrance.png` 하나를 텍스처로 재사용한다. 새 얼굴이나 자세를 프레임마다 생성하지 않는다. 추가 중립 자세의 이미지 생성은 도구에서 거절되어 기존 승인 이미지를 그대로 관절화했다. 원본 PNG는 변경하지 않았다.

- 무릎/발목을 가진 두 다리 메시를 같은 원본 사진에서 구성했다. 피부 텍스처는 관절에 따라 연속적으로 변형된다.
- 접지 중인 발끝은 제자리에 두고, 반대 발은 들어 앞으로 이동한다. 보폭과 몸의 이동량을 같은 시계로 계산한다.
- 실제 뼈 길이를 유지하는 두 관절 계산을 사용한다. 몸은 조금 상하로 움직이고 검은 커버의 반대팔은 작게 흔들린다. 안내하는 손은 원래 자세를 유지한다.
- 치마 위로 피부/검은 조각이 튀어나오는 부분을 클리핑하고, 밑단을 허벅지 위치에 맞게 작게 변형했다. 숨겨진 위쪽 다리 픽셀은 기존 피부 행을 재사용하므로 정확한 신체 재구성은 아니다.
- 머리/얼굴/상체는 같은 이미지와 UV, 원래 축척을 유지한다. `requestAnimationFrame`과 관절 행렬로 움직이며 캐릭터 동영상·새 PNG 프레임 열을 재생하지 않는다.

한 장의 사진에 관절을 넣은 시험이며 실제 3D 인체/모션캡처가 아니다. 가까이서 보면 종이인형이나 치마가 늘어나는 느낌이 남을 수 있다. 원본은 앞·측면을 약하게 섞은 안내 자세라 자연스러운 뒷모습 회전/여러 방향 걷기를 제공하지 않는다. 눈깜빡임/립싱크/최종 음성도 범위 밖이다. 자연스러운 최종 동행 연출로 확정하지 말고 사용자의 동작 검토를 먼저 받는다.

## 변경 파일

- `walk-solver.mjs`: 발 교대·접지·공중 이동·이동 거리·두 관절 계산.
- `photo-walk-rig.js`: 원본 사진 UV, 관절 메시/팔/치마, 원본 자세 복귀.
- `index.html`, `study.js`: 독립 동작 확대/라운지 비교 화면.
- `walk.test.mjs`, `review/verify-walk.mjs`: 실제 접지/길이/렌더링 행렬과 브라우저 동작 검증.
- 부모 폴더 `tour.js`: `?walk=1`일 때만 모듈을 지연 로드하여 기존 카메라 동선에 연결.
- 부모 `index.html`, `tour.css`: 검토용 걷기 링크. 기본 시안 연출은 유지한다.
- `PROJECT_STATUS.md`, README/출처·검증·녹화: 인계 기록.

현재 앱/계약/계산/저장/계정 파일이나 자산은 수정하지 않는다. 실제 메뉴는 부모 시안과 동일하게 현재 로컬 앱 빌드를 읽는다. 기능 담당에게 운영 앱에 iframe을 중첩하라는 변경 요청이 아니다.

## 검증

`node --test docs/cinematics/desk-cinema-25d-20261113/walk-study/walk.test.mjs` 통과. 세 가지 검사 항목: 세 번의 교대 착지 후 두 발 접지, 접지 중 발 위치/다리 길이 불변, 실제 렌더 뼈 행렬의 발끝과 계산 목표 일치/머리·상체 UV·축척 보존.

실제 Chromium에서 재생/멈춤/계속/반복/원래 자세/두 발 정지, 390px 넘침 없음, 동작 줄이기, 승인된 모니터 없는 배경, 투어 선택 연결 및 기본 시안의 걷기 모듈 미로드를 확인했다. 페이지 오류·누락 자산 없음. 사진의 자연스러움은 수치 검사로 보장하지 않는다. 실제 기기/GPU 검증은 별도이며 소프트웨어 녹화 수치는 결과 파일을 따른다.
