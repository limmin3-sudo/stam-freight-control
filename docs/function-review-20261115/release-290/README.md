# beta 2.9.0 / 로그 앱 1.4 배포

사용자 승인: 사이트와 로그 앱 함께 공개. 미커밋 기능을 보존하고 기존 라운지 투어를 유지한다.

- 루트 271 + 앱 88 = 359 테스트 통과, 타입 검사·생산 빌드 통과.
- 배포 조립본의 합성 계정 이어하기·충돌·자동 저장·자료실·지도·모바일 확인: `cloud-browser.json`.
- 실제 loopback 앱 API와 Worker의 합성 로그 자동 수신·재연결·수신함/운항 보존 6항목 통과.
- Firebase 운영 규칙 게시·실제 임시 계정 검증은 `../cloud-production/`의 완료 결과를 따른다. 이번에 실제 사용자 자료를 사용하거나 수정하지 않는다.
- 로그 앱 1.4의 Windows 검증 소스와 현재 패키지 관련 35파일 일치. 직접 uploads API 인증 오류로 GitHub의 기존 Windows package workflow에서 재빌드·검사·게시한다. 공개 파일의 최종 해시는 CI 메타데이터와 실제 다운로드로 확인한다.

Windows 사용자 PC 고배율·실게임 장시간 검증은 사용자가 보류한 항목이다. 확정 음성·립싱크·자연 보행·게이트 이후 셔틀 연결·투어 저장/재개는 연출 후속이며 이번 배포에서 완료로 취급하지 않는다.
