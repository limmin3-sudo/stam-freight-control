# 퀀텀 드라이브 자료와 계산

출처: [Star Citizen Wiki API](https://api.star-citizen.wiki/api/items?filter%5Btype%5D=QuantumDrive). 개별 레코드의 sourceUrl도 유지하고 선택 화면에서 링크한다. 2026-11-04 공개 API 두 페이지의 총57건과 수집 개수가 일치했다. S1 20개, S2 20개, S3 15개, S4 2개. A10/B19/C19/D9. 버전은 4.10.2-LIVE.12881860이다. 게임 실행 파일·메모리·패킷·한글 패치 파일은 사용하지 않는다.

`data/ship-performance.json`의 슬롯 크기/performanceId와 대조해 같은 크기만 후보로 보여 준다. API 슬롯 대응은 모든 기체의 실제 교체 제한이나 상점 재고를 증명하지 않는다. 현재 게임 버전/장착 상태도 별도 확인이 필요하다. 새 목록의 버전이 기존 함선 자료와 다르면 개별 선택을 적용하지 않는다.

`node scripts/refresh-quantum-drives.mjs`로 갱신한다. HTTP 오류·페이지 누락/반복·총수 변화·중복 ID·다른 출처·버전 혼합·누락된 성능은 저장 전에 중단한다. 새 파일 준비 후 교체하며 실패 시 기존 자료를 유지한다. 자동 매일 갱신은 아직 설정하지 않았다.

예상시간은 기존 travel.mjs의 2단계 가속/감속과 드라이브 최고속도·준비·재사용 대기를 사용한다. 기존 구간 준비 여유25초는 별도 계획 가정으로 유지한다. SCM 기반 지상 접근 평균65%, NAV 기반 우주 접근 평균65%, 접근 거리/정박 시간도 가정이다. 현재 질량·전투·기상·서버 지연·정확한 기체 가속은 재현하지 않는다. 예약 항로에서는 상자 구성/작업량을 모르는 만큼 상하차 시간을 합산하지 않는다.

함선별 설정은 기존 vh-ship-performance 키를 사용해 기존 계정 동기화 범위 안에 남긴다. 로그 원문·계약·개인 ID는 추가 저장하지 않는다. 현재 Windows 실게임 시간/GPU 부하 및 실제 두 기기 계정 복원은 최종 검증 대상이다.
