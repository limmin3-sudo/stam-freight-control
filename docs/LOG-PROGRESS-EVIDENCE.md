## 연결 규칙

- 본인으로 대응한 EndMission 또는 로컬 HUD 완료/실패만 완료 결과로 표시한다. 타인 종료는 제외하고, 식별 불가 종료는 결과 미확인으로 둔다. 상충하는 종료/플레이어/정의 관측은 확인 필요로 남긴다.
- 목표 상태와 SCU 알림은 실행 계약 ID+목표 ID로만 결합한다. 마지막 알림을 보여 주고 합산하지 않는다. 수량 역행/총량 변경/동시 충돌은 수량 확정을 막는다.
- 픽업 완료가 함선 aboard를 증명하지 않는다. 목표 완료도 계약 전체 완료를 증명하지 않는다. 실제 남은 상자와 원래 주문량, 예상 항로 이동은 구분한다.
- 진행 갱신은 원래 명세의 계획 서명을 바꾸지 않는다. 실제 수요/상태 충돌과 계약 종료는 기존 계획 선택 규칙을 따른다. 종료 계약의 자동 선택만 해제하며 명시 선택을 지우지 않는다.
- 지급은 정확히 일치하는 실행 ID가 있을 때만 해당 계약 제목을 연결한다. 현재 제공 로그의 5건은 모두 미배정이다. 앞선 완료/제목/금액으로 귀속하지 않는다. 계정 수입/운항 기록에는 자동 저장하지 않는다.
- 재독해·백업의 같은 시각/금액/알림 번호/계약 ID는 중복 억제한다. 다른 알림 번호는 같은 시각·금액이어도 구분한다. 원문을 저장하지 않으며 메모리 이벤트 한도는 그대로다. 세션 간 영구 보관은 아직 미완료다.

## 검증과 남은 작업

`tests/log-progress.test.mjs`: 같은 유형 두 실행 계약, 본인/타인, 종료 충돌, 수량 역행, 중복 지급, 잘못된 금액, 목표 갱신 시 원래 계획 유지, 종료 뒤 수락 복귀 차단.

`scripts/check-progress-browser.mjs`: 실제 로컬 수집기에 합성 로그를 추가해 화면 갱신·계약 분리·종료 선택 해제·펼침 유지·지급 미배정/정확한 ID 대응·중복 억제·계정 기록 무변경·대기 중 캔버스0·모바일390px을 확인한다.

실제 운항의 잔여 화물/실린 위치와 경로 재계산, 세션 영구 복원, 보상 귀속 및 통계 자동 기록은 남았다. 합성 검증은 실게임 검증을 대신하지 않는다. [최종 실게임 목록](FINAL-GAME-VALIDATION.md)의 C03/C04/C06을 따른다.
