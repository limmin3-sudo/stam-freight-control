# 아카데미 내부 모니터 화면 · 2026-11-17

사용자 승인 범위는 운송 정보실·교육실·작전 연구실의 **내부 화면**이다. 이동·전환 연출은 별도 담당에게 남겼다. 새 자산/영상 생성, 클라우드 재구현, 서버 규칙 게시, 배포는 하지 않았다.

## 화면

- 무역센터와 같은 승인 `console-screen-only.png` 모니터 테두리, `glass-ui-approved.png` 버튼, 청록빛 유리·금빛 강조, Barlow Medium 500 + SUIT 500을 사용한다. 기능 입력·내용은 실제 DOM이며 화면 전체를 축소하지 않는다.
- 운송 정보실: 자료 카드와 미션/함선/화물 조회, 노하우, 패치 유의사항, 출처 대조를 모니터 안에 유지. 함선/화물 목록과 상세 자료를 구분하고 관련 미션 이동은 이 방 안에서 연결한다.
- 교육실: 왼쪽 검색·주제·현재 탭 읽음 상태와 오른쪽 학습 내용을 분리한다. 본문은 18px, 줄간격 1.9를 유지한다. 기존 7항목의 출처·읽음 표시·초반 미션 조합 필터·후보/선택 비교를 보존한다.
- 작전 연구실: 사례 설명·함선·총량·계약 선택을 정리하고 넓은 화면에서는 6계약을 세 열로 배치한다. 계산 후 비교 결과 제목으로 포커스와 스크롤을 이동한다. 전략별 지표·방문 선택·지도/적재·상자 선택·유의사항은 유지한다.
- 모바일은 한 열과 두 열 메뉴로 전환한다. 사이트 상단바·사이드바를 중복 생성하지 않고 로비 복귀/Escape 포커스 복원과 동작 줄이기를 유지한다.

## 구현 경계

- `FacilityLobby.tsx`: 기존 무역센터에서만 켜던 `data-monitor`를 아카데미의 선택된 방에도 사용한다. 같은 컴포넌트·저장 인스턴스와 기존 로비를 유지한다.
- `trade-monitor.css`: 승인 프레임·기본 글꼴·헤더·스크롤 규칙을 공유한다. 이번에는 설명 주석만 정정했고 무역 전용 제어 스타일은 그대로다.
- `academy-monitor.css`: 아카데미에만 적용되는 화면 배치. 아카데미 외부의 아카이브·무역 화면에 스타일을 퍼뜨리지 않는다.
- `AcademyLessons.tsx`: 기존 필터와 본문을 별도 영역으로 묶음. 읽음 저장 방식/내용 변경 없음.
- `AcademyStudy.tsx`: 조건/결과 영역 구분과 계산 결과 포커스. 엔진·Worker·실제 사례 수량·저장 로직 변경 없음.

기존 실제 사례 6계약/363 SCU, 통합 1회/계약별 11회 점프는 계산 결과다. 실측 소요·평판 효율·게임 성공 기록으로 바꾸지 않았다. 원본 개인 로그 공개나 실제 운항/교역 수정도 하지 않는다.

## 확인

타입 검사·생산 빌드 통과. Chromium에서 승인 프레임/폰트, 검색·읽음 표시·조합 선택, 6계약 계산/지도/적재, 관련 미션, 로비/포커스, 1366×768·영어 390px·동작 줄이기, 운항 저장 불변, 기존 무역 모니터 연결을 확인했다. 브라우저 오류 0건. 결과와 화면은 [runtime-review/academy-report.json](runtime-review/academy-report.json)에 보관했다. 교육실·작전 연구실·모바일 캡처도 직접 확인했다. 서버/전체 계산 테스트는 반복하지 않았으며 실게임 검증은 아니다.

실행: `npm run build --prefix apps/control-room`, `STAM_ACADEMY_URL=http://127.0.0.1:5190/ STAM_ACADEMY_REVIEW=docs/academy-monitor-20261117/runtime-review node scripts/check-academy-browser.mjs`.

## 연출 인계

두 센터의 내부 도착 화면은 기능 쪽에서 준비했다. 연출은 **로비에서 각 방으로 진입하고 이 화면에 도달하는 이동·전환 및 복귀**를 연결한다. `SpaceExperience.tsx` 전체 덮어쓰기, 기능 화면 재작성, iframe 격리, 저장 구조 변경은 하지 않는다. [공통 인계 문서](../academy-cloud-20261117/CINEMATIC-HANDOFF.md).
