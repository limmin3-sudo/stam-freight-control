## 실제 보완

- 운송 미션과 무역 계획의 공통 함선 선택에 검색 추가. `갤럭시`, `Galaxy`, `갤럭시 화물`, 실제 모듈 class 이름으로 검색할 수 있다. 리버레이터도 한글/영문 검색 가능.
- Galaxy의 기본/화물/의료 구성을 명확한 이름과 SCU로 구분하고, 실제 장착 구성 선택 안내를 표시한다. 한국어 모드는 해당 이름을 한글로, 한/영·영어 모드는 영어로 표시한다. 저장 ID는 그대로다.
- 검색으로 현재 선택이 조건에서 빠져도 별도 ‘현재 선택’ 그룹에 유지한다. 검색만으로 함선·용량·실제 운항을 바꾸지 않는다. 기존 사용자 함선도 유지한다.
- 아카이브·아카데미가 공유하는 함선 자료에도 같은 검색·모듈 설명 적용. 무역의 적재 가능한 함선 결과에도 같은 구성 명칭 사용.
- 신규 설명은 공통 Barlow/SUIT 500, 최소14px, 일반 자간. 기존 미션 CSS의 작은 Oxanium 캡션 스타일이 새 안내를 덮지 않도록 범위를 지정했다.
- 선체 이미지·새 버튼 에셋·공간 연출·사이드바는 수정하지 않았다. 앞선 미커밋 공동 교역·시세·정산 개선도 보존했다.
