# 무역센터 내부 모니터 화면 · 2026-11-17

사용자 범위: **무역센터 내부 화면은 기능 담당, 방으로 넘어가는 이동·전환은 연출 담당**. 이번 작업은 시장정보실·교역 계획실·무역 관제실의 도착 화면이다. 아카데미 화면/클라우드 구현/운영 서버 규칙/배포 범위를 추가하지 않았다.

## 적용

- 기존 `console-screen-only.png` 승인 프레임을 9분할 테두리로 재사용한다. 작업 화면에 방 배경·책상·로비 표식을 중첩하지 않는다. 원본 로비는 복귀 시 그대로 표시한다.
- `glass-ui-approved.png`의 기존 ApprovedGlass 버튼, 청록빛 유리 재질, 금빛 선택 표시, Barlow Medium 500 + SUIT 500을 사용한다. 새 에셋을 생성하거나 미승인 시안을 적용하지 않았다.
- 사이트 상단바·사이드바는 각각 하나만 유지한다. 제목/로비 복귀와 기존 교역 화면 전환, 계정 이어하기를 모니터 안에 배치한다. 입력은 실제 DOM이며 화면 전체를 이미지처럼 축소하지 않는다.
- 시장정보실: 품목 탐색과 시세/거점 자료 영역을 분리. 시세 기록·관심 가격·출처 대조 기능 유지.
- 교역 계획실: 두 파트너, 새 계획/저장 경로/시세 도구, 교역 조건을 구분. 위험·위법·예비금과 세부 조건·계산·계획 검토·인계 기능 유지.
- 무역 관제실: 현재 위치·자본·실현 손익·선내/보관 수량을 위쪽에 표시하고 지도/적재를 함께 배치. 그 아래 재고 관리와 실제 거래 기록, 거래 이력·백업 순서로 구성. 좁은 화면은 한 열로 전환한다.
- 이전 교역 기록도 같은 모니터 안에서 계속 이용할 수 있으며, 확장 화면 복귀 버튼에 같은 승인 유리 에셋을 적용했다.

## 연결 경계

`FacilityLobby.tsx`의 `data-monitor`는 **무역센터에서 방을 선택했을 때만** 켜진다. `trade-monitor.css`는 이 범위에만 적용된다. 기존 모듈을 재마운트하거나 저장 계층을 바꾸지 않고 로비 영역의 도착 화면을 바꾼다.

`TradeSuite.tsx` 변경은 화면 묶음/배치와 최신 계정 저장 안내 문구다. 장부 모델·가격 계산·Worker·확인 트랜잭션·운항 저장·클라우드 전송은 변경하지 않았다. `TradeWorkspace.tsx`는 기존 복귀 버튼의 승인 에셋만 추가했다.

연출은 기존 로비 → 방 접근 → **이 모니터 도착 화면**으로 연결하면 된다. 본 작업에서 새 이동 영상, 카메라 이동 시퀀스, 임시 둘러보기는 만들지 않았다. 기존 패널 닫기/동작 줄이기와 Escape 포커스 복원은 유지한다.

## 검증

타입 검사·생산 빌드와 실제 Chromium의 세 방 화면/입력/거래 확인/기존 교역/모바일 검증을 통과했다. 결과는 `runtime-review/report.json`, 이전 교역 회귀는 `runtime-review/legacy-report.json`에 기록했다. 화면 변경에 맞춘 검증이며 이미 검증한 서버 규칙/전체 계산 테스트를 반복하지 않는다. 합성 거래이며 실게임·운영 계정 검증은 아니다.
