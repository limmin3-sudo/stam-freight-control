## 아직 없는 타사 기능

- 공개 함대 검색·모집, 실시간 채팅, 오피서 권한 위임, 여러 함선을 한 번에 배분하는 함대 전체 경로 최적화.
- 외부 공개 시세 제출, 공개 거래 게시판, 앱이 닫힌 상태의 푸시 알림.
- 게임 내 오버레이, 전역 단축키/음성 제어, 로그만으로 실제 거래를 자동 확정하는 기능.
- UEX와 동일한 서버 예측 수요 모델. 현재 주간 평균이나 사용자가 입력한 보충률 시나리오는 이 모델과 다르다.
- 비공개·비활성 거점은 검증된 LIVE 거래소처럼 노출하지 않는다. 가용성을 확인할 원천이 필요하다.

## 사용자 확정 구성 원칙

기능을 임의로 없애지 않되 한 화면에 모두 펼치지 않는다. 사용자 작업 순서에 맞춰 필요한 정보와 조작을 가까이 두고, 공용 테마·폰트·에셋을 유지한다. 선택 항목은 접어도 입력값과 기능이 보존되어야 한다. 정책·권한·정산 방식이 불명확하면 사용자에게 질문한다.

추천하는 다음 화면 정리: 개인 교역은 현재 화물·가격 비교·다음 거래, 공동 교역은 내 담당 화물·다음 작업·상태 변경을 중심으로 둔다. 함장에게는 미처리 승인 건수를 보여주고, 정산은 마감 단계에 펼친다. 원가·개인별 비율·전체 이력은 상세에서 확인한다. 이는 후속 구성 권고이며 이번 서버 연결에서 해당 재배치까지 완료했다고 보고하지 않는다.
