## 검증 범위

`scripts/check-crew-cloud-production.mjs`는 명시적인 `STAM_PRODUCTION_QA=approved` 설정에서만 실행한다. 서로 다른 임시 Firebase 계정 두 개와 현재 작업본 앱의 실제 브라우저 SDK를 사용한다. 별도의 새 브라우저 로그인으로 기기 간 복원도 확인한다. 실제 사용자 계정/문서를 읽거나 변경하지 않는다.

네트워크 환경 때문에 브라우저 요청은 로컬 루프백 프록시를 경유하지만 upstream TLS를 검증하고 실제 Firebase 응답을 그대로 사용한다. Firestore 에뮬레이터나 모의 SDK 결과가 아니다. 테스트 계정의 합성 거래이며 게임 내 매입·판매·송금, Google 로그인 팝업을 검증한 것은 아니다.

**최종 11항목 통과, 브라우저 오류 0건.** 출자60/40, 매입80, 매출120, 비용3에서 이익37을25/75로 배분해 최종69.25/67.75 aUEC를 확인했다. 시험 교역1개와 하위 문서2개, 각 계정 문서 및 임시 인증 계정2개를 삭제했다. 초대 코드는 시험 중 폐기했으며 잔여 임시 계정 저널0건을 별도로 확인했다. [정산 화면](shared-settlement.png).

최종 결과와 임시 계정·문서 정리는 [실제 서버 검증](production-browser-check.json) 기준이다. 서버 저장 완료는 명시적인 서버 읽기와 조건 재검사로 기다린다. 테스트 도중 비동기 조건이 완료되기 전에 다음 단계를 실행했던 대기 코드도 수정했다. 이 대기 코드 문제를 제품 장부 손상이나 서버 권한 실패로 분류하지 않는다.
