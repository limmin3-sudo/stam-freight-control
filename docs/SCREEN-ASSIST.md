# 화면 보조 감시

기본 로그 수집과 독립된 선택 기능입니다. 사용자가 OS 화면 공유에서 창을 선택하고 브라우저 미리보기에서 알림/계약 수 영역을 지정합니다. 게임 파일·메모리·입력·네트워크 패킷에 접근하지 않습니다. 게임사의 공식 허용 확인을 뜻하지 않으며 로그/화면 도구의 정책 범위 검토는 계속 유지합니다.

## 구현

- `screen-watch.mjs`: 한 캡처 스트림, 4초 간격, 최대 960×480 영역, 32×16 변화 비교. 화면 변화가 없으면 OCR을 건너뜁니다. 하나의 Worker만 사용하고 읽기 10초 초과 시 중단합니다. 게임 화면 해상도가 바뀌면 기존 영역을 재사용하지 않고 재지정을 안내합니다.
- `screen-reader.mjs`: 별도 구 번역/게임 데이터 없이 Tesseract.js 6.0.1 / core 6.0.0 / eng·kor 데이터 1.0.0을 로컬 Worker에서 사용합니다. 인식 원문·이미지 전송/영구 저장 없음. 첫 활성화 때만 고정 URL의 자산을 준비하고 이후 SHA-256/길이 검증 후 재사용합니다. 서버는 이미지나 텍스트 요청 본문을 받지 않습니다.
- `screen-evidence.mjs`: 일정 신뢰도 이상의 명시적 수락 문구 또는 Accepted/Active/진행 중 (N/M)만 후보로 읽습니다. 첫 개수는 기준선이며 이후 증가분을 로그 수락 건수와 나란히 표시합니다. 개수 일치만으로 계약을 확정하지 않습니다.
- 제목과 수락 시각 ±30초가 모두 일치하는 유일한 기록만 대조 표시합니다. 여러 로그/화면 후보가 같은 계약에 대응하면 보류합니다. 같은 시각의 수락 로그가 있지만 OCR 제목이 다르면 화면 제목만 보류하고 이미 등록된 계약을 미수신으로 표시하지 않습니다. 시각 일치만으로 같은 계약이라 판정하지 않습니다. 수락/공유/실행 계약 ID를 화면 제목으로 새로 만들거나 기존 ID에 병합하지 않습니다. 물류 계산은 LogEvidence와 별도로 유지됩니다.
- 공유 종료·사용자 중지·페이지 이탈 시 캡처/Worker를 정리합니다. 로그 교체 시 화면 기준선을 초기화합니다. 로그 감시가 멈추면 화면 읽기도 대기하며 누락을 확정하지 않습니다.

## 한계와 남은 일

실게임 알림 인식률, Windows/게임 동시 성능, 브라우저 백그라운드 캡처는 미확인입니다. 4초보다 짧은 알림, 화면이 가려짐, 매우 작은 영역 변화, 읽기 실패는 놓칠 수 있습니다. 인식되지 않았다는 이유로 계약이 없다고 판정하지 않습니다. 한국어 수락 문구의 다른 번역판과 실제 진행 중 헤더는 샘플을 통해 추가할 수 있습니다. OCR은 화물 명세를 자동 입력하지 않으며, 후보 제목은 원문 없는 검증 요약/계정 저장에서 제외합니다.

## 인식 도구 출처·라이선스

파일은 변경 없이 다운로드하며 원본 소스의 헤더를 보존합니다. 저장소에는 자산 목록/해시만 저장하고 `vendor/screen/`은 Git에서 제외합니다. 첫 준비에 원본 라이선스 파일도 함께 저장합니다.

- [Tesseract.js](https://github.com/naptha/tesseract.js), 6.0.1 — Apache-2.0. `vendor/screen/tesseract-LICENSE`.
- [Tesseract.js-core](https://github.com/naptha/tesseract.js-core), 6.0.0 — Apache-2.0. `vendor/screen/core-LICENSE`.
- [Tesseract trained data](https://github.com/tesseract-ocr/tessdata), [배포 데이터](https://github.com/naptha/tessdata) — 모델 Apache-2.0 (`vendor/screen/data-LICENSE`); npm 배포 패키지는 MIT로 명시되어 있습니다. 패키지의 JS 코드를 가져오지 않고 eng/kor traineddata 파일만 사용합니다.

다운로드 URL·버전·SHA-256: `data/screen-reader-assets.json`. 약 11 MiB, 사용자 활성화 전 다운로드/Worker/캡처 없음. 번역 파일이나 Star Citizen 원본 데이터와 무관한 일반 문자 인식 모델입니다.
