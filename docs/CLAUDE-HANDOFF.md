## 경로·적재에서 되돌리면 안 되는 결정

- **운송 미션 제한시간은 없다.** deadline 입력·표시·OCR 추출·AI 스키마/프롬프트·점수를 제거했다. 예전 저장 데이터의 deadlineAt도 적용하지 않는다. 비행 예상시간·수익률·사용자가 누르는 운항 타이머는 별개 기능이다.
- **재방문 최소화가 최우선**이다. 같은 거점에서 내릴 것을 내리고 실을 수 있는 화물을 싣고 떠난다. 가능한 한 배송지를 모으고 불필요한 항성계 왕복을 피한 뒤 **거리 → 시간**으로 비교한다. 용량 초과·상자 제약·반대 방향 계약 등으로 필요한 재방문은 허용한다.
- 16거점 이하 비순환 문제는 단일 방문 조건의 정확 탐색, 작은 순환 계약은 재방문 상태 탐색, 큰 문제/그리드 제약 등은 제한된 후보 탐색이다. **모든 규모에서 전역 최단·재방문 0을 보장한다고 말하지 않는다.** route-cost.mjs / route-search.mjs / engine.mjs / route-only.mjs / route-estimate.mjs 참조.
- 계약·shipment·box 소유권과 진행 중 aboard 위치를 보존한다. 같은 상품/크기라도 다른 계약 화물로 대체하지 않는다. 목적지별 `gridWalk`·`fullLoadLayout`·`zones`를 유지하고 번호 순 채우기로 되돌리지 않는다.
- 상자 구성 유형은 **품목·SCU 조합** 기준이다. 발주처·제목·장소·게임 버전을 다시 키에 넣지 않는다. 앱 화면에 계약 코드를 주 표시로 노출하지 않는다.
- 게이트웨이 경유와 항성계 점프는 경로 노드에서 추출해 한 묶음으로 안내한다. 실제 게임의 정밀 물리 시뮬레이션을 구현한 것은 아니다.
- 지도 라그랑주 이름은 MIC-L1 / ARC-L4 같은 짧은 코드로 표시한다. 원본 검색 지명은 유지한다. 은하 지도에 경로가 없거나 같은 항성계 경로만 있으면 항성계 연결선 0개, 실제 경로가 쓰는 점프 연결만 표시한다. route-display.mjs / starmap.mjs 참조.

## 업데이트·계정·검증

- 새 버전 알림·업데이트 버튼·변경 기록이 이미 배포돼 있다. updates.mjs가 약 1분 간격/창 복귀 시 version.json을 확인한다. 열린 상세창·OCR 처리 중·저장 실패 시 업데이트를 막는다.
- 향후 사용자 기능 변경은 data/releases.json 맨 앞에 기록한다. CI의 scripts/build-release.mjs가 배포 복사본의 HTML/로컬 모듈/데이터/자산 주소를 커밋 버전으로 통일한다. 소스 체크아웃을 직접 stamp하지 않는다. 업데이트 시 localStorage를 지우지 않는다.
- Firebase 로그인/동기화는 **이미 구현·연결**돼 있다. 사용자의 과거 Google 로그인 성공 및 이전 Claude의 가입/동기화 검증 기록이 있다. 공개 웹 설정만 Git에 있고 비밀키는 없다. 이번 Codex UI 작업에서 실제 Firebase 로그인/기기 간 동기화를 다시 검증했다고 말하지 않는다.
- 마지막 브라우저 검증: 데스크톱/모바일에서 버튼 위치·다섯 요약(검증용 수익 7,147,500 aUEC)·가로 넘침 0, 모드 진입/복귀, 타이머 자동 시작 없음·실행 중 since/진행/상자 위치 유지, 계정 창에서 기록 열기. 계정 기록 로컬 검사는 SDK를 중단한 게스트 경로로 수행했으며 실계정 로그인 검증이 아니다. 실제 배포에서도 모드 진입·요약·기록 제거·업데이트 기록을 확인했고 페이지 오류 0이었다.
- 앞선 독립 경로 대조 360건 일치, 51종 함선 적재 109건/상자 4,218개 검사, 실제 브라우저의 계약 5개/진행 인덱스 1/실린 상자 6개 위치 복원도 통과했다. 자세한 범위는 PROJECT_STATUS.md에 있다. 사용자 개인 브라우저나 미확정 실제 스샷을 검증한 것으로 확대 해석하지 않는다.
- Cloud 전용 추가 스크립트/캡처는 Git 밖에 보관했고 다음 PC로 자동 전달되지 않는다. 코드와 문서만으로 시작하고 추가 재현이 필요하면 새 환경에서 만든다. 원본 사용자 스크린샷/비밀값은 커밋하지 않는다.
