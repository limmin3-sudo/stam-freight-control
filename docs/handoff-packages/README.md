# 로컬 인계 보관 묶음

사용자 요청에 따라 `stam-local-update-20261111.zip`도 GitHub 작업 브랜치에 보관한다. SHA-256은 함께 있는 `.sha256` 파일에 있다.

**최신 브랜치를 받은 경우 ZIP을 다시 적용하지 않는다.** 저장소의 소스·자산·인계 문서에 이미 같은 작업이 반영돼 있다. ZIP은 이전 기준 커밋 `50272b880242d4eeabd610b78dc7b963e4e3b6e4`에 대한 변경 묶음이며 전체 저장소가 아니다. ZIP 안의 '아직 푸시하지 않음' 기록은 묶음 생성 시점 기록이다.

현재 전달 방법은 `handoff/local-studio-20261110` 브랜치를 직접 받는 것이다. [최신 로컬 인계](../LOCAL-CODEX-HANDOFF.md)를 따른다. 사용자가 ZIP을 따로 다운로드하거나 기존 작업 폴더에 덮어쓸 필요가 없다.
