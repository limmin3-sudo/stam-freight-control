# 原본 영문/숫자 형태 대조 — 미확정

사용자는 생성된 투사형 개념도의 글씨가 꼭 필요하다고 명시했고, 임시 적용된 Jura의 숫자를 특히 싫어한다고 반려했다. Jura 파일과 활성 CSS/배포 라이선스 목록에서 Jura를 제거했다. 과거 문서의 Jura 적용을 승인으로 취급하지 않는다.

`comparison.png`: 왼쪽은 사용자 선택 개념도와 그 이미지의 실제 부분 확대이며, 오른쪽은 실제 글꼴 세 개다. 01 Roboto Condensed Light, 02 Barlow Light, 03 Barlow Semi Condensed Light. 글자/숫자와 같은 문자열을 렌더링해 비교한다. 사용자가 02 Barlow Light를 선택한 뒤 굵기를 올려 보라고 요청했다. 후속 `../barlow-medium/`은 같은 Barlow 계열의 실제 Medium 500 검토 캡처다. 이미지 생성 글자에 원본 폰트 파일이나 정확한 폰트 이름이 있다고 주장하지 않는다.

`specimen.html`은 저장소 안 폰트와 개념도를 상대 경로로 참조한다. 원본을 대체해 다시 그린 글자를 원본이라고 표시하지 않는다.

DEV 미션 콘솔에서만 `typeface=air|grotesk|semi`로 후보를 대조할 수 있다. 사이드바/상단바의 기존 승인 폰트에는 적용하지 않는다. 고정 메뉴 검토 캡처의 영문/숫자는 후보 01을 임시 표시한 것으로 최종 서체 확정이 아니다.
