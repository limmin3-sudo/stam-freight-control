# Barlow Medium 500 적용 검토

사용자가 폰트 비교 2번 Barlow Light를 선택하고 두껍게 해 보라고 요청하여 실제 Medium 500 파일을 적용했다. 전체 디자인/새 굵기/배포까지 최종 승인된 상태는 아니다.

- `projection.png`, `chip.png`: 고정 상단바/사이드바를 포함한 실제 미션 콘솔 1920×1080.
- `projection-numbers.png`, `chip-numbers.png`: 같은 화면의 운송 요약 영역 확대 캡처.
- `font-check.txt`: 실제 Medium 폰트 face 로드, 계산된 500 굵기, 합성 굵기 없음, 사이드바 SUIT 550 유지, 런타임 오류 없음.

두 안 모두 동일 합성 계약 2개/40 SCU/보상 73,500 aUEC다. 영문/숫자는 Barlow Medium, 한글은 SUIT 500. 고정 메뉴의 글꼴·외형은 그대로 유지했다. 새 두 미션 재질의 DEV 검토 기본값만 바꾸며 다른 화면의 테마를 확정하지 않는다.
