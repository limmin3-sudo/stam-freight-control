# 투사형 / 유리 칩형 실제 미션 콘솔 구현

사용자가 두 개념도 모두 실제로 구현하여 비교하라고 요청했다. 검토용 구현이며 아직 디자인 선택/전체 적용/배포 승인은 없다.

- `projection-1920.png`: 투사형. `/?material=projection#/mission?lang=ko`.
- `chip-1920.png`: 반듯한 유리 칩형. `/?material=chip#/mission?lang=ko`.
- 두 화면 모두 실제 DOM, 동일 계약 2개/40 SCU/73,500 aUEC, 수석 항해사, Cutlass Black, 로빌 출발. 1920×1080 배율 1 Chromium.
- 폰트는 얇은 Jura(영문/숫자) + SUIT(한글). 생성 이미지의 글자에 특정 폰트명이 있다고 단정하지 않는다.
- `browser-check.txt`: 두 안의 실제 선택/계산/지도/복귀/모바일/사이드바 제외 검사.
- `capture-check.txt`: 캡처 상태와 페이지 오류/가로 넘침 확인.

이미지 생성 개념도와 다르게 글자·입력·버튼은 실제로 동작한다. PNG는 빈 재질 표면이며 글자를 구워 넣지 않았다. 원형 광학 장식은 경로 지도가 아니다. DEV 매개변수 없이는 새 검토 테마를 기본 적용하지 않는다. 사이드바는 변경하지 않았다.
