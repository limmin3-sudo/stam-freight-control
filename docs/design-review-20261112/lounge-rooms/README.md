# 라운지 내부 화면 테마 — 2026-11-12

기능 클라우드 / feature/mission-intake-flow-20261112 / 미커밋·미푸시·미배포 검토본.

정보실·서비스센터·영상관에 미션과 같은 Barlow Medium 500(영문/숫자), SUIT 500(한글), 균일한 유리 프레임/버튼을 적용했다. `content-optics.css`는 내부 화면과 서비스 native dialog만 대상으로 하며 고정 상단바와 승인된 공간 사이드바는 변경하지 않았다.

실제 앱 캡처: information.png / service.png / cinema.png (1920×1080), 각 -mobile.png (390×844). 최신 사이드바는 라운지/관제센터의 큰 공간 버튼 아래 하위 메뉴가 펼쳐지는 형태다. 기존 공개 화면의 단일 평면 메뉴와 다르다.

정보실은 기존 SCMDB 미션 목록 / 이용안내 / SCMDB 원본 출처로 연결한다. 카드/링크를 정리한 것이며 기존 별도 문서 페이지 내부까지 새 UI로 이식했다고 주장하지 않는다. 서비스의 계정/운송기록과 기존 소개영상 파일/재생 동작을 보존했다.

검증: TypeScript/Vite 빌드, 고정 메뉴 위치·사이드바 SUIT 유지, 본문 Barlow 500, 링크 대상, 계정/기록 창 열기·닫기, 클릭 전 mp4 요청 없음, 클릭 후 실제 재생·이동 후 video 제거, ko/mix/en 모바일 가로 넘침 검사. 계정 로그인 제출·외부 메시지 전송·실계정 동기화를 실행하지 않았다.

```sh
npm run build:control-room
STAM_MISSION_URL=http://127.0.0.1:5186/ node scripts/check-room-optics-browser.mjs
# 배포용 빌드 미리보기도 같은 검사 가능. 현재 5188에서 검수했다.
```

지도·관제 콘솔의 테마 확장은 후속이다. 공개 사이트는 아직 바뀌지 않았다.

## 중복 공간 이동 정리

본문의 라운지로/관제실로 링크를 제거하고 고정 공간 사이드바로 이동한다. 제목 배치도 한 열로 바꿨다. 계정·기록 dialog가 열린 동안 Esc가 배경 공간까지 이동시키지 않도록 수정하고, 창만 닫힌 뒤 서비스센터에 남는 것을 확인한다.

최신 캡처에는 제목 오른쪽 복귀 버튼이 없다. `browser-production.txt`는 배포용 빌드에서 계정/기록 창까지 확인한 결과다. 실제 공개 배포와 구분한다.

최종 결과: 루트 232/232, 앱 45/45, TypeScript/Vite 빌드 및 개발/배포용 브라우저 모두 통과. 미션 사이드바 복귀·수량 수정 회귀도 통과했다.
