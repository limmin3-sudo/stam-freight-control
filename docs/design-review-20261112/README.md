# 버튼 · 폰트 · 테마 비교 시안

**사용자 확정 — 사이드바 유지:** 현재 승인된 공간 사이드바의 버튼·폰트·색상·크기·배치·펼침/접힘 동작은 그대로 유지한다. 이후 전체 테마/버튼/폰트 개편 범위에서도 사이드바는 제외한다. 사용자가 별도로 변경을 요청하기 전에는 재디자인하지 않는다.

기존 단일 버튼 PNG의 일괄 확대/축소 사용은 반려됐다. 이 폴더는 새로운 역할별 UI 체계를 비교하기 위한 미승인 시안이며 앱에 적용하지 않았다.

- 비교: `comparison.png`.
- 1안: `prism.png` — 청록 투사 유리, 각진 절단면, 금색 주요 실행, SUIT.
- 2안: `chrome.png` — 훈연 유리, 은색 금속 베젤, 원형 도구, Pretendard.
- 3안: `opal.png` — 청보라 오팔 유리, 부드러운 캡슐형 가장자리, Orbit.
- `hologram-systems.html`은 네트워크 없이 로컬에서 열 수 있으며 저장소 내 폰트 파일을 참조한다. SVG는 역할별 모양/유리 층/금속 테두리를 그리며 글자는 실제 텍스트다. 탭은 선택 가능하다.

주요 계산/일반 조작/화면 탭/작은 도구/정보 상태를 구분한다. 여기서 기본 방향을 선택한 뒤 실제 미션 콘솔 한 화면에 적용하여 다시 검토한다. 이후 전체 콘솔에 확장한다.

## 추가 재질 시안 — 미승인

사용자가 첫 세 시안보다 더 멋있고 세련된 방향을 요청했다. `material-study-v2.png`는 새로 생성한 실사 재질/형태 비교 이미지다. 01 LUMEN은 투명 크리스털과 청록 투사광, 02 NOCTIS는 훈연 유리와 티타늄, 03 AURORA는 오팔 유리와 약한 스펙트럼 반사다. 실제 앱 화면/실제 폰트 구현 검증본이 아니며 영문 글자도 이미지의 일부다. 선택한 재질과 역할별 형태를 실제 버튼 및 한글 폰트로 구현해 다시 검토해야 한다. 아직 선택/전체 적용 승인은 없다. 사이드바는 계속 제외한다.

## 사용자 반려 및 입체 실사 홀로그램 추가 방향

사용자가 세 미션 캡처는 재질 개념도와 분위기가 너무 다르다고 지적했다. 앞선 SVG/CSS 미션 테마는 승인되지 않았으며 완료된 재현으로 취급하지 않는다. 비교용 실제 광학 유리/금속 PNG 패널과 주 실행 버튼을 생성하여 `apps/control-room/src/assets/material-review/*-glass-*.png`, `*-titanium-*.png`에 보존했으나 아직 앱에 연결하지 않았다. 원본은 `/workspace/generated_images/`에 남겼다.

이어서 사용자가 입체 실사 홀로그램형도 있는지 물어 `volumetric-hologram-study.png`를 생성했다. 이 이미지는 실제 앱 스크린샷이 아니라 투명한 광학 투사 면·깊이층·부드러운 반사광·약한 입자/스캔선의 새 아트 디렉션 시안이다. 실제 화면과 혼동하지 않는다. 아직 이 방향을 선택했다는 사용자의 답은 없다. 다음 구현에서는 방향 확인 후 실제 재질 자산과 동작하는 텍스트/입력/선택 UI를 결합해 시안과 캡처의 차이를 줄여야 한다. 사이드바는 유지한다.

## 새 사용자 참조 — 반듯한 입체 유리 칩

사용자가 과하게 휘거나 찌그러진 홀로그램형을 반려하고, 반투명 청록 유리 칩·선명한 청록 발광 가장자리·어두운 금속 기반·주황색 신호/선택 강조가 있는 예시를 제시했다. 새로운 형태는 반듯하고 정돈된 기하 형태이며, 두께와 재질로 입체감을 낸다. `geometric-chip-hologram-study.png`는 이 특징을 STAM에 맞춰 새로 만든 개념도다. 원본 스톡 이미지의 구성/로고/워터마크를 재사용한 자산이 아니며 실제 앱 캡처나 디자인 확정본도 아니다. 버튼/패널/탭/선택 상태의 위계를 유지하고 사이드바는 변경하지 않는다.
