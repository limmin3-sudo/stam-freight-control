# 무역 흐름·함대 공동 교역 보완 — 2026-11-17

> 후속 갱신: 공동 교역 운영 규칙 게시와 실제 임시 계정 검증11항목을 완료했다. [최신 상태](../crew-production-20261117/README.md). 아래 미게시 기록은 구현 당시 상태이며 신규 웹 화면은 여전히 미배포다.

현재 작업본 구현·검증 완료. **커밋·푸시·배포 및 신규 공동 교역 운영 Firestore 규칙 게시 없음.** 공개 beta 3.0.0(`2c637afa21c9de904b3ad58b289215f3508670ec`)과 구분한다. 사용자 승인 범위는 경쟁 도구 추가 조사·개인 교역 보완·함대 공동 교역 포함이며, 기본 정산은 **출자금 비례, 필요하면 개인별 이익 비율 수정**이다.

공동 교역은 `crewTrades` / `crewInvites` 별도 공간이다. 개인 운항·무역 클라우드와 로컬 장부를 합치거나 자동 차감하지 않는다. 기존 선택 경로에서 첫 매입 화물을 배정 입력으로 가져올 수 있지만 실제 거래는 복사하지 않는다. 연출 담당의 `SpaceExperience.tsx`, `FacilityLobby`와 자산은 수정하지 않았다.

## 운영·후속 통합 시 주의

1. 다음 배포에 공동 교역을 포함할 때는 검증한 `firestore.rules` 게시와 운영 임시 계정 검증을 웹 배포와 함께 수행해야 한다. **지금 서버에서 새 공동 교역을 사용할 수 있다는 뜻이 아니다.** 기존 운영 개인 무역 저장 규칙은 건드리지 않았다.
2. 함장은 공동 장부의 승인 권한자다. 서버 규칙은 비회원/함대원의 권한 침범·확정 후 변경을 차단한다. JSON 내부 회계 검증은 클라이언트 엔진에서 수행하며, 악의적인 함장을 상대로 금융 기관 수준의 원장 진위를 보증하는 구조는 아니다.
3. 공동 교역 하나에 최대30명·배정100개·승인 거래500건·payload650KB, 목록조회 최대100건. 거래500건을 넘기면 다음 교역으로 나누며 기존 기록을 자동 삭제하지 않는다. 구독은 공동 패널이 열려 있을 때만 유지하고 계정 변경/닫기에서 해제한다.
4. 공개 함대 검색/채팅/오피서 위임/함대 전체 경로 최적화/외부 공개 시세 제출/게임 오버레이 등은 [조사 문서의 별도 범위](RESEARCH.md)에 명시했다. 타사 모든 기능 완료로 보고하지 않는다.
5. 실제 사이트 이동 연출·파트너 배치·새 통합 둘러보기·운송/무역별 튜토리얼은 별도 작업과 통합한다. 기존 미커밋 파일과 미사용 자산 후보를 일괄 stage/삭제하지 않는다.
