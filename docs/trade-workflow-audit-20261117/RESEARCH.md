## 현재 패치·운송 정보

[공식 4.10.3 Known Issues](https://support.robertsspaceindustries.com/hc/en-us/articles/360056254754-Star-Citizen-Alpha-4-10-3-Known-Issues)와 기존 Wiki/SCMDB 기반 임무 정의를 대조했다. 실제 로그에서 얻은 계약 수량, 정의상의 상한, 커뮤니티 추천, 현 패치 가용성은 서로 다른 근거다. 평판/시간 실측 자료가 없으므로 특정 조합을 ‘평판 최고 효율’로 단정하지 않는다. 이번 아카데미 추가 내용은 **시세·수요·보고 연령 읽기**, **부분 판매 원가와 실제 정산**으로 한정하고 수익 수치는 계산 설명용 예시라고 표시한다.

## 이번 발견과 구현 판단

- 한글 품목 검색이 된다고 앞서 안내했지만 가격 콘솔 일부는 영문 이름만 검색했다. 기존 번역 자료의 공식 우선순위를 유지하며 한글/영문 검색을 함께 적용했다.
- 기존 매입 입력 준비는 전체 계획 수량을 다시 넣을 수 있었다. 현재 방문 회차·실제 매입 수량·재계획을 반영해 아직 매입하지 않은 잔량을 제안한다.
- 현금 감소와 실현 손익은 다르다. 매입 80, 부분 판매 30(원가20), 비용3이면 현금흐름은 -53, 실현 이익7, 남은 원가60이다. 세 값을 분리 표시한다.
- 타사 가격 이력 화면을 흉내 내려고 가짜 곡선을 만들 필요가 없다. UEX 실제 보고 시계열을 검증 후 작은 점 그래프로 표시하고 원자료 표는 펼친다.
- 공동 교역은 사용자 선택으로 범위에 포함했다. 기본 이익 배분은 출자금 비례, 개인별 비율 수정 가능. 게임 내 돈을 움직이는 기능이 아닌 공동 기록·승인·지급 확인이다.

## 여전히 별도인 범위

외부 공개 시세 제출·타사 로그인·게임 내 오버레이·전역 키/음성 제어·공개 거래 게시판·닫힌 앱 푸시·타사 Datalink 수준 자동 거래 인식은 미연결이다. 공동 교역에는 비공개 초대/함장/함대원/담당 화물/상태·문제 메모/정산을 구현했으며 공개 함대 검색·채팅·오피서 권한 위임·전체 함대의 동시 경로 자동 최적화는 이번 구현에 포함되지 않는다. 기존 단일 함선 경로 계획을 참고해 각 담당 화물을 배정한다. 이 차이를 숨기고 ‘타사 모든 기능 구현 완료’로 보고하지 않는다.
