# 이용안내 실행 순서·진입 연결 (미배포)

사용자 확정: 게임 실행 → STAM 로그 앱 실행 → 미션 콘솔 연결.

로그 앱 안내 첫머리에 실행 순서를 표시하고 설치 후 실행, 첫 운송, 다른 기기 연결, 문제 해결 안내도 같은 순서로 맞췄다. 앱 자체의 실행 제한이나 감시 동작은 변경하지 않았다.

진입 경로 점검에서 서비스센터·아카이브는 새 이용안내 연결을 확인했다. 안내데스크의 기존 「운송 절차 안내」 버튼은 한 줄 설명만 보여주던 것을 새 이용안내로 연결했다. 기존 패널 수납과 첫 운송·함선/화물·투어 화면은 보존했다. 구형 독립 도구의 guide.html 링크는 해당 도구 안내이므로 유지한다. 로그 앱 설치본은 변경하지 않았다.

생산 타입 검사·빌드 통과. 실제 Chromium에서 4개 주제 × 3언어의 실행 순서, 데스크톱 한국어/390px 영어 안내데스크 진입, 언어·고정 메뉴 유지, 기존 첫 운송/정보 버튼, 선택 계약 보존을 확인했다. 페이지 오류 0건. report.json 참고. 실게임 및 Windows 실행을 이번 검사로 주장하지 않는다. 운영 서버 쓰기·커밋·푸시·배포 없음.
