# 로그 앱 다운로드·설치·연결 이용안내 — 2026-11-16 / 미배포

이용안내 → 미션 가져오기에 4단계 안내를 구현했다. 상단 앱 다운로드 → Windows 설치·실행 → 실제 게임 채널의 Game.log 선택 → 미션 콘솔 자동 수신 확인. 안내 안의 다운로드 링크는 상단과 같은 `data/desktop-release.json`의 설치 EXE를 사용하며 버전/파일명도 해당 자료에서 표시한다. 파일·스크린샷·직접 입력 및 탭 수신함 보관 설명을 유지했다.

모바일에는 Windows 게임 PC에서 설치/연결해야 한다고 설명한다. 연결 상태와 계약 수신·배송 완료를 구분하고, 연결 불가·계약 없음·다운로드 파일 위치 문제에 대한 해결 방법을 추가했다. 승인 상단바/사이드바와 앱 자체는 수정하지 않았다.

## 이미지 출처와 검증 경계

- 다운로드: 현재 생산 빌드의 실제 상단바 요소를 3개 언어로 촬영.
- 앱 창: 기존 실제 Windows Server 2025 검증 캡처. `66c26ac`의 `Launcher.cs`/`installer.iss`가 현재 HEAD `8c9b06a`와 변경 없음을 Git diff로 확인했다. 한국어/영어 원본을 사용하고 한영 모드에는 한국어 앱을 표시한다. 캡처는 연결 대기 상태이며 연결 성공 화면으로 소개하지 않는다.
- 연결 상태: 실제 로그 API를 실행해 별도 임시 합성 Game.log를 읽고 실제 미션 콘솔과 연결했다. UI 문구를 조작하거나 연결 응답을 가짜로 채우지 않았다. 공개 사이트 origin을 사용하는 격리 브라우저에 현재 로컬 빌드를 제공했으며 공개 서버는 변경하지 않았다.
- Windows 설치 마법사 캡처는 없으므로 이미지를 만들어 넣지 않았다. 설치 소스와 기존 Windows 검증 기록을 대조한 글 안내만 제공한다. 이번 작업에서 Windows 설치를 다시 실행한 것은 아니다.
- 각 장면은 해당 단계에서 한 번만 사용한다. 개인정보/실제 사용자 로그/운항 자료는 사용하지 않았다.

[캡처 출처](capture-provenance.json). 새 캡처 재현은 생산 빌드 후 `node scripts/capture-manual-log-app.mjs`. 기본 자산 경로를 덮어쓰므로 갱신할 때만 실행한다. 임시 로그/로컬 API는 완료 시 정리한다.
