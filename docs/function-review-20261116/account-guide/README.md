# 계정 저장·다른 기기 이어하기 안내 — 2026-11-16 / 미배포

`AccountSaveGuide.tsx`로 이용안내 → 저장하고 이어하기를 보완했다. 계정 열기 → 현재 기기에서 저장 → 다른 기기에서 비교·불러오기 → 목적지/화물 확인·타이머 재개의 4단계다. 저장과 불러오기의 방향을 먼저 표시한다. 로그인 전 운항 소유 연결과 서버 저장의 차이, 자동 저장 상태, 다른 기기 충돌 시 다시 확인, 이전 운항 복구, JSON 파일 이전도 설명한다.

## 구현 근거

`FlightCloudPanel.tsx`, `use-flight-cloud.ts`, `FlightBackup.tsx`, `FlightOperations.tsx`, `use-flight.ts`와 실제 버튼/상태를 대조했다. 앱 재연결은 기기별로 필요하며, 계정 운항 복원은 선적/기록 유지·재계산 없음·진행 타이머 일시정지라는 현재 동작을 안내한다. 기능 코드나 계정 데이터 저장 규칙은 바꾸지 않았다.

## 캡처

첫 저장 전 계정 비어 있음, 다른 기기에서 서로 다른 두 운항 비교, 복원 완료 상태 3장 × 3언어. 모두 실제 생산 UI를 조작한 요소 캡처다. 서로 다른 두 브라우저 저장 공간과 모의 Firebase SDK/메모리 저장소를 사용했다. 실제 사용자 데이터·실계정·운영 서버 요청은 없다. 모의 계정 캡처를 새 운영 서버 검증 결과로 주장하지 않는다.

계약 두 종류의 예시 운항으로 진행했으며 첫 저장, 두 번째 기기의 명시 불러오기, 복원 전 운항 백업, 선내 화물 보존과 타이머 일시정지를 함께 확인했다. [캡처 기록](capture-provenance.json). 재현: 생산 빌드 후 `STAM_MANUAL_URL=http://127.0.0.1:5189/ node scripts/capture-manual-account.mjs`. 기본값은 자산 폴더를 갱신하므로 의도적으로 캡처를 갱신할 때만 실행한다.
