# 운항 중 조작 이용안내 — 2026-11-16 / 미배포

`OperationsGuide.tsx`로 이용안내 → 운항 중 조작을 보완했다. 완료·되돌리기, 운항 관리, 방문 순서/실제 위치 수정, 계약 변경 확인, 보류 화물 하역 5개 상황이다. 실제 화면의 버튼명을 사용하고 완료 기록과 게임 행동, 선적 기록과 예상 배치, 타이머 일시정지와 운항 종료, 경로 제외와 실제 하역을 구분한다.

## 구현 근거

`FlightOperations.tsx`, `FlightRouteEditor.tsx`, `FlightReceiptReview.tsx`, `HeldCargoReview.tsx`, `use-flight.ts`, `flight-receipts.ts`를 대조했다. 확인 전에는 경로가 바뀌지 않고 현재 단계 완료 버튼이 제한된다. 종료·취소 계약은 확인 후 경로에서 제외하며 화물은 선내 보류한다. 항해사의 하역 확인은 선택한 상자만 제거하고 다른 배치를 보존한다. 기능 코드·저장 규칙·파트너 정책은 바꾸지 않았다.

## 캡처와 검증 범위

운항 완료 조작부, 운항 관리 메뉴, 방문 순서 수정, 계약 변경 확인창, 하역 확인창 5장 × 한국어/영어/한영. 예시 운항으로 격리 브라우저를 시작하고 실제 버튼을 눌러 캡처했다. 취소 신호는 합성 수신 상태를 초기화해 재현했으며 실제 게임 로그를 수신했다고 주장하지 않는다. 이미지에 인물/파트너 대화를 넣지 않았다.

캡처 중 완료→되돌리기 후 선내 상자 복원, 변경 확인 전 화물 보존, 확인 후 선내 보류 유지, 실제 하역 확인 후 선택한 한 상자만 제거를 검사했다. 운영 계정/사용자 운항/사용자 로그 접근 없음. 캡처 재현: `node scripts/capture-manual-operations.mjs` (생산 미리보기 필요, 기본 URL 5189). 자산 갱신이 필요한 경우에만 실행한다.

생산 타입/빌드 통과. 실제 Chromium 안내 9개 점검 그룹 통과: [결과](browser-report.json). 단계별 5개 이미지/3언어/390px 모바일/선택 계약 보존을 확인했다. 작은 버튼 이미지가 원본보다 확대되지 않도록 CSS 상한을 조정하고 최종 표시를 별도 확인했다: [크기 확인](image-size-check.json). 안내만 변경했으므로 이전에 통과한 루트 271개·앱 88개 전체 검사를 다시 반복하지 않는다. 외부 서비스/실게임 검증이나 새 운항 기능 구현은 이번 범위가 아니다.

승인 상단바/사이드바와 기존 미커밋 작업 보존. 커밋·푸시·배포 없음.
