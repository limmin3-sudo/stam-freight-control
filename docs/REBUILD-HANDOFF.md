## 사용자 목표와 반드시 지킬 결정

- 게임 로그는 읽기 전용. 메모리/프로세스 주입/패킷 감청/자동 입력/게임 파일 수정/EAC 우회 금지. RSI 로그인 정보 수집 금지. 다른 도구가 한다는 이유로 CIG 허용이라고 단정하지 않는다.

## 재개할 때 할 일

1. 현재 요청을 읽고 브랜치·작업 트리·upstream·최신 CI부터 확인한다. 기존 미커밋 작업을 보존한다. 이 문서 이전 상태로 되돌리지 않는다.
2. 후보 단계 다음으로 **본인 조종/정박 근거·지원 클래스/장소 대응을 확대할 수 있는지 검증**한다. 필요 근거가 없으면 미확인 유지. 모든 사용자에게 수동 재입력을 요구하는 화면을 기본 흐름으로 만들지 않는다.
3. 목표·종료·지급 표시는 연결했다. 다음은 실제 운항의 **잔여 화물·보상 귀속/기록·세션 복원**을 원래 계약 요구량/예상 이동과 분리해 연결한다. 여러 계약 완료 뒤 보상을 순서만으로 확정하지 않는다. 실린 화물의 위치·소유권·진행을 새 계획으로 초기화하지 않는다.
4. 일반 미션의 주문→거점 배분과 상자 구성 근거를 확대한다. 보조 OCR은 허용됐지만 오류/누락을 확정값으로 처리하지 않는다. 원본 유형 목록 전체 보유와 모든 명세 자동 해석을 혼동하지 않는다.
5. Node22/24/26 호환을 유지하되 모든 과거 버전 지원을 보장하지 않는다.
