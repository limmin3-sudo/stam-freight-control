## G. 제외·보존 규칙

- 새 사용자 정의 적재 그리드 좌표/크기 편집 UI는 제외. 기본 함선·구역 켜기/끄기·기존 customShip 복원은 유지.
- 함선 선택 시 퀀텀 드라이브 강제 선택 UI를 되살리지 않음.
- 오퍼레이터에 적재 3D/적재 입력 강요하지 않음. 항해사는 지도+상시 적재 유지.
- 고정 상단바·승인된 사이드바를 다시 디자인하거나 제거하지 않음.
- 전체 공간 3D 모델링·자유 보행·WASD를 과거 문서에서 되살리지 않음. 최신 2.5D/영상 동선 유지.
- 게임이 알려주지 않는 선적·배송 완료·지급 보상을 자동 확정하는 기능을 임의 추가하지 않음.

## 권장 마감 방식

현재 운송 기능의 가까운 마감 범위는 F1 운영 규칙 반영과 선택한 변경의 F6이다. 품질 보강 F3/F4와 화면 정리 F5는 구현 완료로 유지한다. E 항목을 자동으로 배포 선행 조건에 넣지 않는다. D 항목은 사용자가 재개할 때까지 보류한다. 새 결함이 나오면 기존 F/V 항목에 근거와 영향을 붙이고, 새 기능 제안은 E에 표시해 완료 기준이 조용히 늘어나지 않게 한다.
