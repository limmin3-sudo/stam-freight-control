# 무역 기능 재구성 · 2026-11-16 · 미배포

사용자 요청: 경쟁 교역 도구에서 확인한 기능을 가져와 구성하고 기능 검증까지 수행한다. 추가 확정: **예비금은 켜기/끄기 가능. 기본 켜짐·10%, 꺼도 마지막 입력 비율 유지.** 기존 운송 운항·계정·미커밋 연출과 이전 교역 장부를 보존한다.

경쟁 도구의 공개 화면·계산 응답을 실제 조사한 [비교 근거](../trade-tools-benchmark-20261116/README.md)를 기준으로 구현했다. 타사 화면 자산·소스 코드를 복제한 것이 아니다. 아래 **연결됨 / 제한 / 외부 기능 미연결**을 구분한다. 다른 서비스가 제공하는 모든 기능을 무조건 완료했다고 주장하지 않는다.

## 화면과 데이터 흐름

- 교역 계획실: 신규 교역 / 보유 화물 판매 / 목적지 경유 / 왕복 / 연속 교역. 기본 입력 뒤 세부 조건을 펼친다. 수석 교역관은 동일 행성계, 링 가문 중개인은 실제 행성계 연결을 포함한 경로를 찾는다.
- 시장정보실의 `시세 기록·관심 가격`과 계획실의 같은 기능에서 비교·주간 통계·즐겨찾기·가격 알림·개인 시세 검토를 연다.
- 무역 관제실: 지도와 혼합 적재 3D, 실제 거래·부분 판매·창고 보관/회수·손실·비용·잔액 보정·출발/도착·마감·감사 이력. 계획을 시작해도 실제 화물/매입/판매를 자동 생성하지 않는다.
- 기존 단일 품목 계획·장부는 `이전 교역 기록`에서 계속 읽고 사용할 수 있다. 기존 저장 형식이나 거래 기록을 새 형식으로 덮어쓰지 않았다.
- 새 장부는 `stam.trade-suite.v1:<owner>`. 계정 경계 확인, Web Lock, 기존 raw 값 비교, 원자적 단일 키 쓰기, 최대 크기 제한. 다른 탭 수정은 열린 확인창을 취소하고 최신 상태를 불러온다. 손상된 장부는 빈 장부로 덮지 않는다.
- 개인 관측 시세·조회 이력은 sessionStorage의 현재 탭 자료다. 개인 시세는 원본·단위 검토 후 별도로 켜야 계산에 사용된다. UEX 원본 파일을 수정하거나 외부로 제출하지 않는다.

## 계산·성능 경계

- 경로 탐색: 최대 5거래, 인근 매입지까지 초기 이동 추가 가능. 유망 상태 20개, 같은 거점 2개, 거래소 쌍 검사 최대 16,000회, 결과 최대 100개. 혼합 바구니는 두 정렬 방식으로 탐색한다. 항상 전역 최적해라는 문구를 쓰지 않는다.
- 계산과 혼합 적재는 Worker에서 실행. 입력 변경/취소/화면 종료 시 이전 Worker 종료. 실제 그리드 결과는 상자 규격별 수량으로 캐시하고, 항로는 거점 쌍별로 재사용한다.
- [성능 측정](performance.json): 실제 수집본, Cutlass Black·Everus·100만·조건 완화 표본. 브라우저 검증 동시 실행 중 단일 128ms, 왕복 1,460ms, 연속 2,623ms, 목적지 경유 2,018ms. 모든 함선·브라우저의 성능 보장값이 아니다.
- 지도와 화물의 기존 렌더러/자원 해제·보이지 않는 화면의 렌더링 제어를 재사용한다. 거래 비용만 바뀌면 동일 화물 3D를 다시 계산하지 않는다.

## 검증 근거
