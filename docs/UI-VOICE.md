# STAM 화면 문구와 파트너 말투

사용자 요청(2026-11-04 KST): 번역투를 피하고 스타시티즌의 운송·항해 분위기에 맞춘다. 화면은 존댓말이며, 기본 배치와 기존 파트너 성격을 유지한다.

- 짧고 자연스럽게 쓴다. 주 화면은 **출항 준비 / 계약 대기 / 화물 확인 / 항로 / 적재 / 하역 / 관제**를 중심으로 쓴다.
- 게임 고유명(함선·지명·상품·발주처)은 영어 원문을 유지한다. 새 번역 데이터와 언어 모드는 별도 승인·연결 작업이다.
- ‘관측된 인스턴스’, ‘해결된 명세’, ‘어댑터’ 같은 개발 용어는 진단 화면·문서에 둔다. 플레이에 필요한 상태는 ‘계약이 들어왔습니다’, ‘화물 확인이 필요합니다’, ‘항로를 준비하고 있습니다’로 설명한다.
- 수석 항해사: 차분하고 간결하게 ‘항로와 적재 순서를 준비하겠습니다.’
- 브리지 오퍼레이터: 친근하고 경쾌하게 ‘함장님, 계약을 받아 주세요. 가까운 배송부터 정리할게요.’ 과장된 감탄·군대식 명령·억지 우주 용어를 남발하지 않는다.
- 분위기 때문에 사실을 부풀리지 않는다. ‘이전 설정’, ‘직접 확인’, ‘정보 확인 중’, ‘예상 이동’은 필요한 곳에서 분명히 표시한다. 로그 연결을 위치 동기화라고 부르지 않는다.
- 버튼은 수행하는 일을 말한다. `항로 계산·안내 시작`은 STAM의 안내 시작이며 게임 함선을 출항시키지 않는다. 실제 적재·배송·보상 완료와 혼동되는 대사를 쓰지 않는다.

## 계약 제외·남은 화물

- 파트너가 묻는 질문·안내는 선택한 파트너의 말투와 초상화로 표시한다. 수석 항해사는 차분한 격식체, 브리지 오퍼레이터는 밝고 친근한 존댓말을 유지한다.
- 계약 제외 질문: 수석 항해사 “함장님, 이 계약의 화물이 아직 실려 있습니까?” / 오퍼레이터 “함장님, 이 계약 화물은 아직 배에 남아 있나요?”
- 사용자의 답변 선택지는 “남아 있습니다 / 없습니다”처럼 명확하게 표시한다. 답변 버튼에 파트너 대사를 넣지 않는다.
- 출항 준비·계산·실패·남은 화물 정리까지 같은 캐릭터의 말투를 이어간다. 시스템 오류·데이터 삭제 안내는 사실과 수행할 일을 정확하게 쓴다.
- “아직 안 실음 / 전부 내렸거나 버림 / 실려 있음”처럼 내부 상태를 나열하지 않는다. 한 번도 싣지 않은 경우와 모두 내린 경우를 불필요하게 구분해서 묻지 않는다.
- 남아 있다고 답할 때만 실려 있는 화물을 고르게 한다. 계약 제외와 실제 하역을 혼동시키지 않는다.
- 게임 계약 포기는 게임에서 진행한다는 점을 짧게 안내한다. STAM이 게임을 조작하는 것처럼 표현하지 않는다.
