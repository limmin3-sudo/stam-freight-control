2026-11-03 작성. **지금 사용자에게 전부 시험해 달라는 요청이 아니다.** 기능 구현 후 시험할 목록이다. 자동 검사/합성 로그/브라우저 검사는 실게임 통과로 대체하지 않는다. 미구현 항목은 구현 후 진행한다.

## 결과 기록 형식

`항목 ID / 앱 커밋 / 게임 빌드·언어 / 조건 / 조작 시각 / 관측 / 기대와 차이 / 상태 / 후속 작업`

실패하면 영향 있는 항목을 고친 뒤 해당 범위부터 다시 확인한다. 단순 UI 변경마다 같은 수락 시험을 사용자에게 반복 요구하지 않는다. 검증하지 않은 항목은 미실행으로 남긴다.

## 재개 후 추가 확인 — 목표·계약 종료·지급

- 동일 유형 두 계약에서 같은 목표 ID가 있어도 실행 계약 ID로 분리되는지 확인합니다. 한 계약 목표 완료가 다른 계약이나 전체 계약 완료로 번지면 실패입니다.
- HUD 완료/실패와 EndMission·MissionEnded가 함께 또는 일부만 찍힐 때 상태를 대조합니다. 타인 종료, 서로 모순되는 종료 기록, 완료 뒤 뒤늦은 수락은 완료로 확정하지 않습니다.
- 목표 완료와 마지막 SCU 알림이 서로 다른 시점이어도 실제 적재·남은 상자를 만들어 내지 않는지 확인합니다. 진행 수량의 역행/충돌은 확인 필요로 남겨야 합니다.
- 여러 계약 완료 직후 같은 금액이 지급돼도 시간 순서로 계약에 붙이지 않습니다. ID 없는 지급은 연결 미확인, 중복 재독해는 중복 알림 없음, 계정 누적 수입 자동 증가 없음이 기준입니다.
- 전체 계약 종료로 자동 선택이 해제돼도 다른 계약의 수동 선택과 원본 관측은 보존해야 합니다. 실제 실린 상자와 경로 진행의 자동 연결은 별도 미완료입니다.

위 항목은 합성 브라우저/자동 검사와 제공 로그 형식 확인까지 수행했습니다. 실제 Windows 운항 전체 검증은 아직 하지 않았습니다.

## 오늘 실행 준비 — 고정 주소/재시작

- 같은 PC/브라우저에서 실행기를 종료하고 다시 실행했을 때 함선·출발지·파트너·그리드 설정을 유지하는지 확인합니다. 새 연결 키로만 연결되며 이전 설정은 현재 감지로 표시하지 않아야 합니다.
- 실행기를 두 번 켠 경우 주소 점유 안내를 표시하고 자동으로 다른 포트/빈 저장 공간으로 바꾸지 않아야 합니다. 이전 실행기 종료 후 재시작합니다.
- ZIP을 새 폴더에 풀어도 같은 기본 주소의 브라우저 저장 공간을 사용해야 합니다. 이전 임의 포트·시크릿 모드·다른 프로필은 자동 이전되지 않습니다.
- 실행→현재 Game.log 선택→게임 접속→지원 계약 자동 선택→설정 확인→항로/적재 시작은 [오늘 실행 안내](TODAY-RUN.md)를 따릅니다. Windows 파일 선택 대화상자·실게임 동시 성능은 별도 검증합니다.

## 공간 예약·수동 상자·화면 보조 감시

- 중형 50 SCU 품목·배송지 일치, 픽업별 미확인 배분을 만들지 않는지 확인합니다. 일반 유형의 일부 목표만 연결된 경우 일부 표시가 유지돼야 합니다.
- 같은 배송지의 서로 다른 계약이 인접 배치되며 계약별 화물 소유권이 유지되는지 확인합니다. 66 SCU 가이드/작은 그리드 분할/비활성 그리드/수동 실제 상자 불가 배치를 확인합니다.
- 크기별 개수 합계의 부족·초과를 차단하고, 새 계약 수신 시 기존 사용자 지정을 유지하는지 확인합니다. 화면 새로고침 뒤 입력이 사라지는 현 범위를 안내합니다.
- 화면 감시 기본 꺼짐, 게임 창 선택/취소, 한영·한글 알림, Accepted 또는 진행 중 계약 수 영역, HUD 위치·UI 크기·해상도 변경, 창 최소화/백그라운드 조건을 비교합니다. 게임 자체가 알림을 생략할 때 감지 성공으로 보고하면 안 됩니다.
- 화면 알림→늦은 로그, 로그 없는 알림, 같은 제목 연속 수락, 파티 공유 계약, 무역/전투 계약이 섞인 전체 개수의 오해를 확인합니다. 후보가 실제 계약·화물·기록으로 자동 승격되면 실패입니다.
- 화면/로그 감시 동시 실행 시 게임 FPS와 CPU·메모리를 측정합니다. 한 OCR만 실행, 공유 종료/페이지 닫기 시 캡처·Worker 종료, 화면 원문 외부 전송 없음도 확인합니다. 합성 Chromium 검증은 Windows 실게임 검증을 대체하지 않습니다.

## 계약 제외·남은 화물 확인

- 계약을 제외할 때 “남아 있습니다 / 없습니다”가 실제 상황에 맞게 동작하는지 확인합니다. 게임 계약 포기 자체는 자동 실행하지 않습니다.
- 일부만 싣고 제외: 남은 상자·영역만 선택하고 표시 위치와 실제 위치를 대조합니다. 다른 계약을 계산해도 선택한 화물 위치와 소유권이 유지돼야 합니다.
- 마지막 계약 제외, 종료/참여 이탈, 확인 창 취소, 새로고침: 확인하지 않은 화물을 삭제하거나 빈 공간으로 취급하지 않아야 합니다.
- 남은 화물이 있는 그리드 끄기·함선 변경·화물칸 수정·저장 실패·계정 전환을 확인합니다. 화물 위치를 임의로 바꾸거나 다른 함선에 복제하면 안 됩니다.
- 중형/대형 혼합 방문 항로는 모든 픽업 후 배송, 같은 배송지 묶음, 점프 구간을 확인합니다. 예약 3D는 전체 공간을 유지하며 단계별 실물 적재량으로 오해하지 않도록 안내합니다.
- 합성 테스트 결과와 별개로 Windows 실게임 미확인입니다.

## 파트너 안내·상자 구성 기억

- 수석 항해사/브리지 오퍼레이터를 바꾸고 출항 준비, 계산 안내, 계약 제외, 남은 화물 정리의 말투·초상화가 맞는지 확인합니다.
- 실제 확인한 상자 구성 입력 후 앱을 새로 열고 같은 Game.log를 읽어 복원되는지 확인합니다. 동일 유형의 다른 실행 계약에는 섞이지 않아야 합니다.
- 게임 빌드·화물 정보 변경 시 재확인, 계정 전환 시 분리, 저장 실패 시 이전 구성 유지, 직접 해제 후 재실행을 확인합니다.

## 운송 중 위치 유지·배송 확인

- 실제 상자와 적재도가 맞는 상태에서 일부/전체 화물을 위치 유지로 기록하고 새 계약을 추가합니다. 같은 상자의 그리드·좌표·방향·계약 귀속이 유지돼야 합니다.
- 같은 배송지의 다른 계약 화물은 가까이 배치하되, 배송 체크가 다른 계약에 적용되면 안 됩니다. 잘못된 배송지·예약 영역 배송은 차단돼야 합니다.
- 부분 배송 후 해당 공간만 비워지는지, 모두 적재한 실물 계약의 불필요한 픽업이 사라지는지, 배송을 되돌릴 때 기존 위치 충돌을 막는지 확인합니다.
- 새로고침/앱 재실행/로그 교체·계약 누락/다른 빌드·함선·그리드/저장 실패·계정 전환을 확인합니다. 누락만으로 화물이 삭제되거나 다른 함선에 옮겨지면 안 됩니다.
- 종료·포기·직접 제외 이후 남은 화물로 전환할 때 중복 배치하지 않고, 다음 실행에도 남아야 합니다.
- 실게임 Windows 조작·부하 검증은 별도이며, 합성 검증으로 통과 처리하지 않습니다.
