# 기능 배포 / 진행 중인 연출 인계 — beta 2.6.0

사용자가 오늘 기능 작업분을 배포하고 남은 기능은 다음 작업일에 이어가도록 승인했다. 연출 담당은 현재 별도 작업 중이다. 이번 배포에 아직 전달되지 않은 연출 변경을 포함했다고 가정하지 않는다.

공통 기준은 `handoff/local-studio-20261110`, 공개 소스는 `main`이다. 배포 적용 커밋은 해당 브랜치 이력과 공개 `version.json`의 `version`으로 확인한다. 작업 폴더는 `stam-freight-control-fresh-20261108`이다. 기존 작업이 있다면 먼저 별도 브랜치에 보존하고 최신 기준과 대조한다.

## 오늘 기능 변경

- 승인된 펼침형 왼쪽 사이드바와 상단바를 모든 콘솔에서 유지. 입력/계약 카드 순서 정리, Barlow Medium + SUIT, 균일한 유리 테두리, 서비스센터/정보실/영상관 테마 및 중복 복귀 링크 제거.
- 실제 OCR와 검토/수동 수정, 여러 픽업의 배송지별 총 SCU를 한 번 예약. 실제 수량과 목록 최대치를 구분.
- 새 운송의 파트너 선택. 총 SCU 미입력 시 오퍼레이터 경로 전용으로 전환. 오퍼레이터 관제에 적재/3D 없음. 항해사는 총량 예약과 적재 유지. 기존 운항/계약 보존.
- SCMDB 우선, 정확한 정의 UUID에 한해 Wiki 누락 정보 보충. 출처/버전/다른 값 분리. 검증된 캐시와 일일 자동 갱신.

## 연출 담당에게

진행 중인 연출은 별도 브랜치에서 계속한다. 기능 담당이 최종 통합/배포를 맡는다. 연출 완료 후 브랜치, 전체 SHA, 변경 파일, 검증 및 미완료 항목을 전달한다. 두 담당이 main에 따로 배포하지 않는다.

최종 파트너 선택은 **2.5D 관제센터에 서 있는 오퍼레이터/항해사를 클릭하는 구성**이다. 현재 큰 초상화 카드는 기능용 임시 화면이다. 연출은 후속 작업이며 지금 진행 중인 제작을 교체하라는 지시가 아니다.

현재 영상·배경·인물 원본을 유지했다. 상단바/사이드바는 고정하며 콘솔 UI는 모니터 내부 콘텐츠로 이어진다. 영상이 모니터 화면 내용까지 다가온 마지막 프레임에서 실제 UI로 연결하는 원칙을 유지한다.

겹치는 파일:

- `apps/control-room/src/SpaceExperience.tsx`: 공간 전환, 공통 메뉴, 콘솔 렌더링, 임시 파트너 선택. **옛 파일 전체 덮어쓰기 금지.** 최신 기준의 이벤트/콘텐츠 구조에 연출 변경을 합친다.
- `SpaceNavigation.tsx`, `left-space-navigation.css`: 사용자 승인 사이드바. 새 연출을 이유로 디자인/펼침 동작을 바꾸지 않는다.
- `ControlRoom.tsx`, `MapConsole.tsx`, `persistent-console-shell.css`: 고정 메뉴 안쪽의 실제 콘솔. 기능 담당 소유.
- `PartnerChoice.tsx`, `partner-policy.ts`: 임시 UI와 기능 역할 정책. 공간 인물 클릭을 연결할 때 선택 정책을 재사용한다.
- `GuideDesk.tsx`, `ShuttleBoarding.tsx`, `OpeningFilm.tsx`, `hologram-layout.ts`: 기존 연출과의 접점. 이번 기능 변경에서 영상 교체는 하지 않았다. 별도 연출 브랜치의 변경을 검토해서 통합한다.

## 다음 기능 작업 순서

1. 항로 지도: 기존 조작 보존, 실사 행성/항성/배경과 홀로그램 표현, 지도 왼쪽/운항 순서 오른쪽 및 경로 표시 검수.
2. 관제: 현재 목적지와 수행할 작업 중심으로 정리. 항해사 적재 3D는 필요할 때 여는 보조 화면.
3. 적재 3D: 실제 배치/조작과 시각 품질 검수 및 개선. 기존 선적 좌표와 소유권 보존.
4. 이후 2.5D 파트너 클릭 연출 통합. 미확정 이륙/최종 효과음/추가 콘솔 이동은 연출 담당의 확정 인계가 필요하다.

검증 기록은 `docs/function-review-20261112/partner-source-policy/README.md`, `mission-final/README.md`, `docs/design-review-20261112/lounge-rooms/README.md`에 있다. 루트 238, 앱 48 테스트와 빌드, 배포용 브라우저 역할/총량/로그 검사가 통과했다. 실게임 OCR 정확도와 실제 계정/실물 기기 검증으로 확대하지 않는다.
