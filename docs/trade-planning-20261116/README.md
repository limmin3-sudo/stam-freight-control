# 교역 계획실 — 2026-11-16, 미배포

현재 기능 브랜치의 기존 미커밋 작업을 보존해 교역 계획실을 연결했다. 사용자가 지정한 기본 예비금은 가용 자본의 **10%**이며 직접 조정할 수 있다. 커밋·푸시·배포는 하지 않았다.

## 구현

- 무역센터 수석 교역관은 행성계 내부, 링 가문 중개인은 행성계 간 계획을 연다. URL의 advisor로 역할을 보존하고 계획실에서도 바꿀 수 있다.
- 함선 97개 기본 프로필, 구매 거래소, 자본, 예비금, 추가 비용, 이번 교역 적재 한도를 입력한다. 기존 운송의 함선명만 초기 제안으로 읽고 운항·계정·화물 저장값은 쓰지 않는다.
- 구매 금액 + 추가 비용 + 예비금이 자본을 넘지 않도록 계산한다. 예비금은 지출로 차감하지 않는다. 매입 단가는 소수 둘째 자리 올림, 매도 단가는 내림으로 보수적으로 계산한다.
- 보고된 공급·수요, 구매 가능한 상자 크기, 양쪽 거래소 최대 상자 크기, 기존 함선 그리드 치수·직립 제한을 모두 적용한다. 한 종류 상자를 빈 그리드에 배치하는 실현 가능한 수량이며 혼합 상자 최적해는 아니다. 미확인 공급·수요·상자 조건을 만들어 넣지 않는다.
- Hull C는 양쪽 loading dock이 확인된 경우만 허용한다. 일반 도킹 포트 유무로 대체하지 않는다.
- 합법성, 위험 조건, 가격 기록 시점을 독립 선택한다. 기본값은 합법 분류·주의 화물 제외·감시/정전 거점·현재 패치 24시간 내 수정 가격이다. 현재 패치의 오래된 가격만 선택적으로 포함할 수 있고 이전 패치·미확인 가격은 제외한다.
- 기존 지도 점프 연결을 사용해 스탠턴↔닉스는 파이로를 거친다고 표시한다. 이것은 행성계 연결 정보이며 거리/시간을 최적화한 상세 항로가 아니다.
- 예상 차익/매입금/수량 정렬, 후보별 수량 제한 사유, 가격 수정 시점, 설비 패치 및 감시 자료 날짜를 표시한다. 검토 후 예상 계획 JSON을 내려받을 수 있다.
- 품목 시세 재확인 성공 시 재계산 후 후보를 다시 선택하게 한다. 실패 시 기존 자료와 선택을 유지한다. 실제 매입·매도 기록이나 운항 시작은 아직 생성하지 않는다. 입력은 화면 내부 상태로, 방을 나가면 초기화된다.

## 자료와 한계

UEX 기존 204품목·114거래소·2,566가격을 유지하고, 이미 수집한 station/outpost/city 원본을 정확한 시설 ID로 결합했다. 113개 거래소에 시설 보안 원본이 연결된다. 상위 도시의 안전 플래그를 누락된 정거장에 임의 상속하지 않는다. 날짜 미확인 또는 모호한 결합은 보수적 후보에서 제외한다. 수집 스크립트에도 세 시설 API와 해시 근거를 추가했다.

감시·정전은 시설 자료이며 **실시간 항로 위험도**가 아니다. 실제 경로의 치안, 관할별 법률, 화물 소유권, 방문 가능한 함선 크기 전체를 판정하지 않는다. 이전 패치의 시설 기록은 검토 화면에서 표시한다. 공급·수요는 커뮤니티 보고값이며 재고 예약/확약이 아니다. 연료·수리·수수료는 사용자가 입력한 비용만 차감하고 시간당 수익은 산출하지 않는다.

자료 전수 수집·대조 근거는 [이전 시장/운송 검증](../market-information-20261116/README.md)에 있다. 이번 시세 갱신 브라우저 성공/실패 검증은 모의 응답을 사용했다. Cloud Chromium의 직접 외부 API는 프록시 인증서 문제로 실성공이 확인되지 않았으며 실제 게임/실거래는 검증하지 않았다.

## 검증

- 타입 검사 및 생산 빌드 통과. 기존 큰 초기 번들 경고는 유지되며 새 계획실은 지연 로드한다.
- 앱 테스트 **111개**, 루트 테스트 **271개** 통과.
- 새 계산 10개 테스트: 예비금/비용, 공급·수요·자본, 상자 배수/그리드, 미확인 자료, 가격 시점, 위험/위법 독립, 점프 경유, Hull C 하역, 잘못된 입력, 여러 자본·재고 값의 상한 불변식.
- 정확한 시설 보안 ID 결합 및 역할 URL 왕복 테스트 추가.
- [브라우저 보고서](runtime-review/report.json): 두 담당자 실제 진입, 기본 10%, 계획 JSON, 시세 정상/실패, 100% 예비금, 닉스 경유, 영어·1920/1366/390 화면, Escape/포커스 복원, 실제 예시 계약을 넣은 기존 저장값 보존.
- 브라우저 검수에서 드롭다운 접근 이름, 스타일 로드 순서에 따른 입력 그리드, 모바일 유리 에셋에 전신 이미지 스타일이 섞이는 문제를 찾아 수정했다.
