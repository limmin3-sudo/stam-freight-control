# beta3.1.0 / 로그 앱1.5 배포 진행

현재 기능 작업을 선별해 `1e561bc26f4f10db49372ef56ffc3b384c4cdc44`에 보존하고 integration 브랜치에 푸시했다. 제외한 초안과 미승인 연출 후보는 로컬에 보존했으며 배포 커밋에 넣지 않았다.

깨끗한 커밋 사본에서 루트283개·앱172개, 타입·배포 빌드 통과. 앞서 실제 Firestore 에뮬레이터9흐름과 합성2계정 브라우저 검증도 통과했다.

GitHub 내부에서 기존 검증 산출물을 내려받아 설치 EXE/ZIP 크기·SHA256, ZIP 무결성, 취소 모듈 부재를 확인했다. 검증 소스35개를 대조했고 차이는 웹 패키지의 취소 모듈 제외뿐이다. 네이티브 앱과 런타임 소스는 일치한다. Windows 설치·업데이트·제거/설정 보존, 오버레이/단축키/만료/표시 상태와 한/영 캡처를 확인했다. 검증 머신의 음성 엔진은 en-US이며 한국어 실제 음성·마이크·게임 검증을 통과했다고 주장하지 않는다.

`companion-promotion.json`의 release.status는 빌드가 만든 게시용 메타데이터다. 해당 값 자체가 공개 릴리스 존재의 증거는 아니다. GitHub 릴리스 및 공개 다운로드 검사 결과가 게시 완료 기준이다.

운영 Firestore 규칙은 직전 v1과 동일함을 다시 읽어 확인했다. 공동 대화/게시판 규칙 게시는 자동 승인 검토에서 정확한 권한 변경의 명시적 승인 부족으로 차단되어 사용자 확인을 요청했다. 승인 전에는 다른 경로로 게시하지 않는다. 과금/Functions 설정은 변경하지 않는다.

## 로그 앱 공개 완료

[앱1.5 릴리스](https://github.com/limmin3-sudo/stam-freight-control/releases/tag/app.1.5.0)와 [승격·공개 다운로드 검사](https://github.com/limmin3-sudo/stam-freight-control/actions/runs/44076038719)가 완료됐다. `companion-publication.json`이 공개 완료 근거다. 웹 배포는 운영 규칙 명시적 승인 대기이며 현재 공개 사이트 버전은3.0.0이다.
