# STAM 소개 영상 — C2 단일 함선 제작 프롬프트

2026-11-06 제작안. 공개 사이트는 승인된 40초 이미지 기반 임시 영상을 그대로 사용합니다. 아래 60초 영상은 Gemini에서 제작 중인 교체용 계획이며, 완성·반영된 기능이 아닙니다. 교체 방법은 [미디어 안내](../assets/intro/README.md)를 따릅니다. 앞서 여러 함선을 사용하는 안 대신 C2 한 척으로 통일합니다.

## Gemini에 전달할 공통 프롬프트

Star Citizen 운송 계획 도구 STAM Freight Control의 실사풍 소개영상 원본을 제작한다. 최종 편집은 약 60초이며, 원본은 8개 씬 × 각 10초로 확보한다. 8개를 동시에 생성하지 말고, 사용자가 지정한 씬 하나만 생성한다. 앞 씬을 확인한 다음 이어서 진행한다.

등장 함선은 제공한 참고 사진의 Crusader C2 Hercules 기본형 한 척이다. 정면·측면·후면을 함께 대조하고 도장·선체 비율·조종석·날개·엔진·랜딩기어·전후 램프 위치를 유지한다. 확인하지 못한 엔진 개수나 개폐 구조를 임의로 확정하지 않는다. 참고 이미지와 시작 프레임 지정은 구분한다. 업로드 이미지를 실제 시작 프레임으로 지정할 수 없는 도구라면 먼저 알려준다.

실제 게임에서 촬영한 영화 같은 화면을 목표로 한다. 금속 패널, 이음새, 사용 흔적, 정교한 광원과 그림자를 살리고 과한 안개나 발광으로 형태를 가리지 않는다. 함선과 화물은 무게감 있게 가감속한다. 선체 변형, 엔진 배치 변경, 갑자기 생기는 오브젝트, 바닥·선체 관통을 피한다. SCU 상자는 굵은 프레임과 모서리 잠금장치가 있는 형태로 통일한다.

램프와 화물칸은 장면 시작부터 필요한 상태로 열거나 닫아 둔다. 복잡한 개폐·변형 애니메이션은 생략한다. 연결되는 씬은 앞 씬의 마지막 프레임을 다음 씬의 시작 이미지로 사용하고, 함선·상자·장비·조명을 유지한다. 시작과 끝에 편집 여유를 두고 마지막 순간 새 동작을 시작하지 않는다. 장소나 시간이 달라지는 컷은 편집으로 연결하며, 강제로 같은 연속 숏처럼 만들지 않는다.

자막·로고·음악·내레이션·게임 HUD·웹사이트 화면을 생성하지 않는다. 엔진, 트랙터빔, 화물 접지, 퀀텀과 점프의 현장 효과음만 장면에 맞춰 넣는다. 소개 문구와 음악은 전체 편집에서 통일한다.

## 8개 씬 — 원본 각각 10초

1. **적재 준비.** 격납고에 정박한 C2와 열린 전방 램프, 대기 화물을 함께 담는 전측면 와이드. 카메라가 천천히 접근한다. 함선은 정지해 있다. 마지막에는 램프와 적재할 상자 하나가 함께 보이도록 안정시킨다.
2. **트랙터빔 적재.** 씬 1 끝에서 이어진다. 작업자가 트랙터빔으로 그 상자 하나를 들어 전방 램프를 통해 화물칸에 옮긴다. 그리드에 천천히 내려놓은 뒤 빔을 해제한다. 나머지 배치는 유지한다.
3. **출발.** 적재 후 시간이 흐른 컷. 램프는 처음부터 닫혀 있다. 개방된 이륙 공간에서 C2가 떠오르고 서서히 전진한다. 후방 사선 로우앵글로 규모와 추력을 보여준다. 복잡한 기어 수납은 생략한다.
4. **퀀텀 충전·진입.** 우주 공간의 후방 사선 구도. 게임 속 퀀텀 충전 → 진입 가속 → 안정적인 퀀텀 비행을 보여준다. 항성계 점프 터널과 구별하고, 선체를 늘이거나 변형하지 않는다.
5. **스탠턴 측 점프 포인트 진입.** 퀀텀을 끝낸 뒤의 별도 구간. C2 후방에서 점프 입구의 규모와 깊이를 보여주고 실제 입구 통과까지 담는다. 일반 SF 포털을 임의로 넣지 말고 확인한 게임 비주얼을 따른다.
6. **터널 내부.** 씬 5에서 이어져 같은 C2가 터널을 비행한다. 공간의 흐름과 곡률로 속도를 표현하고 자세는 완만하게 조정한다. 함선 형태를 고정하고 카메라가 선체를 통과하지 않는다.
7. **파이로 측 출구.** 터널 안 → 출구 경계 → 외부 우주까지 이동으로 연결한다. 나온 뒤 따뜻한 주황·호박빛과 거친 분위기로 스탠턴과 구별한다. 전체 화면을 빨간 필터로 덮지 않는다. 끝에는 안정적인 비행 상태를 확보한다.
8. **격납고 도착.** 파이로 도착 이후 시간 경과 컷. 같은 C2가 산업적인 대형 격납고로 진입해 착지한다. 랜딩기어는 처음부터 펼쳐져 있다. 카메라는 내부 전측면에서 바라본다. 착지 후 엔진 빛이 잦아들며 마지막 2초는 안정된 상태로 남긴다.

## 첫 생성 전 확인 문장

> 영상은 아직 생성하지 마. 참고 사진 중 씬 1의 실제 시작 이미지로 지정할 사진을 먼저 골라줘. 적합한 사진이 없으면 필요한 구도 하나만 구체적으로 알려줘. 정지 구도 검토를 대신할 확인용 영상도 생성하지 마.

각 클립은 마지막 프레임과 함께 보관한다. 프레임을 맞춰도 생성 도구가 외형과 동작을 완전히 유지한다고 보장하지 않는다. 틀린 함선 구조는 컷 전환만으로 고칠 수 없으므로 연결 장면을 생성하기 전에 확인한다. 80초 원본에서 안정적인 구간을 골라 약 60초로 편집하며, 음악·효과음·자막 타이밍은 편집에서 결정한다.
