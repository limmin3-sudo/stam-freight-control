# 위치 수신과 지도 좌표 대조

2026-11-04. 사용자 전달 Claude 조사 메모를 검토하고 아래 공개 원문을 다시 읽었다. 코드 복사 없이 입력 검증·회전 계산·지도 표시를 구현했다. 공개 도구 설명과 실제 사용자의 4.10.2 측정은 구분한다.

## 확인한 출처

- [Quantum nav_core.py, 고정 커밋](https://github.com/Sammmy1036/Quantum/blob/07b3d8495de61fe9ea352d2d496aa0c9cb6f0c40/nav_core.py): `/showlocation`은 항성계 중심 미터 좌표, 지표/미션 마커는 자전하는 천체 로컬 좌표. 자전 오프셋은 패치별 보정 대상.
- [Quantum gateways.py](https://github.com/Sammmy1036/Quantum/blob/07b3d8495de61fe9ea352d2d496aa0c9cb6f0c40/gateways.py): Pyro 파일→게임 회전 -85.22993°. Stanton Gateway Station(Pyro)의 4.10 사용자 측정값과 다른 천체 대조 설명.
- [Quantum starmap_import.py](https://github.com/Sammmy1036/Quantum/blob/07b3d8495de61fe9ea352d2d496aa0c9cb6f0c40/starmap_import.py): 지표 오프셋과 항성계 정거장 회전을 서로 다르게 처리한다. 지표·중첩 컨테이너 회전을 무시한 합산 위치는 오류 가능.
- [SC Log Tracker 제한 설명](https://github.com/DefaultHahn/sc-log-tracker#limitations): 4.3~4.10 238세션 경험에서 실시간 좌표를 제공하지 않는다고 설명한다. 이를 모든 미래 게임 로그에 좌표가 절대 없다는 증명으로 확대하지 않는다.

## 구현 범위

- `position-feed.mjs`: 명시한 항성계와 `Coordinates: x:… y:… z:…` 전체 입력만 처리한다. 임의 로그의 XYZ, 계약 마커, 함선 내부 Zone 좌표는 이 경로에서 거부한다.
- 클립보드는 사용자가 직접 붙여 넣는다. 백그라운드 클립보드 감시·게임 채팅 자동 입력은 없다. 수신 시각과 좌표 측정 시각은 다르므로 `receivedAt`만 기록하고 `observedAt`은 미확정으로 남긴다.
- Stanton/Nyx는 동일 축·단위의 참조 좌표, Pyro 입력은 +85.22993° 역회전. 기존 데이터/경로/픽업·배송 좌표는 바꾸지 않는다.
- 회전 후 Pyro 측정값과 STAM Stanton Gateway 지도 마커의 차이는 약3.9km다. 이는 항성계 표시의 교차 대조이며 해당 마커가 정확한 도킹 위치라는 의미가 아니다.
- 기존 지도는 천체·위성계를 확대/이격한다. 지표 자전 보정 없는 좌표를 특정 아웃포스트에 붙이지 않는다. 천체 가까이는 해당 천체권, 멀리서는 항성계 참조 위치로 표시한다. 수신 좌표·지표 미보정 상태를 표시한다.
- 직접 확인한 거점은 별도의 마지막 확인 위치로 표시한다. `내 위치`는 현재 계획과 무관하게 해당 표시로 카메라를 돌린다. 항로·상자·운송 완료 상태를 변경하지 않는다.
- 한 번의 좌표 붙여넣기나 거점 확인으로 실시간 동기화 배지를 켜지 않는다. 현재 지속적인 본인 좌표 공급은 구현되지 않았다. 공급원이 준비되더라도 최근 연속 관측과 실제 좌표 검증 조건을 만족해야 한다.

## 남은 검증

- 사용자 실제 4.10.2 `/showlocation` 원문과 항성계 확인. 한국어 패치에서 접두어 변경 여부.
- Pyro 방향이 다른 정거장 두 곳에서 회전 재확인. Stanton 게이트웨이의 정거장/점프 지점 차이 구분.
- Calliope/Clio/Euterpe 중심의 위키/커뮤니티 차이와 지표 자전 오프셋 검증.
- 실제 좌표 지속 공급 방식은 별도 결정. 로그의 목적지/계약 마커/타인 인벤토리를 본인 현재 위치로 승격하지 않는다.
- 관제 카메라 확대/따라가기와 실제 Windows·게임 동시 실행 성능 확인. 소프트웨어 WebGL 브라우저 검사를 실제 GPU 성능 검증으로 보고하지 않는다.
