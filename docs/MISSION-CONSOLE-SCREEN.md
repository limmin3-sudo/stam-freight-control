# 미션 콘솔 화면 구현 기록

2026-11-12 · Codex · `feature/mission-console-screen` · 미커밋 로컬 검토본

## 화면과 연출의 연결 경계

미션 주소는 `#/mission?lang=ko`다. 접근 영상 끝에 화면 내용이 브라우저 전체를 채운다는 현재 사용자 지시를 따른다. 실제 UI는 영상·배경·모니터 테두리를 포함하지 않는다. 상단 콘솔 이동과 관제실 복귀, 언어 선택도 화면 내부에 있다. 영상 제작과 전환 연결은 연출 담당 범위다.

`ControlRoom.tsx`의 미션 분기에만 `monitor-ui`를 적용하고 `mission-screen.css`로 격리했다. 기존 관제 `at-display` 프레임을 미션에는 적용하지 않는다. 지도/관제의 디자인과 렌더러를 함께 교체하지 않았다. SUIT를 화면 본문·버튼·수치에 사용한다.

## 현재 구현한 흐름

| 항목 | 현재 동작 |
| --- | --- |
| 계약 선택 | 카드 본문 또는 체크박스 클릭으로 공용 초안에 직접 선택/해제 |
| 함선·출발지 | 화면 상단에 유지, 기존 거점 검색과 기본 함선 성능 사용 |
| 오퍼레이터 | 경로 안내, 사용자가 직접 적재. 기존 행성권 픽업 후 배송 우선 정책 유지 |
| 항해사 | 경로와 적재 공간 계산. 확인된 상자/총량/최대치의 기존 근거 규칙 사용 |
| 배송지 총량 | 카드에서 입력 후 반영 또는 계산 버튼으로 적용. 여러 픽업을 유지하고 배송 총량을 한 번 예약 |
| 최대치 | 기본 포함, 버튼으로 해제. 실제 수량으로 승격하지 않음 |
| 수량도 최대치도 없음 | 항해사의 자동 계산 제외, 수량 보완 필요. 오퍼레이터는 거점 확인 후 경로만 계산 |
| 상세 수정 | 기존 화물·총량·상자 편집 유지 |
| 가져오기 | Game.log 읽기/지원 브라우저 자동 수신, 수동 입력, 기존 JSON 백업 흐름 유지 |
| 공용 상태 | 기존 `useFlight` 세션 재사용. 콘솔 전환·새로고침에서 선택과 계산 계획 유지 |
| 운항 중 | 미션 변경 잠금 유지 |

카드 내부 입력·상세 버튼 조작으로 카드가 함께 선택되지 않는다. 총 운송량과 순간 최대 적재량을 혼동하지 않도록 요약에 설명한다. 배송 총량을 바꾸면 해당 배송지의 기존 상자 구성만 무효화한다. 종료/충돌/서명 변경 계약의 보호 규칙을 유지한다.

## 주요 파일

- `MissionConsole.tsx`, `mission-screen.css`: 화면과 직접 선택/입력 흐름.
- `mission-quantities.mjs`: 원래 `inbox-core.mjs`와 `delivery-totals.mjs`의 근거·예약 규칙을 화면/계산에서 공용으로 사용.
- `flight-engine.mjs`, `use-flight.ts`: 기존 엔진에 확인된 총량 또는 허용한 최대치 전달, 경로 전용 오퍼레이터 유지.
- `use-log-receipts.ts`: 같은 서명의 준비된 계약에도 수동 보완 적용.
- `ControlRoom.tsx`: 미션 화면 탐색과 계산 전 초안 전달.

루트 경로 탐색·적재 알고리즘을 새로 작성하거나 공용 세션과 별도의 저장소를 만들지 않았다.

## 검증과 한계

`npm test`: 232개 통과. `npm run test:control-room`: 12개 테스트 파일 통과. `npm run build:control-room`: TypeScript/Vite 성공, 기존 500 kB 초과 chunk 경고 있음.

`scripts/check-mission-screen-browser.mjs`는 실행 중인 Vite를 대상으로 한다. 기본 주소는 `http://127.0.0.1:5182`, `STAM_MISSION_URL`로 조정할 수 있다. 브라우저 검증은 예시/합성 계약과 실제 앱의 가져오기·선택·계산 경로를 사용했다. 최대치 32 SCU 계약에 배송지 총량 22 SCU를 입력했을 때 두 픽업을 남겨 두고 최종 예약/최대 적재량이 22 SCU가 되는 것을 확인했다. 잘못된 0 입력은 기존 32 SCU 계획을 손상시키지 않는다.

실제 게임 세션, Windows 파일 감시, 계정 로그인·기기 간 동기화는 검증하지 않았다. 시각 방향과 미션 콘솔 첫 구현에 대한 검토본이며 전체 개편 완료본이 아니다. 구 지도 조작 비교/복원, 왼 지도·오른 방문 순서, 운항 진행 중심 관제, 적재 3D 개선은 후속 작업이다. 커밋·푸시·병합·배포하지 않았다.
