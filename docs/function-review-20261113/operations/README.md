# 관제콘솔 테마와 파트너별 구성 — 2026-11-13

기능 클라우드 / `feature/navigation-console-20261113`, 기준 `40c3301`(beta 2.6.0).
현재 작업본이며 main 배포·커밋·푸시는 하지 않았다.

## 최종 사용자 결정과 적용

- Barlow Medium 500(영문/숫자) + SUIT 500(한글), 균일하게 빛나는 유리 테두리, 금빛 현재 작업·완료 버튼·선택 강조를 관제에도 적용했다. 포인터를 따라 움직이는 반사와 마지막으로 클릭한 버튼에 계속 남는 임의 선택 강조는 제거했다.
- 사이트 상단바·승인 사이드바는 보존한다. 관제 내부의 중복 STAM 제목/이동 바는 제거하고 운항 상태는 운항 패널에 표시한다. 미션 내부의 중복 제목 영역도 화면 공간에서 제거하되 접근성 제목과 화면 전환 초점은 보존한다. 지도 내부 중복 이동 바는 기존 공통 셸에서 이미 숨겨져 있다.
- 오퍼레이터: 승인된 지도/운항 작업/전체 방문 순서를 유지한다. 적재 패널·적재 렌더러·적재 팝업을 마운트하지 않는다.
- 항해사: 지도와 적재 3D를 항상 동시에 표시한다. 예전 관제모드인 `style.css`의 `.run-desk`(좌측 지도 : 우측 적재 1.3 : 1, 아래 운항 진행 : 파트너 안내)를 참고했다. 하단은 기존 22vh 비율을 사용하되 현재 버튼 가독성을 위해 최소 240px이다. 현재 목적지와 현재 거점의 픽업/배송 작업을 표시하며 전체 방문 목록은 표시하지 않는다. 전체 순서는 항로 지도에서 확인한다. 운항 기록과 순서 수정은 접힌 상세 기능으로 유지한다.
- 적재의 선적 기록 / 작업 전 예상 / 작업 후 예상 전환을 유지한다. 예상 보기 자체가 운항을 진행하거나 실제 상자를 바꾸지 않는다. 다음 작업으로 넘어가면 실제 선적 기록으로 돌아온다.
- 항해사 적재의 포인터 조작 시 패널에 초점을 두어 Space/Enter가 운항 완료로 전달되지 않게 했다. 지도/적재/입력/버튼에 초점이 있는 동안 전역 완료 단축키는 실행되지 않는다.
- 좁은 화면에서는 운항 작업 → 파트너/현재 작업 안내 → 지도 → 적재 순으로 쌓는다. 적재를 따로 여는 버튼 없이 계속 렌더링한다.

## 확인 방법

1. 앱에서 항해사를 선택하고 미션콘솔의 `예시 계약 보기`에서 광석/의료 물자를 선택해 계산한다.
2. 고정 사이드바의 관제콘솔로 이동한다. 지도 왼쪽/적재 오른쪽, 하단 현재 작업/파트너 안내가 별도 열기 조작 없이 표시되어야 한다.
3. 운항 시작 → 출발 완료 → 접수 완료를 누른다. 선적 기록의 상자가 실제 완료한 픽업과 일치해야 한다.
4. 작업 전·후 예상 보기를 바꿔도 실제 선적 기록은 바뀌지 않아야 한다. 적재 화면을 클릭하고 Space를 눌러도 운항이 진행되면 안 된다.
5. 완료/되돌리기, 언어 변경, 적재 설정 왕복, 새로고침 후에도 상자 ID·소유권·위치가 유지되어야 한다.
6. 별도 세션에서 오퍼레이터를 선택한다. 방문 목록은 보이고 적재 3D 영역은 없어야 한다.

## 검증과 증거

TypeScript/Vite 빌드 통과. 배포용 빌드를 로컬 5188에서 실행한 실제 Chromium 검증도 최종 통과했다(페이지 오류 0). 실행 명령:

```sh
npm --prefix apps/control-room run build
STAM_MISSION_URL=http://127.0.0.1:5188/ STAM_QA_OUTPUT=/tmp/stam-operations-final node scripts/check-flight-progress-browser.mjs
```

- `build.log`: TypeScript/Vite 빌드 결과.
- `browser.log`: 지도/적재 동시 표시·1.3:1 비율·현재 목적지만 표시, 고정 메뉴 보존, 실제 Barlow 500 적용, 계획/실제 화물 분리, 키보드 격리, 언어 전환, 적재 설정 왕복, 새로고침/되돌리기, 390/768/1366px 가로 넘침, 오퍼레이터 적재 없음 검증.
- `operations-desktop.png`: 항해사, 1920×1080, 실제 선적 후.
- `operations-operator.png`: 오퍼레이터, 1920×1080.
- `operations-mobile.png`: 항해사, 390×844, 상단 현재 작업.

실제 게임 진행, 실기기 GPU/FPS·터치 성능은 이번 UI 검증에 포함하지 않았다. 지도 표면 원본 고해상도화·추가 디테일·적재 그래픽 재제작은 별도 후속 작업이다. 단순 이미지 확대를 새 표면 디테일 생성으로 보고하지 않는다. 연출 자산/영상/PR #25는 변경하지 않았다.
