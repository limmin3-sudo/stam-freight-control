# 적재 3D 표시·조작 정비 — 2026-11-13

기능 클라우드 / `feature/navigation-console-20261113`, 기존 미커밋 지도·관제 작업에 이어지는 검토본. main 배포·커밋·푸시는 하지 않았다.

- 공통 CargoViewport, 적재 설정/명세 화면에 Barlow Medium 500 + SUIT 500 및 유리 버튼·금빛 선택을 적용했다. 3D 상자에 표시되는 SCU 숫자도 같은 서체로 그린다.
- 전체/위/좌현/우현 버튼은 실제 카메라 선택 상태를 표시한다. 직접 회전·확대하면 고정 시점 선택을 해제한다. 언어/화물 정보 갱신은 같은 그리드의 카메라를 보존한다.
- 사용 해제한 그리드가 회색 윤곽으로 남던 오류를 수정했다. 해당 윤곽/표시는 숨기며 원래 그리드 인덱스는 보존한다. 사용 구역 변경 시 카메라 범위를 다시 맞춘다. 모든 구역이 꺼져 있어도 카메라 좌표가 유효하게 유지된다.
- 선수·선미·출입구·구역 라벨은 투영된 위치 가까이에서 겹치지 않도록 배치한다. 공간이 없거나 화면 밖인 라벨은 숨기며 실제 3D 그리드 좌표는 바꾸지 않는다.
- 목적지 색상의 상자 면·중립 금속 프레임·실제 부착면의 금빛 그리드와 기존 수량/소유권은 유지한다. 없는 함선 외형이나 방 전체 바닥을 추가하지 않는다.
