# 항로지도 — 실사 / 천체 고유 색 홀로그램 비교

기능 클라우드 작업. `feature/navigation-console-20261113`, 공개 기준 `40c3301` 위의 미배포 검토본. 고정 상단바/승인 사이드바와 연출 PR #25는 변경하지 않았다.

## 최신 사용자 기준

- 실사 지도와 홀로그램 지도는 별도 시안이다.
- 홀로그램도 천체별 고유 색을 유지한다. 일괄 청록색으로 칠하지 않는다.
- 위경도 격자, 와이어프레임, 삼각 연결망을 넣지 않는다. 실제 궤도와 계산한 항로만 표시한다.
- 강조는 일정한 황금색 발광으로 표현한다. 선택 천체의 얇은 윤곽/지명, 활성 경로/거점과 선택 카드에 적용한다. 불규칙한 번쩍임은 없다.
- 사용자 참고 이미지는 발광 윤곽과 유리 같은 투명도/입체 깊이의 방향이다. 해당 이미지를 지도 배경으로 사용하거나 동일한 사진 품질을 검증했다고 주장하지 않는다.

## 변경과 원인

이전 성운 배경은 1774×887 이미지로 360도를 덮어 화면 일부에서 확대됐고, 가까운 시야에서 해상도가 부족했다. 새 `chart-sky.ts`는 카메라의 방향으로 성운 먼지층을 화면 픽셀에서 계산한다. 14,000개 별은 별도 점 형상으로 그린다. 구형 배경 PNG는 보존하되 실행 코드에서 불러오지 않는다. 확대 업스케일을 4K 원본이라고 표현하지 않는다.

실사형은 스탠턴 청색/파이로 호박색/닉스 청록색 배경, 기존 승인 항성 그림과 얇은 코로나, 기존 천체 표면 지도, 자연스러운 명암/대기층/도시 밤 조명을 사용한다. 텍스처는 게임에서 추출한 정밀 표면 자료가 아닌 기존 시각 자산이다.

홀로그램형은 별도 반투명 재질로 앞면과 희미한 뒷면을 겹쳐 깊이를 표현한다. 천체 표면의 원래 색과 각 천체의 대기 색을 유지하며, 선택 윤곽은 금빛이다. 격자/스캔라인은 없고, 초기 시안의 과도한 미세 윤곽 발광도 제거했다. 표면에 임의의 화물/미션/거점 데이터를 만들어 표시하지 않는다.

항로의 화살표 반복 무늬를 얇은 연속 발광선으로 교체했다. 경로 좌표, 직선 퀀텀/천체 우회, 경로 계산/운항 상태는 바꾸지 않았다. 거점 표식과 선택 라벨도 실제 기존 위치를 사용한다. 블룸은 계속 비활성이다.

## 실제 미리보기

- 실사: `http://127.0.0.1:5188/#/map?lang=ko`
- 홀로그램: `http://127.0.0.1:5188/#/map?lang=ko&chartLook=hologram`

5188은 배포용 빌드 미리보기이고 5186은 개발 서버다. 먼저 미션 콘솔에서 항해사/예시 계약을 선택해 계산하면 실제 운항 순서를 함께 볼 수 있다. `chartLook`은 비교용 URL 선택이며 전역 사이드바에 새 설정을 넣지 않았다. 기본은 실사형이고 홀로그램형은 사용자 비교용이다.

## 검증

`check-chart-optics-browser.mjs`: 실제 앱에서 예시 계약 → 지도, 세 항성계, 실사/홀로그램 근접 화면, 마이크로텍/허스턴/크루세이더 색상, 보통/높음/최고 화질, 1920×1080·2560×1440·390px 화면을 캡처한다. 콘솔 셰이더 오류·과거 배경 PNG 요청이 없는지와 계약/운항 저장 상태 불변을 검사한다.

`check-celestial-occlusion.mjs`: 별이 실제로 렌더링되고 불투명 전경이 배경 별을 모두 가리는지 확인한다. 루트 238개/앱 48개 테스트도 통과했다. 소프트웨어 Chromium 검수이며 사용자 GPU의 프레임률이나 실물 모바일 성능까지 보장하는 결과는 아니다.

## 후속 사용자 정정 — 경로선 두께

일반 경로가 궤도선과 혼동되지 않도록 실사형 폭 배율을 0.64→1.25, 홀로그램형을 0.78→1.45로 높였다(약 1.9배). 활성 금빛 경로는 기존의 일반 경로 대비 굵기 차이를 유지한다. 궤도선과 위치/경로 계산은 변경하지 않았다.

두께 보정 후 빌드와 실제 실사/홀로그램 캡처, 셰이더 오류 없음/운항 저장 상태 불변 확인을 통과했다. 최신 두께: [실사](route-width-physical.png), [홀로그램](route-width-hologram.png). 앞의 전체 스타일 비교 캡처는 두께 보정 전 기록이다.
