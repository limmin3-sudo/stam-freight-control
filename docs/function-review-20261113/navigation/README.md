# 항로 지도 — 기능 연결과 공통 테마

기준: beta 2.6.0 `40c3301`. 작업 브랜치: `feature/navigation-console-20261113`. 공개 배포 전 검토본이다. 연출 PR #25의 미승인 자산은 사용하지 않는다.

## 변경

- 사용자 정정: 지명은 테두리/박스 배경 없는 글자와 위치 표식으로 표시한다. 지도 내부 캔버스의 영문·숫자도 Barlow 500으로 그린다.

- 고정 상단바/승인 사이드바 안에서 왼쪽 지도, 오른쪽 방문 순서를 유지한다. 지도에는 미션 콘솔과 같은 Barlow Medium 500 + SUIT, 균일한 유리 프레임과 버튼을 적용한다.
- 선택한 방문의 픽업/배송/계약/적재만 펼친다. 다른 방문은 작업 개수를 요약하고 오른쪽 목록만 스크롤한다. 구간·누적·전체 예상 시간을 표시한다. 운항 중 현재 작업과 완료 방문은 선택 중인 방문과 구분한다.
- 지도 거점 선택/검색으로 해당 방문을 함께 선택한다. 같은 거점을 여러 번 방문하면 현재 선택을 유지하고, 다른 거점에서 선택할 경우 현재 진행 이후의 방문을 우선한다. 현재 작업/출발지로 돌아가는 버튼을 제공한다. 탐색이나 미리보기로 실제 계약·선적·운항 상태를 변경하지 않는다.
- 예전 `starmap.mjs`의 회전/이동/줌/계층 탐색을 그대로 사용한다. 별도 지도 엔진으로 재작성하지 않았다. 키보드 Tab으로 지도 진입이 가능하도록 기존 tabindex를 보존하고, 전체 항성계 화면에서 바로 위에서 보기로 전환할 때 시점 옵션을 적용한다. 목록에서 고른 거점이 F 키 초점 대상이 되도록 맞춘다. 먼 거리에서 확대 이동 중 현재 거리가 아직 멀다는 이유로 focusId가 해제되던 문제는 목표 거리 기준으로 고쳐, 실제 축소 의도일 때만 초점을 해제한다.
- 승인했던 `stellar-plasma.png`, 행성 표면과 항성계별 배경을 재사용했다. 새 항성 그림을 생성하거나 기존 선택안을 교체하지 않았다. 이번 작업이 새로운 전체 천체 그래픽 제작 완료를 의미하지 않는다.

## 기존 CI 실패의 원인

`check-intro-guide-browser.mjs`는 구형 독립 도구에서 지도와 경로가 같은 행이라고 가정했다. 실제 `flight-deck.css`/DOM은 넓은 지도 아래에 적재와 경로를 나란히 놓는다. 검사를 실제 구조(소개 아래 지도, 지도 아래 적재/경로, 그 둘의 상단 정렬과 workspace 내부 경계)로 고쳤다. 이동된 설정/도움말은 실제 `.prep-utility`/`.deck-help` 메뉴를 펼쳐 접근한다. 이 오류 때문에 과거 레이아웃으로 제품을 되돌리지 않는다.

## 검증과 캡처

- `scripts/check-navigation-browser.mjs`: 실제 회전/우클릭 이동/Shift 이동/휠 확대, 항성계·위성 탐색, 방문 선택 시 해당 계통으로 복귀, 실제 적재 3D 상자 선택/소유권, 미리보기의 운항 상태 불변, 언어/모바일, 관제센터 테이블→지도, 적재 중 재접속, 배송과 되돌리기.
- `scripts/check-map-console-browser.mjs`: 배포용 빌드에서 지도/방문 목록 좌우 정렬, 폰트, 선택 방문만 펼침, 검색과 방문 연동, 같은 거점의 반복 방문 선택 유지, 키보드 Esc 계층 이동, 전체 항성계에서 위에서 보기, 출발지 복귀, 저장 상태 불변, 390px 넘침과 실제 1920×1080 캡처.
- `scripts/check-intro-guide-browser.mjs`: 기존 도구의 배치와 가이드/설정/영상/모바일 회귀.
- 루트/앱 테스트와 TypeScript/Vite 빌드 로그를 같은 폴더에 보존한다. 합성 예시 계약으로 검수했으며 실게임·실물 모바일·사용자 GPU에서 새로 검증한 결과는 아니다.

미리보기는 `http://127.0.0.1:5186/#/mission?lang=ko`에서 항해사 선택 → 예시 계약 보기 → 계약 선택 → 계산이다. 배포용 빌드 미리보기는 5188이다. 기존 운항이 있으면 초기 파트너 선택은 반복하지 않는다.

다음은 사용자 화면 검토 후 필요한 지도 시각 조정, 이후 관제 콘솔 테마/작업 배치, 적재 3D다. 2.5D 파트너 선택과 새 홀로그램 연출은 별도 연출 작업이다.

## 검증 결과

- 루트 238개 / 앱 48개 테스트 통과(지도 선택·배치 변경 후). 최종 지명 테두리 제거·캔버스 서체 변경은 후속 빌드/브라우저에서 확인한다.
- TypeScript + Vite 배포용 빌드 통과. 기존 큰 번들 안내는 남아 있다.
- 전체 지도 조작/적재 소유권/운항 재접속·되돌리기 검사 통과.
- 구형 도구 검사 통과: 한·영 55개 안내 슬라이드 각각 1440/390px, 실제 배치·설정·도움말 접근, 돌아오기·데이터 보존, 영상 재생/닫기·모바일.
- 전체 관제 콘솔 테마 개편과 실제 기기 성능 검수는 이번 완료 범위가 아니다.

실제 화면 캡처: [1920×1080 지도](map-overview.png). 지명의 버튼형 프레임을 제거한 검토본이다. 고정 사이드바/상단바는 이전 디자인 그대로다.

최종 배포용 빌드 브라우저 검사 통과: 지명 프레임 제거/서체 변경과 초점 유지 수정 이후, 검색·반복 방문·F 확대·Esc 계층 이동·전체 항성계에서 위에서 보기·출발지 복귀·저장 데이터 불변·390px 넘침을 확인했다. `map-console-browser.log`, `map-planet.png`, `map-mobile.png` 참조. 실물 모바일 검증은 아니다.
