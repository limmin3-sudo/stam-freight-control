# 대기권 구간과 경로 비용

수석 항해사는 거점 재방문·불필요한 항성계 왕복·행성권 재방문을 먼저 줄이고, 같은 조건에서는 예상 비행·접근·착륙·작업 비용과 거리를 차례로 비교한다. 거리가 조금 늘더라도 반복 진입·착륙을 줄이는 사용자 결정이다. 큰 문제의 제한된 후보 탐색은 전역 최적을 보장하지 않는다.

한 구간은 다음 순서다.

1. 지상 출발이면 이륙 준비 후 퀀텀 진입 고도까지 가속·상승한다.
2. 함선의 선택한 퀀텀 드라이브로 이동한다. 항성계 변경은 확인된 점프 연결을 거친다.
3. 지상 도착이면 하강과 저속 최종 접근을 거쳐 착륙·정렬한다.
4. 정박 준비와 화물 작업을 더한다. 대기권 시간이 퀀텀 시간 안에 겹쳐 계산되지는 않는다.

같은 천체·같은 행성권의 다른 천체·다른 행성권·다른 항성계는 구분한다. 일률적인 거리 배수 대신 각 구간의 퀀텀 성능, 지상/우주 접근, 점프 및 착륙 비용을 사용한다. 항성이 부모인 정거장의 가장 가까운 행성권은 실제 궤도 소속이 아닌 인접권이다.

## 확인된 값과 가정

- Star Citizen Wiki의 함선별 SCM·NAV·0→SCM 시간과 선택한 퀀텀 드라이브를 참조한다. 퀀텀 가속을 대기권 가속으로 사용하지 않는다.
- 기본 상승 목표는 NAV의65%, 상승 순가속은 SCM/0→SCM 시간의25%다. 두 비율은 **계획용 가정**이며 대기 밀도·중력·부스트·적재 질량을 측정한 값이 아니다. 함선별 성능 설정의 상승 목표·순가속을 직접 보정할 수 있다. 같은 최고속도라도 순가속이 작으면 상승 시간이 늘어난다.
- 상승은 목표 속도까지 일정 순가속 후 등속으로 가정한다. 거리가 짧아 목표 속도에 못 미치면 가속 구간만 계산한다. 이륙 준비 여유 기본1분은 별도다.
- 하강은 NAV 구간 후 목적지 약10km에서 SCM 접근 평균(SCM65% 가정)으로 전환하며, 마지막2km는 최대50m/s로 느리게 접근한다. 모드 전환만으로 즉시 감속한다고 보지 않고 하강·정렬 여유를 별도로 둔다. 하강·착륙 정렬 여유는 기존 설정을 보존한다(기본5분).
- 퀀텀 진입 고도 기본30km는 전 천체에 확인된 실제 고도가 아니다. 설정에서 보정한다. 천체별 중력·대기·실제 퀀텀 제한 고도 자료는 현재 묶음에 없다.
- SCU는 부피다. 품목·질량 자료 없이 SCU를 kg으로 바꾸거나 적재량에 따른 실제 가속 저하를 계산하지 않는다. 무거운 함선·적재 상태는 실비행에 맞춰 순가속을 낮춰 보정한다. 단순한 “대형함선 배수”는 사용하지 않는다.

방문 순서에는 상승·하강/착륙의 가정 시간을 따로 표시한다. 실제 게임 비행시간을 보장하는 시뮬레이터는 아니다. 간편 경로도 비행 비용은 반영하지만 함선 용량·그리드·상자 작업은 계산하지 않는다.


## 다른 도구의 확인 범위

- [StarLane](https://starlane.tech/)은 공식 소개에서 퀀텀 준비·대기권 이동·착륙을 시간 간선 비용으로 명시하고, 위키 좌표 예상값을 수동 검증 시간으로 보정한다고 설명한다. 실제 가속·항력 공식까지 공개됐다고 주장하지 않는다.
- [Cargo Deck](https://cargodeck.onrender.com/en)의 Flugzeiten 설정은 출발→퀀텀 준비 약1분, 마지막 약20km 접근·착륙 약1분30초를 제작자의 측정 예로 설명하며 보정 입력을 제공한다. 이 값들은 모든 함선·행성의 기준이 아니므로 STAM에 실제 성능값으로 수입하지 않는다. “이륙 전체 측정”을 “이륙 준비”에 다시 더해 중복하지 않도록 계산 범위를 구분한다.
- [Schaulers 공개 lane-data.js](https://schaulers.space/lane-data.js?v=1)는 함선·노선별 전체 경과 시간표를 먼저 조회하고, 없으면 권역 시간표와 적재량 등급의 작업 추가 시간을 사용한다. 2026-08-28 생성 주석을 확인했다. 이는 질량·중력·항력을 적분하는 대기권 상승 공식이 아니다. 공개 파일은 읽어 비교했으며 코드·시간표를 복사하지 않았다.
- [Verse Toolkit](https://versetoolkit.com/starmap/)은 상승·하강을 경로에 넣지 않고 이동 시간도 제시하지 않는다고 명시한다. 이번 대기권 계산의 근거로 사용하지 않는다.
- SPViewer의 성능 화면은 검색되지만 현재 직접 조회가 리디렉션 반복으로 실패했다. 연료 항목 근처의 Estimated flight time을 대기권 상승 시간이라고 해석하지 않았다.

확인한 공개 도구에서 적재 질량·천체별 중력·항력을 모두 반영하는 재사용 가능한 상승·착륙 공식을 검증하지는 못했다. 따라서 이번 구현은 단계별 추정과 함선별 보정이며 실게임 물리 재현을 주장하지 않는다.
