# 기능 클라우드 작업본 보존

이 브랜치는 e1d9f0d에서 시작한 미션 콘솔·입체지도·적재 3D 작업을 보존한다. 최신 개발 인계/공개 배포본과 구분한다. 셔틀 탑승 연결 4990780과 연출 PR #23은 포함되지 않는다. 운영 배포나 통합 완료본이 아니다.

- 최신 인계 문서: 개발 브랜치 `handoff/local-studio-20261110`의 `docs/LOCAL-FUNCTION-HANDOFF.md`.
- 이 브랜치의 `SpaceExperience.tsx`를 통째로 최신 파일에 덮어쓰지 않는다. 셔틀 연결 보존과 관제센터 전경 홀로그램 호출 복원이 통합 우선 검수 항목이다.
- `star-approved.png`: 사용자가 마지막으로 선택한 **개편 후 중간 항성**. `stellar-plasma.png` 정면 VFX이며 개편 전 항성 셰이더가 아니다.
- `cargo-detail.png`: 새 프레임·잠금봉·고정 비율 SCU 명판이 적용된 실제 앱 캡처. 이 후속 적재 표현의 사용자 최종 승인은 아직 없다.
- `map-overview.png`: 왼 지도/오른 방문 순서 검토 캡처. 초기 천체 표현이 담긴 구성 자료이며 항성/표면의 최신 미술 기준은 아니다.
- 나머지 이미지/브라우저 로그는 해당 파일명의 재현 검증 결과다. 합성 계약이며 실제 게임 데이터가 아니다.
- `../function-design-archive-20261112/`: 과거 테마/서체/버튼/화면 구성 비교 시안. 실제 계산이 연결된 앱이 아니다. 최초 제안 중 가상 바닥 등은 현재 요구와 다르므로 재적용하지 않는다.
- `prototypes/guide`, `prototypes/intro-archive`: 기존 미추적 준비/폐기 자료도 보존했다. 실행 앱 및 공개 빌드에 연결하지 않는다. 최신 이용안내/승인 영상으로 바꾸어 쓰지 않는다.
