# 시장정보실·운송정보실 연결 및 자료 전수 대조

2026-11-16 기능 Codex · `integration/freight-division-20261113`. 미커밋·미배포. 사용자 추가 지시로 무역/운송 자료 수집과 대조 범위를 확대했다. 기존 인물·로비·상단바·사이드바·운항/계정 작업은 보존했다.

## 제품 연결

- 무역센터 시장정보실: 품목 검색, 행성계, 독립적인 위법 분류/화물 취급 위험 필터, 사용자 관점 구매·판매 aUEC/SCU, 공급/수요의 0과 미확인 구분, 이전 패치/24시간 경과/시점 미확인 표시. 최신 자료만 선택 가능.
- 114개 거래소의 최대 상자·엘리베이터·도킹·자동 적재 자료. 이 값만으로 특정 함선의 출입/상하역 성공을 보장하지 않는다. 위험 필터는 화물 특성이며 항로 치안 점수로 위장하지 않는다. 합법성도 UEX 분류이며 관할·소유권별 판정은 미구현.
- 최초 진입 시 가격이 있는 품목 선택. 품목 상세는 필요한 시점에만 공개 API 조회, 메모리 30분 캐시/동시 요청 공유, 타임아웃. 실패/버전 불일치 시 마지막 성공 자료 유지. 날짜를 새 조회 시각으로 덮어써 가격 자체가 최신처럼 보이게 하지 않는다. 수동 재확인과 빈 결과/실패 복구 제공.
- 아카데미 운송정보실: 기존 미션·함선·화물 상세 자료 연결, 공식 4.10.3 화물 관련 주의사항, 미션/그리드/적재량 출처 차이와 이전 버전 보존 이유 표시. 교육실·작전연구실은 아직 소개 단계다.
- `MarketInformation.tsx`, `FreightInformation.tsx`는 방문 시 지연 로드. 실제 거래, 추천 루트, 거래 운항 저장, 신규 전체 투어는 이번 범위가 아니다.

## 자동 갱신과 재현

- `node --experimental-strip-types scripts/refresh-trade.ts`: 전체 LIVE 거래소를 순차 조회하며 요청 간 1.1초 간격, ID/중복/누락/버전 변경/급격한 감소 검증 후 파일을 원자적으로 교체한다. 실패 시 이전 스냅샷 유지. 기존 Pages 일일 파이프라인에 연결했으나 **현재 미푸시이므로 운영에서 실행 중인 것은 아니다**.
- `node scripts/refresh-freight-reference.mjs`: Wiki 품목/거점 참고 목록 재수집. 버전 고정, 안정 정렬, 페이지 총수·고유 ID·중간 버전 변화·자료 급감 확인. 실패 시 기존 참고 라이브러리 보존. 현재 수동 실행용이며 운영 스케줄에 별도 등록하지 않았다.
- SCMDB/Wiki 미션, 함선은 기존 갱신 스크립트를 별도 임시 사본에서 실행했다. 처음 함선 재현은 복사본의 log-vehicle-index.mjs 누락으로 실패했고 필요한 파일 복사 후 정상 완료했다.
- 처음 Wiki 공통 페이지 수집기는 품목의 version 필드 부재/거점 중복을 거부했다. 실패 자료는 제품에 적용하지 않고 해당 응답 스키마와 안정 정렬을 적용해 전체 다시 확인했다.

## 참고 출처와 사용 경계

- [UEX API](https://uexcorp.space/api/documentation/), [시세](https://uexcorp.space/api/documentation/id/get_commodities_prices/), [거래소](https://uexcorp.space/api/documentation/id/get_terminals/): 커뮤니티 가격, SCU 단위, 시간당 시세 갱신/거래소 패치 단위. 최신 실게임 서버의 재고를 보장하지 않는다.
- [SCMDB 원본](https://github.com/KrovaxCode/SCMDB_DATA), [Wiki API](https://api.star-citizen.wiki/developers), [SuperCargo 그리드](https://github.com/AquatikJustice/SuperCargo): 같은 정의·정확한 변형에 대한 대조만 수행.
- [SC Trade Tools](https://github.com/EtienneLamoureux/sc-trade-tools): REST/MCP는 인증 토큰이 필요한 범위를 확인했다. 토큰 없이 인증 자료를 조회하거나 사용자 비밀값을 프런트에 넣지 않았다. 미연결.
- [Gallog](https://gallog.co/trading): 교역·거점·시간 보고 참고 화면 확인. 지원되는 공개 API가 확인되지 않아 수집 완료/자동 갱신 출처로 표시하지 않는다.
- [Wiki Hauling](https://starcitizen.tools/Hauling): 커리어와 평판 구성의 참고. 2026-09-05 수정된 일반 안내의 상자/수량 구간을 4.10.3 모든 계약에 일괄 적용하지 않는다.
- [RSI 4.10.3 패치](https://robertsspaceindustries.com/en/comm-link/Patch-Notes/21429-Star-Citizen-Alpha-4103), [알려진 문제](https://support.robertsspaceindustries.com/hc/en-us/articles/360056254754-Star-Citizen-Alpha-4-10-3-Known-Issues): 890 Jump 점프 후 상호작용 상실과 지상 차량 화물 그리드 문제를 날짜·원문 링크와 함께 짧게 요약했다. 변할 수 있는 공지이므로 영구적인 함선 제한으로 적용하지 않는다.

## 실행 검증

- 타입 검사 포함 프로덕션 빌드 성공. 앱 99개/루트 271개 테스트 통과. 첫 루트 테스트는 제한된 loopback 환경에서 3개 파일이 실패했고 네트워크 허용 환경으로 재실행해 전체 통과했다.
- 새 데이터 테스트: 0/미확인·단위·ID 조인·중복·부분 응답·이전 패치·오래된/미래 시각·위험/위법 독립·실패 시 원본 보존.
- [브라우저 결과](runtime-review/report.json): 모의 UEX 응답으로 정상/실패와 마지막 성공 자료 보존, 검색·필터·114거점·출처·영어·1366/390 화면·표 내부 스크롤·운항 저장값 보존 확인.
- 기존 로비 6개 방/사이드바/복귀/언어/동작 줄이기 검증 통과. 지연 로딩 중 소개 패널을 완료 화면으로 잘못 잡던 검증을 로딩 구분으로 해소했다.
- 실제 UEX 수집은 TLS 검증을 유지한 네트워크 요청으로 성공했다. Cloud Chromium 직접 외부 요청은 프록시 인증서 신뢰 문제로 실패했으며 이 상황의 저장 자료 표시를 확인했다. `live-network.json`은 이 실패를 기록하며 실사용 브라우저의 직접 갱신 성공 증거로 취급하지 않는다. TLS 검증을 끄지 않았다.
- 실제 게임/실제 거래 실행은 미검증. 공개 배포 없음.

추가 재현: 무역 수집기에 실제 수집한 전체 원본 응답을 재생해 114개 거래소/2,566개 가격의 정상 원자 저장을 확인했다. 새 Wiki 참고 수집기는 실제 네트워크로 재실행해 품목 206개/거점 2,034개 전체 완료했다.
