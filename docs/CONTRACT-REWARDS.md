# 계약 보상과 예상 수입

- 실제 계약에서 확인·직접 입력한 보상이 최우선이다. 직접 확인한0은 `_rewardKnown:true`로 구분한다.
- 실제 보상이 없으면 SCMDB의 동일 정의 UUID에서 찾은 **목록 기본 보상**을 예상 합계·시간당 수입에 사용한다. `_rewardReference`로 출처·빌드·정의 ID를 별도 보존하며 실제 `reward`에 덮어쓰지 않는다.
- 금액이 없거나 SCMDB 자체의 같은 정의에 상충하는 금액이 있으면 미확인으로 표시하고 합계에서 제외한 건수를 알린다. Wiki 보상으로 보완하지 않는다.

목록 기준 예상임을 카드·합계·완료 기록에 표시한다. 실제 보너스·부분 지급·패치 차이로 지급액이 달라질 수 있다. 연료·수리 비용을 뺀 순이익은 아니다. SCU×임의 단가나 STAM 예상 비행시간으로 보상을 지어내지 않는다.

[SCMDB 공개 목록](https://github.com/KrovaxCode/SCMDB_DATA/blob/937f66810a392aa5682b9615a1afbff20fe96e3f/data/merged-4.10.2-live.12913470.json)의 예시 정의 `bc53a9c8-6adf-4f64-9a79-4fccdad4b587`는 기본 보상215,250 aUEC를 제공한다. 직접 입력한 실제180,000은 이 참고값보다 우선하며 다음 수주에 복사하지 않는다. STAM이 게임 보상 산식을 직접 재현했다고 주장하지 않는다.

자료 출처와 자동 갱신은 [미션 데이터 안내](MISSION-DATA-RECONCILIATION.md)를 따른다.
